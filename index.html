（1）JSON 简介

  • 定义：JSON（JavaScript Object Notation）是一种轻量级的数据交互格式，采用文本格式存储和表示数据。

（2）JSON 转换

  • 将 Python 数据转换为 JSON：

    • 使用 json.dumps() 方法。
    • 如果有中文，可以设置 ensure_ascii=False 确保中文正常转换。
    • 语法： 
      json_data = json.dumps(python_data, ensure_ascii=False)
    • 示例： 
      import json

data = {"name": "张三", "age": 25}
json_data = json.dumps(data, ensure_ascii=False)
print(json_data)  # 输出 {"name": "张三", "age": 25}

  • 将 JSON 转换为 Python 数据：

    • 使用 json.loads() 方法。
    • 语法： 
      python_data = json.loads(json_data)
    • 示例： 
      json_data = '{"name": "张三", "age": 25}'
data = json.loads(json_data)
print(data)  # 输出 {'name': '张三', 'age': 25}

Python异常、模块与包

（一）异常

1. 异常的概念

  • 异常：程序运行过程中出现的错误。
  • Bug：指程序中的异常或错误，源于历史上因小虫子导致计算机失灵的案例。
  • 异常的影响：
    • 程序可能因异常停止运行（崩溃）。
    • 通过捕获异常，可以让程序在出现异常时继续运行。

2. 捕获异常

（1）基本语法

  • 作用：提前假设某处会出现异常，并做好处理准备。

  • 语法：

    try:
    可能发生错误的代码
except:
    如果出现异常执行的代码

（2）捕获指定异常

  • 作用：捕获特定类型的异常。

  • 语法：

    try:
    可能发生错误的代码
except 异常类型 as e:
    处理异常的代码

（3）捕获多个异常

  • 作用：捕获多种类型的异常。
  • 语法： 
    try:
    可能发生错误的代码
except (异常类型1, 异常类型2) as e:
    处理异常的代码
  • 示例： 
    try:
    print(num)  # 可能抛出 NameError
    print(1 / 0)  # 可能抛出 ZeroDivisionError
except (NameError, ZeroDivisionError) as e:
    print("捕获到异常:", e)

（4）捕获所有异常

  • 作用：捕获所有类型的异常。

  • 语法：

    try:
    可能发生错误的代码
except Exception as e:
    处理异常的代码

（5）else 和 finally

  • else：当没有异常时执行的代码。
  • finally：无论是否发生异常，都会执行的代码（如关闭文件）。
  • 语法： 
    try:
    可能发生错误的代码
except Exception as e:
    处理异常的代码
else:
    没有异常时执行的代码
finally:
    无论是否异常都会执行的代码
  • 示例： 
    try:
    f = open("test.txt", "r")
except Exception as e:
    print("捕获到异常:", e)
else:
    print("没有异常，真开心")
finally:
    f.close()

3. 异常的传递性

  • 定义：当函数中发生异常且未被捕获时，异常会传递给调用该函数的代码，直到被捕获或程序崩溃。
  • 特点：
    • 异常会从内层函数向外层函数传递。
    • 如果所有函数都未捕获异常，程序会崩溃。
  • 示例： 
    def func01():
    print(1 / 0)  # 抛出 ZeroDivisionError

def func02():
    func01()  # 异常传递到 func02

def main():
    try:
        func02()  # 异常传递到 main
    except Exception as e:
        print("捕获到异常:", e)

main()  # 输出 "捕获到异常: division by zero"

（二）模块

1. 模块的概念

  • 定义：模块是一个 Python 文件（以 .py 结尾），包含类、函数、变量等，可以被其他 Python 程序导入和使用。
  • 作用：
    • 将代码组织成可重用的单元。
    • 提供工具包，帮助快速实现功能（如 time 模块用于时间操作）。

MySQL JSON 数据处理解析

题目要求： 从 products 表的 attributes（JSON 字段）中提取 color 和 size 字段的值。

JSON 提取语法

在 MySQL 中，JSON 数据存储在 JSON 类型的列中，使用 ->> 和 -> 操作符 提取值：

  • -> 返回 JSON 格式 的值（适用于嵌套查询）。
  • ->> 返回 文本格式 的值（适用于字符串和数值查询）。

查询示例：

SELECT 
    attributes->>'$.color' AS color,
    attributes->>'$.size' AS size
FROM products;

示例数据

假设 products 表的结构如下：

CREATE TABLE products (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100),
    attributes JSON
);

表中的数据：

Python数据容器

Python 中的数据容器是用于存储和管理数据的对象。常见的数据容器包括列表（list）、元组（tuple）、字符串（str）、集合（set）和字典（dict）。

（一） 数据容器：list（列表）

1、定义：

  • 列表是一种有序、可变的数据容器，可以存储任意类型的元素
  • 元素可以重复、支持增删改查操作
  • 列表可以一次存储多个数据，且可以为不同的数据类型（混装），支持嵌套
  • 下标支持从前往后（正数）、从后往前（负数）
列表名 = [元素1, 元素2, ...]

2、list 的遍历

  • 方法 1：使用 for 循环

    for fruit in fruits:
    print(fruit)

  • 方法 2：使用索引

    for i in range(len(fruits)):
    print(fruits[i])

  • 方法 3：使用 enumerate()

    for index, fruit in enumerate(fruits):
    print(f"Index: {index}, Fruit: {fruit}")

3、列表常用操作

# 定义一个列表
fruits = ["apple", "banana", "cherry"]

# 1. 追加元素
fruits.append("orange")
print("追加后:", fruits)  # 输出 ['apple', 'banana', 'cherry', 'orange']

# 2. 扩展列表
fruits.extend(["grape", "mango"])
print("扩展后:", fruits)  # 输出 ['apple', 'banana', 'cherry', 'orange', 'grape', 'mango']

# 3. 插入元素
fruits.insert(1, "pear")
print("插入后:", fruits)  # 输出 ['apple', 'pear', 'banana', 'cherry', 'orange', 'grape', 'mango']

# 4. 删除元素
del fruits[2]
print("删除后:", fruits)  # 输出 ['apple', 'pear', 'cherry', 'orange', 'grape', 'mango']

# 5. 弹出元素
removed_fruit = fruits.pop(3)
print("弹出后:", fruits)        # 输出 ['apple', 'pear', 'cherry', 'grape', 'mango']
print("弹出的元素:", removed_fruit)  # 输出 orange

# 6. 移除元素
fruits.remove("pear")
print("移除后:", fruits)  # 输出 ['apple', 'cherry', 'grape', 'mango']

# 7. 清空列表
fruits.clear()
print("清空后:", fruits)  # 输出 []

# 8. 统计元素
fruits = ["apple", "banana", "cherry", "banana"]
count = fruits.count("banana")
print("banana 出现的次数:", count)  # 输出 2

# 9. 查找元素下标
index = fruits.index("cherry")
print("cherry 的下标:", index)  # 输出 2

# 10. 获取列表长度
length = len(fruits)
print("列表长度:", length)  # 输出 4

# 11. 修改元素
fruits[1] = "orange"
print("修改后:", fruits)  # 输出 ['apple', 'orange', 'cherry', 'banana']

# 12. 反转列表
fruits.reverse()
print("反转后:", fruits)  # 输出 ['banana', 'cherry', 'orange', 'apple']

# 13. 排序列表
numbers = [3, 1, 4, 2]
numbers.sort()
print("排序后:", numbers)  # 输出 [1, 2, 3, 4]

# 14. 切片操作
subset = fruits[1:3]
print("切片后:", subset)  # 输出 ['cherry', 'orange']

Python文件操作

（一）编码

1. 编码的概念

  • 定义：编码是一种将 可识别内容（如文字、符号等）转换为 二进制数据 的规则，同时也定义了如何将二进制数据转换回可识别内容。
  • 作用：
    • 存储：将人类可读的内容转换为计算机可存储的二进制数据。
    • 传输：在网络传输中，编码确保数据能够正确传递和解析。
    • 显示：将二进制数据转换回人类可读的内容。

2. 常见编码

（1）UTF-8

  • 是一种 可变长度 的 Unicode 编码。
  • 支持全球所有语言的字符。
  • 兼容 ASCII 编码。
（2）GBK
  • 是一种针对 中文 的编码。
  • 支持简体中文和繁体中文。

（3）Big5

  • 是一种针对 繁体中文 的编码。
  • 主要用于台湾、香港等地区。

3. 编码与解码

（1）编码（Encode）

  • 作用：将字符串转换为二进制数据。

    字符串.encode(编码格式)

    text = "我喜欢你"
binary_data = text.encode("UTF-8")
print(binary_data)  # 输出 b'\xe6\x88\x91\xe5\x96\x9c\xe6\xac\xa2\xe4\xbd\xa0'
（2）解码（Decode）

  • 作用：将二进制数据转换为字符串。

    二进制数据.decode(编码格式)

    binary_data = b'\xe6\x88\x91\xe5\x96\x9c\xe6\xac\xa2\xe4\xbd\xa0'
text = binary_data.decode("UTF-8")
print(text)  # 输出 "我喜欢你"

4. 编码错误的处理

  • 常见错误：
    • UnicodeEncodeError：编码时无法将字符转换为指定编码。
    • UnicodeDecodeError：解码时无法将二进制数据转换为指定编码的字符。
  • 解决方法：
    • 使用 errors 参数指定错误处理方式。
      • ignore：忽略无法编码/解码的字符。
      • replace：用替代字符（如 ?）替换无法编码/解码的字符。
