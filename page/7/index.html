Python文件操作

（一）编码

1. 编码的概念

  • 定义：编码是一种将 可识别内容（如文字、符号等）转换为 二进制数据 的规则，同时也定义了如何将二进制数据转换回可识别内容。
  • 作用：
    • 存储：将人类可读的内容转换为计算机可存储的二进制数据。
    • 传输：在网络传输中，编码确保数据能够正确传递和解析。
    • 显示：将二进制数据转换回人类可读的内容。

2. 常见编码

（1）UTF-8

  • 是一种 可变长度 的 Unicode 编码。
  • 支持全球所有语言的字符。
  • 兼容 ASCII 编码。
（2）GBK
  • 是一种针对 中文 的编码。
  • 支持简体中文和繁体中文。

（3）Big5

  • 是一种针对 繁体中文 的编码。
  • 主要用于台湾、香港等地区。

3. 编码与解码

（1）编码（Encode）

  • 作用：将字符串转换为二进制数据。

    字符串.encode(编码格式)

    text = "我喜欢你"
binary_data = text.encode("UTF-8")
print(binary_data)  # 输出 b'\xe6\x88\x91\xe5\x96\x9c\xe6\xac\xa2\xe4\xbd\xa0'
（2）解码（Decode）

  • 作用：将二进制数据转换为字符串。

    二进制数据.decode(编码格式)

    binary_data = b'\xe6\x88\x91\xe5\x96\x9c\xe6\xac\xa2\xe4\xbd\xa0'
text = binary_data.decode("UTF-8")
print(text)  # 输出 "我喜欢你"

4. 编码错误的处理

  • 常见错误：
    • UnicodeEncodeError：编码时无法将字符转换为指定编码。
    • UnicodeDecodeError：解码时无法将二进制数据转换为指定编码的字符。
  • 解决方法：
    • 使用 errors 参数指定错误处理方式。
      • ignore：忽略无法编码/解码的字符。
      • replace：用替代字符（如 ?）替换无法编码/解码的字符。

（一） JSON 数据处理

（1）JSON 简介

  • 定义：JSON（JavaScript Object Notation）是一种轻量级的数据交互格式，采用文本格式存储和表示数据。

（2）JSON 转换

  • 将 Python 数据转换为 JSON：

    • 使用 json.dumps() 方法。
    • 如果有中文，可以设置 ensure_ascii=False 确保中文正常转换。
    • 语法： 
      json_data = json.dumps(python_data, ensure_ascii=False)
    • 示例： 
      import json

data = {"name": "张三", "age": 25}
json_data = json.dumps(data, ensure_ascii=False)
print(json_data)  # 输出 {"name": "张三", "age": 25}

  • 将 JSON 转换为 Python 数据：

    • 使用 json.loads() 方法。
    • 语法： 
      python_data = json.loads(json_data)
    • 示例： 
      json_data = '{"name": "张三", "age": 25}'
data = json.loads(json_data)
print(data)  # 输出 {'name': '张三', 'age': 25}

Python异常、模块与包

（一）异常

1. 异常的概念

  • 异常：程序运行过程中出现的错误。
  • Bug：指程序中的异常或错误，源于历史上因小虫子导致计算机失灵的案例。
  • 异常的影响：
    • 程序可能因异常停止运行（崩溃）。
    • 通过捕获异常，可以让程序在出现异常时继续运行。

2. 捕获异常

（1）基本语法

  • 作用：提前假设某处会出现异常，并做好处理准备。

  • 语法：

    try:
    可能发生错误的代码
except:
    如果出现异常执行的代码

（2）捕获指定异常

  • 作用：捕获特定类型的异常。

  • 语法：

    try:
    可能发生错误的代码
except 异常类型 as e:
    处理异常的代码

（3）捕获多个异常

  • 作用：捕获多种类型的异常。
  • 语法： 
    try:
    可能发生错误的代码
except (异常类型1, 异常类型2) as e:
    处理异常的代码
  • 示例： 
    try:
    print(num)  # 可能抛出 NameError
    print(1 / 0)  # 可能抛出 ZeroDivisionError
except (NameError, ZeroDivisionError) as e:
    print("捕获到异常:", e)

（4）捕获所有异常

  • 作用：捕获所有类型的异常。

  • 语法：

    try:
    可能发生错误的代码
except Exception as e:
    处理异常的代码

（5）else 和 finally

  • else：当没有异常时执行的代码。
  • finally：无论是否发生异常，都会执行的代码（如关闭文件）。
  • 语法： 
    try:
    可能发生错误的代码
except Exception as e:
    处理异常的代码
else:
    没有异常时执行的代码
finally:
    无论是否异常都会执行的代码
  • 示例： 
    try:
    f = open("test.txt", "r")
except Exception as e:
    print("捕获到异常:", e)
else:
    print("没有异常，真开心")
finally:
    f.close()

3. 异常的传递性

  • 定义：当函数中发生异常且未被捕获时，异常会传递给调用该函数的代码，直到被捕获或程序崩溃。
  • 特点：
    • 异常会从内层函数向外层函数传递。
    • 如果所有函数都未捕获异常，程序会崩溃。
  • 示例： 
    def func01():
    print(1 / 0)  # 抛出 ZeroDivisionError

def func02():
    func01()  # 异常传递到 func02

def main():
    try:
        func02()  # 异常传递到 main
    except Exception as e:
        print("捕获到异常:", e)

main()  # 输出 "捕获到异常: division by zero"

Python面向对象

1. 类的组成

类由两部分组成：

  • 成员变量（属性）：描述类的特征或状态。
  • 成员方法（行为）：描述类的行为或功能。

注意：函数写在类外，而定义在类内部的函数称为方法。

2. 类和成员方法的定义语法

类的定义语法：

class 类名:
    成员变量
    成员方法

成员方法的定义语法：

def 方法名(self, 参数1, 参数2, ...):
    方法体

3. self 的作用

  • self 表示类对象本身。
  • 只有通过 self，成员方法才能访问类的成员变量。
  • self 出现在形参列表中，但不占用参数位置，调用时无需传递。

4. 构造方法

构造方法的名称：

__init__，注意 init 前后有两个下划线。

构造方法的作用：

  • 在创建类对象时自动运行。
  • 构造方法的参数会传递给类对象，借此可以初始化成员变量。

注意事项：

  • 构造方法中不要忘记 self 关键字。
  • 在方法内使用成员变量时需要使用 self。

8. 常用特殊方法

方法 功能
__init__ 构造方法，用于创建类对象时设置初始化行为。
__str__ 用于实现类对象转字符串的行为，通常用于打印对象信息。
__lt__ 用于两个类对象进行小于或大于比较。
__le__ 用于两个类对象进行小于等于或大于等于比较。
__eq__ 用于两个类对象进行相等比较。

示例代码

class Person:
    # 构造方法
    def __init__(self, name, age):
        self.name = name  # 成员变量
        self.age = age

    # 成员方法
    def say_hello(self):
        print(f"Hello, my name is {self.name} and I am {self.age} years old.")

    # __str__ 方法
    def __str__(self):
        return f"Person(name={self.name}, age={self.age})"

    # __eq__ 方法
    def __eq__(self, other):
        return self.name == other.name and self.age == other.age

# 创建对象
person1 = Person("Alice", 25)
person2 = Person("Bob", 30)

# 调用方法
person1.say_hello()

# 打印对象信息
print(person1)

# 比较对象
print(person1 == person2)  # False
