Python数据容器

Python 中的数据容器是用于存储和管理数据的对象。常见的数据容器包括列表（list）、元组（tuple）、字符串（str）、集合（set）和字典（dict）。

（一） 数据容器：list（列表）

1、定义：

  • 列表是一种有序、可变的数据容器，可以存储任意类型的元素
  • 元素可以重复、支持增删改查操作
  • 列表可以一次存储多个数据，且可以为不同的数据类型（混装），支持嵌套
  • 下标支持从前往后（正数）、从后往前（负数）
列表名 = [元素1, 元素2, ...]

2、list 的遍历

  • 方法 1：使用 for 循环

    for fruit in fruits:
    print(fruit)

  • 方法 2：使用索引

    for i in range(len(fruits)):
    print(fruits[i])

  • 方法 3：使用 enumerate()

    for index, fruit in enumerate(fruits):
    print(f"Index: {index}, Fruit: {fruit}")

3、列表常用操作

# 定义一个列表
fruits = ["apple", "banana", "cherry"]

# 1. 追加元素
fruits.append("orange")
print("追加后:", fruits)  # 输出 ['apple', 'banana', 'cherry', 'orange']

# 2. 扩展列表
fruits.extend(["grape", "mango"])
print("扩展后:", fruits)  # 输出 ['apple', 'banana', 'cherry', 'orange', 'grape', 'mango']

# 3. 插入元素
fruits.insert(1, "pear")
print("插入后:", fruits)  # 输出 ['apple', 'pear', 'banana', 'cherry', 'orange', 'grape', 'mango']

# 4. 删除元素
del fruits[2]
print("删除后:", fruits)  # 输出 ['apple', 'pear', 'cherry', 'orange', 'grape', 'mango']

# 5. 弹出元素
removed_fruit = fruits.pop(3)
print("弹出后:", fruits)        # 输出 ['apple', 'pear', 'cherry', 'grape', 'mango']
print("弹出的元素:", removed_fruit)  # 输出 orange

# 6. 移除元素
fruits.remove("pear")
print("移除后:", fruits)  # 输出 ['apple', 'cherry', 'grape', 'mango']

# 7. 清空列表
fruits.clear()
print("清空后:", fruits)  # 输出 []

# 8. 统计元素
fruits = ["apple", "banana", "cherry", "banana"]
count = fruits.count("banana")
print("banana 出现的次数:", count)  # 输出 2

# 9. 查找元素下标
index = fruits.index("cherry")
print("cherry 的下标:", index)  # 输出 2

# 10. 获取列表长度
length = len(fruits)
print("列表长度:", length)  # 输出 4

# 11. 修改元素
fruits[1] = "orange"
print("修改后:", fruits)  # 输出 ['apple', 'orange', 'cherry', 'banana']

# 12. 反转列表
fruits.reverse()
print("反转后:", fruits)  # 输出 ['banana', 'cherry', 'orange', 'apple']

# 13. 排序列表
numbers = [3, 1, 4, 2]
numbers.sort()
print("排序后:", numbers)  # 输出 [1, 2, 3, 4]

# 14. 切片操作
subset = fruits[1:3]
print("切片后:", subset)  # 输出 ['cherry', 'orange']

Python文件操作

（一）编码

1. 编码的概念

  • 定义：编码是一种将 可识别内容（如文字、符号等）转换为 二进制数据 的规则，同时也定义了如何将二进制数据转换回可识别内容。
  • 作用：
    • 存储：将人类可读的内容转换为计算机可存储的二进制数据。
    • 传输：在网络传输中，编码确保数据能够正确传递和解析。
    • 显示：将二进制数据转换回人类可读的内容。

2. 常见编码

（1）UTF-8

  • 是一种 可变长度 的 Unicode 编码。
  • 支持全球所有语言的字符。
  • 兼容 ASCII 编码。
（2）GBK
  • 是一种针对 中文 的编码。
  • 支持简体中文和繁体中文。

（3）Big5

  • 是一种针对 繁体中文 的编码。
  • 主要用于台湾、香港等地区。

3. 编码与解码

（1）编码（Encode）

  • 作用：将字符串转换为二进制数据。

    字符串.encode(编码格式)

    text = "我喜欢你"
binary_data = text.encode("UTF-8")
print(binary_data)  # 输出 b'\xe6\x88\x91\xe5\x96\x9c\xe6\xac\xa2\xe4\xbd\xa0'
（2）解码（Decode）

  • 作用：将二进制数据转换为字符串。

    二进制数据.decode(编码格式)

    binary_data = b'\xe6\x88\x91\xe5\x96\x9c\xe6\xac\xa2\xe4\xbd\xa0'
text = binary_data.decode("UTF-8")
print(text)  # 输出 "我喜欢你"

4. 编码错误的处理

  • 常见错误：
    • UnicodeEncodeError：编码时无法将字符转换为指定编码。
    • UnicodeDecodeError：解码时无法将二进制数据转换为指定编码的字符。
  • 解决方法：
    • 使用 errors 参数指定错误处理方式。
      • ignore：忽略无法编码/解码的字符。
      • replace：用替代字符（如 ?）替换无法编码/解码的字符。

1. 打开文件

  • file：文件路径（字符串类型）。

1、Python 中的三元表达式

[on_true] if [expression] else [on_false]
  • [expression] 是一个布尔表达式，结果为 True 或 False。
  • 如果 [expression] 为 True，则整个表达式的结果是 [on_true]。
  • 如果 [expression] 为 False，则整个表达式的结果是 [on_false]。

例子：

x = 10
y = 20

# 使用三元表达式选择较大的值
max_value = x if x > y else y

print(max_value)  # 输出: 20

在这个例子中，x > y 是 False，所以 max_value 被赋值为 y，即 20。

2、Python 中如何实现多线程？

Python 中的多线程可以通过 threading 模块来实现。线程是轻量级的进程，多线程允许程序同时执行多个任务。然而，由于 Python 的全局解释器锁（GIL），多线程在 CPU 密集型任务中并不能真正实现并行执行，但在 I/O 密集型任务中仍然有用。

使用 threading 模块实现多线程

import threading

def print_numbers():
    for i in range(5):
        print(i)

def print_letters():
    for letter in ['a', 'b', 'c', 'd', 'e']:
        print(letter)

# 创建线程
thread1 = threading.Thread(target=print_numbers)
thread2 = threading.Thread(target=print_letters)

# 启动线程
thread1.start()
thread2.start()

# 等待线程完成
thread1.join()
thread2.join()

print("多线程执行完毕")

  1. GIL（全局解释器锁）：Python 的 GIL 确保同一时间只有一个线程执行 Python 字节码。这意味着即使在多核 CPU 上，Python 的多线程也不能真正并行执行 CPU 密集型任务。GIL 的存在是为了保护 Python 解释器的内部数据结构不被多个线程同时修改。

SQL时间相关总结

1. 常见时间类型

数据库通常支持以下几种时间类型：

  • DATE：仅存储日期，格式为 YYYY-MM-DD。
  • TIME：仅存储时间，格式为 HH:MM:SS。
  • DATETIME / TIMESTAMP：存储日期和时间，格式为 YYYY-MM-DD HH:MM:SS。
  • YEAR：仅存储年份。
  • INTERVAL：表示时间间隔（如 30 days、1 month 等）。

2. 获取当前时间

数据库提供了多种函数来获取当前时间：

  • CURRENT_DATE：返回当前日期（不包括时间）。 
    SELECT CURRENT_DATE;  -- 2023-10-05
  • CURRENT_TIME：返回当前时间（不包括日期）。 
    SELECT CURRENT_TIME;  -- 14:30:45
  • CURRENT_TIMESTAMP / NOW()：返回当前日期和时间。 
    SELECT CURRENT_TIMESTAMP;  -- 2023-10-05 14:30:45

3. 时间计算

数据库支持对时间进行加减运算，常用的方式是使用 INTERVAL。

示例 1：加减天数

SELECT CURRENT_DATE + INTERVAL '10 days';  -- 10 天后的日期
SELECT CURRENT_DATE - INTERVAL '30 days'; -- 30 天前的日期

示例 2：加减月份

SELECT CURRENT_DATE + INTERVAL '1 month';  -- 1 个月后的日期
SELECT CURRENT_DATE - INTERVAL '3 months'; -- 3 个月前的日期

示例 3：加减时间

SELECT CURRENT_TIME + INTERVAL '2 hours';  -- 2 小时后的时间
SELECT CURRENT_TIME - INTERVAL '30 minutes'; -- 30 分钟前的时间

1、partition by 和 group by的区别

GROUP BY

  • 用途: GROUP BY 用于将数据分组，并对每个分组进行聚合计算（如 SUM、AVG、COUNT 等）。

  • 结果: 它会将多行数据合并为一行，每个分组只返回一行结果。

  • 使用场景: 当你需要对数据进行分组并计算汇总值时使用。

  • 示例:

    SELECT dept_id, AVG(salary) AS avg_salary
FROM employees
GROUP BY dept_id;

    这个查询会返回每个部门的平均工资，每个部门只有一行结果。

  • 特点:

    • 分组后的结果会减少行数。
    • 只能选择分组字段和聚合函数的结果。

PARTITION BY

  • 用途: PARTITION BY 是窗口函数的一部分，用于在窗口函数中对数据进行分组，但不会减少行数。

  • 结果: 它不会将多行合并为一行，而是为每一行计算一个值（如排名、累计值等）。

  • 使用场景: 当你需要对数据进行分组计算，但希望保留原始行数时使用。

  • 示例:

    SELECT name, salary, dept_id,
       RANK() OVER (PARTITION BY dept_id ORDER BY salary DESC) AS rank
FROM employees;

    这个查询会为每个部门的员工根据工资排名，但不会减少行数，结果中每一行都会保留。

  • 特点:

    • 分组后的结果不会减少行数。
    • 可以同时选择分组字段、原始字段和窗口函数的结果。

核心区别

特性 GROUP BY PARTITION BY
行数变化 减少行数（每个分组返回一行） 不减少行数（保留原始行数）
用途 数据分组和聚合 数据分组并计算窗口函数
是否支持聚合函数 是（如 SUM、AVG、COUNT 等） 否（窗口函数如 RANK、ROW_NUMBER）
结果字段 只能选择分组字段和聚合结果 可以选择原始字段和窗口函数结果

IoC DI AOP

Jinxiwei published on 2025-03-08 included in Java
  • IoC：将对象创建和依赖管理的控制权交给框架。
  • DI：通过注入方式实现IoC，解耦对象及其依赖。
  • AOP：通过切面分离横切关注点，提升代码模块化和可维护性。

1. IoC（Inversion of Control，控制反转）

定义： IoC是一种设计原则，将对象的创建和依赖管理交给框架或容器，而不是由开发者手动控制。

传统方式： 开发者通常在代码中直接创建和管理对象，控制权在开发者手中。

IoC方式： 框架或容器负责对象的创建和生命周期管理，开发者只需定义对象及其依赖关系，控制权转移到框架。

优点：

  • 降低耦合：对象不直接依赖具体实现，而是依赖抽象。
  • 提高灵活性：依赖关系可通过配置更改，无需修改代码。
  • 便于测试：依赖可替换为模拟对象，简化单元测试。

2. DI（Dependency Injection，依赖注入）

定义： DI是IoC的一种实现方式，通过构造函数、setter方法或接口注入依赖对象。

实现方式：

  • 构造函数注入：通过构造函数传递依赖。
  • Setter注入：通过setter方法设置依赖。
  • 接口注入：通过接口方法注入依赖。

示例：

public class MyService {
    private MyRepository repository;

    // 构造函数注入
    public MyService(MyRepository repository) {
        this.repository = repository;
    }

    // Setter注入
    public void setRepository(MyRepository repository) {
        this.repository = repository;
    }
}

优点：

  • 解耦：对象不直接创建依赖，依赖由外部注入。
  • 可测试性：依赖可替换为模拟对象，便于测试。
  • 可配置性：依赖关系可通过配置文件管理。

3. AOP（Aspect-Oriented Programming，面向切面编程）

定义： AOP通过切面将横切关注点（如日志、事务、安全等）与核心业务逻辑分离，提升代码的模块化。

核心概念：

  • 切面（Aspect）：封装横切关注点的模块。
  • 连接点（Join Point）：程序执行中的特定点（如方法调用）。
  • 通知（Advice）：在连接点执行的动作（如前置、后置、环绕通知）。
  • 切入点（Pointcut）：定义哪些连接点会触发通知。
  • 引入（Introduction）：为类添加新方法或属性。
  • 织入（Weaving）：将切面应用到目标对象的过程。
