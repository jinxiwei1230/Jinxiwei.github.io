**1. qsort 函数：**来自 C 标准库 stdlib.h，使用比较函数来确定两个元素的顺序。 **cmp 比较函数：**cmp 是一个函数指针，指向用户定义的比较函数。该比较函数接受两个参数，返回值为：

  • 如果 cmp(a, b) < 0（负数），则 a 排在 b 前面
  • 如果 cmp(a, b) > 0（正数），则 b 排在 a 前面
  • 如果 cmp(a, b) == 0（零），则 a 和 b 视为相等，顺序不变
qsort(nums1, nums1Size, sizeof(int), cmp);

int cmp(const void *a, const void *b)
{
    return *(int*)a - *(int*)b;
}

// 降序比较函数
int cmp_desc(const void* a, const void* b) {
    return *(int*)b - *(int*)a;  // 让较大的数排在前面
}
