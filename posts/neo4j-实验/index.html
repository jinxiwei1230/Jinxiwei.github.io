（一）相关知识回顾

1. 关于CREATE子句的问题

  1. 一个语句可以有多个CREATE子句吗？

    • 是的，一个Cypher语句可以包含多个CREATE子句，用逗号分隔。

  2. 不同CREATE子句节点变量名称能相同吗？

    • 不能，在同一查询中，变量名必须是唯一的。如果重复使用相同变量名，后面的会覆盖前面的。

2. Cypher语句分析

2.1 创建和修改节点

CREATE (n:人物{name:'关羽'}) RETURN n;
  • 创建一个带有"人物"标签的节点，设置name属性为"关羽"，并返回该节点
MATCH (n:人物{name:'关羽'}) SET n:五虎上将:蜀;
  • 查找name为"关羽"的人物节点，并添加"五虎上将"和"蜀"两个标签
MATCH (n:人物{name:'关羽'}) SET n.gender ='男';
  • 查找name为"关羽"的人物节点，设置gender属性为"男"
MATCH (n:人物{name:'关羽'}) 
RETURN labels(n) AS nodeLabel, keys(n) AS nodeProperties, n.name;
  • 查找name为"关羽"的人物节点，返回:
    • 节点的所有标签
    • 节点的所有属性键
    • 节点的name属性值

2.2 删除标签

MATCH (n:人物{name:'关羽'}) REMOVE n:蜀;
  • 查找name为"关羽"的人物节点，删除"蜀"标签

2.3 创建关系

MATCH (n:人物{name:'关羽'}) 
CREATE (n)-[r:义弟{地点:'桃园'}]->(n1:人物{name:'刘备'})
RETURN n,n1;
  • 查找name为"关羽"的人物节点
  • 创建一个新节点n1(刘备)和从n到n1的关系，关系类型为"义弟"，关系属性"地点"为"桃园"
  • 返回关羽和刘备两个节点

2.4 查询关系和节点信息

MATCH (n:人物{name:'关羽'}) -[r]- (n1) 
RETURN type(r) AS relationshipType,
keys(r) AS relationshipProperties,
labels(n1) AS nodeLabel, 
keys(n1) AS nodeProperties, 
n1.name;
  • 查找name为"关羽"的人物节点及其所有关系和相连节点
  • 返回:
    • 关系类型
    • 关系的所有属性键
    • 相连节点的所有标签
    • 相连节点的所有属性键
    • 相连节点的name属性值

2.5 删除节点及其关系

问题1：以下语句是否能删除两个节点及其关联关系？

match (a{name:"张三"})--(b{name:"李四"}) 
where id(a)=1241 and id(b)=1242
delete a,b;

答案：不能。这个语句会报错，因为节点上存在关系时不能直接删除节点。必须先删除关系或使用DETACH DELETE。

正确的删除方式

match (a{name:"张三"})--(b{name:"李四"}) 
where id(a)=1241 and id(b)=1242
DETACH DELETE a,b;
  • DETACH DELETE会先删除节点上的所有关系，然后再删除节点本身

2.6 MERGE操作

创建初始节点

CREATE (e:Customer{custID:100});
CREATE (cc:CreditCard{cardID:300360});

两种创建关系的区别

  1. 使用CREATE创建关系
MATCH (e:Customer{custID:100}),(cc:CreditCard{cardID:300360}) 
CREATE (e)-[r:DO_SHOPPING_WITH]->(cc);
  • 必须确保两个节点已存在
  • 如果关系已存在，会创建重复的关系
  • 如果节点不存在，不会创建新节点
  1. 使用MERGE创建关系
MERGE (e:Customer{custID:100})
MERGE (cc:CreditCard{cardID:300360})
MERGE (e)-[r:DO_SHOPPING_WITH]->(cc);
  • 如果节点不存在会自动创建
  • 会检查关系是否已存在，避免重复创建
  • 是原子操作，保证整个模式存在

3. UNWIND和COLLECT示例

UNWIND示例

WITH [1,2,3] AS list
UNWIND list AS item
RETURN item;
  • 将列表[1,2,3]展开为三行，每行一个值

COLLECT示例

MATCH (n:Person)
RETURN collect(n.name) AS names;
  • 将所有Person节点的name属性收集到一个列表中

组合使用示例

WITH ['Alice','Bob','Charlie'] AS names
UNWIND names AS name
MERGE (p:Person{name:name})
RETURN collect(p.name) AS createdNames;
  • 展开names列表并为每个名字创建Person节点
  • 最后返回所有创建的节点名称集合
