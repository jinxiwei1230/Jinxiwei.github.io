Python数据容器

Python 中的数据容器是用于存储和管理数据的对象。常见的数据容器包括列表（list）、元组（tuple）、字符串（str）、集合（set）和字典（dict）。

（一） 数据容器：list（列表）

1、定义：

  • 列表是一种有序、可变的数据容器，可以存储任意类型的元素
  • 元素可以重复、支持增删改查操作
  • 列表可以一次存储多个数据，且可以为不同的数据类型（混装），支持嵌套
  • 下标支持从前往后（正数）、从后往前（负数）
列表名 = [元素1, 元素2, ...]

2、list 的遍历

  • 方法 1：使用 for 循环

    for fruit in fruits:
    print(fruit)

  • 方法 2：使用索引

    for i in range(len(fruits)):
    print(fruits[i])

  • 方法 3：使用 enumerate()

    for index, fruit in enumerate(fruits):
    print(f"Index: {index}, Fruit: {fruit}")

3、列表常用操作

# 定义一个列表
fruits = ["apple", "banana", "cherry"]

# 1. 追加元素
fruits.append("orange")
print("追加后:", fruits)  # 输出 ['apple', 'banana', 'cherry', 'orange']

# 2. 扩展列表
fruits.extend(["grape", "mango"])
print("扩展后:", fruits)  # 输出 ['apple', 'banana', 'cherry', 'orange', 'grape', 'mango']

# 3. 插入元素
fruits.insert(1, "pear")
print("插入后:", fruits)  # 输出 ['apple', 'pear', 'banana', 'cherry', 'orange', 'grape', 'mango']

# 4. 删除元素
del fruits[2]
print("删除后:", fruits)  # 输出 ['apple', 'pear', 'cherry', 'orange', 'grape', 'mango']

# 5. 弹出元素
removed_fruit = fruits.pop(3)
print("弹出后:", fruits)        # 输出 ['apple', 'pear', 'cherry', 'grape', 'mango']
print("弹出的元素:", removed_fruit)  # 输出 orange

# 6. 移除元素
fruits.remove("pear")
print("移除后:", fruits)  # 输出 ['apple', 'cherry', 'grape', 'mango']

# 7. 清空列表
fruits.clear()
print("清空后:", fruits)  # 输出 []

# 8. 统计元素
fruits = ["apple", "banana", "cherry", "banana"]
count = fruits.count("banana")
print("banana 出现的次数:", count)  # 输出 2

# 9. 查找元素下标
index = fruits.index("cherry")
print("cherry 的下标:", index)  # 输出 2

# 10. 获取列表长度
length = len(fruits)
print("列表长度:", length)  # 输出 4

# 11. 修改元素
fruits[1] = "orange"
print("修改后:", fruits)  # 输出 ['apple', 'orange', 'cherry', 'banana']

# 12. 反转列表
fruits.reverse()
print("反转后:", fruits)  # 输出 ['banana', 'cherry', 'orange', 'apple']

# 13. 排序列表
numbers = [3, 1, 4, 2]
numbers.sort()
print("排序后:", numbers)  # 输出 [1, 2, 3, 4]

# 14. 切片操作
subset = fruits[1:3]
print("切片后:", subset)  # 输出 ['cherry', 'orange']

（二）数据容器：tuple（元组）

1、定义：元组是一种有序、不可变的数据容器。

元组名 = (元素1, 元素2, ...)

2、元组相关操作

方法 作用 代码示例
index() 查找某个数据，如果数据存在返回对应的下标（第一个），否则报错 nums.index(2) → 1
count() 统计某个数据在当前元组中出现的次数 nums.count(2) → 2
len(元组) 统计元组内的元素个数 len(nums) → 4 
# 定义一个元组
nums = (1, 2, 3, 2)

# 1. 查找元素下标
index = nums.index(2)
print("2 的下标:", index)  # 输出 1

# 2. 统计元素出现次数
count = nums.count(2)
print("2 出现的次数:", count)  # 输出 2

# 3. 获取元组长度
length = len(nums)
print("元组长度:", length)  # 输出 4

（三） 数据容器：str（字符串）

1、定义：字符串是一种有序、不可变的字符序列。

text = "Python"
print(text[0])  # 输出 P

2. 字符串的分割

字符串.split(分隔符字符串)

  • 作用：按照指定的分隔符字符串，将字符串划分为多个子字符串，并存入列表对象中。

  • 注意：字符串本身不变，返回一个新的列表。

    text = "apple banana cherry"
result = text.split(" ")
print(result)  # 输出 ['apple', 'banana', 'cherry']

3. 字符串的索引访问

  • 根据下标索引取出特定位置的字符。

    • 从前向后，下标从 0 开始。
    • 从后向前，下标从 -1 开始。

  • 示例：

    text = "Python"
print(text[0])   # 输出 P
print(text[-1])  # 输出 n

4. 字符串的不可变性

  • 字符串是一个 不可修改 的数据容器。
  • 以下操作均无法完成：
    • 修改指定下标的字符（如 字符串[0] = "a"）。
    • 移除特定下标的字符（如 del 字符串[0]）。
    • 追加字符（如 字符串.append()）。
  • 如果需要修改字符串，只能创建一个新的字符串。
text = "Python"
new_text = text.replace("P", "J")
print(new_text)  # 输出 Jython

5. 查找特定字符串的下标索引值

字符串.index(字符串)

  • 作用：查找给定字符串的第一个匹配项的下标。如果字符串不存在，会抛出 ValueError。

    text = "Python"
index = text.index("th")
print(index)  # 输出 2

6. 字符串的替换

字符串.replace(字符串1, 字符串2)

  • 作用：将字符串内的全部 字符串1 替换为 字符串2。不会修改原字符串，而是返回一个新的字符串。

    text = "Hello World"
new_text = text.replace("World", "Python")
print(new_text)  # 输出 Hello Python

7. 字符串的规整操作

（1）去除前后空格
字符串.strip()

  • 移除字符串首尾的空格和换行符。

    text = "  Python  "
result = text.strip()
print(result)  # 输出 Python
（2）去除前后指定字符串
字符串.strip(字符串)

  • 移除字符串首尾的指定字符（按单个字符处理）。

    text = "12Python21"
result = text.strip("12")
print(result)  # 输出 Python

8. 统计字符串中某字符串的出现次数

字符串.count(字符串)

  • 统计字符串内某字符串的出现次数。

    text = "apple banana apple"
count = text.count("apple")
print(count)  # 输出 2

9. 统计字符串的长度

len(字符串)

  • 统计字符串的字符个数。数字、字母、符号、中文均算作 1 个字符。

    text = "Python编程"
length = len(text)
print(length)  # 输出 8

10. 字符串的遍历

  • 方法：使用 for 、while循环遍历字符串中的每个字符。

    text = "Python"
for char in text:
    print(char)

字符串.index(字符串) 查找给定字符串的第一个匹配项的下标
字符串.replace(字符串1, 字符串2) 将字符串内的全部 字符串1 替换为 字符串2，返回新字符串
字符串.split(字符串) 按照给定字符串对字符串进行分隔，返回列表
字符串.strip() 移除首尾的空格和换行符
字符串.strip(字符串) 移除首尾的指定字符（按单个字符处理）
字符串.count(字符串) 统计字符串内某字符串的出现次数

(四) 数据容器的切片

1. 什么是序列？

  • 定义：序列是一种 内容连续、有序，并支持 下标索引 的数据容器。
  • 常见的序列类型：列表（list）、元组（tuple）、字符串（str）

2. 序列的切片操作

序列[起始下标:结束下标:步长]
  • 作用：从序列中提取一个子序列，返回一个新的序列（列表、元组或字符串）。
  • 参数说明：
    • 起始下标：从何处开始（包含）。如果省略，默认从头开始。
    • 结束下标：到何处结束（不包含）。如果省略，默认到结尾。
    • 步长：取元素的间隔。如果省略，默认为 1。
      • 步长为正数：从左向右取。
      • 步长为负数：从右向左取（反向取）。

3. 切片操作示例

（1）基本切片

  • 示例 1：从列表中提取子列表。

    my_list = [1, 2, 3, 4, 5]
new_list = my_list[1:4]  # 从下标1开始，到下标4（不含）结束，步长1
print(new_list)  # 输出 [2, 3, 4]

  • 示例 2：从元组中提取子元组。

    my_tuple = (1, 2, 3, 4, 5)
new_tuple = my_tuple[:]  # 从头开始，到尾结束，步长1
print(new_tuple)  # 输出 (1, 2, 3, 4, 5)

  • 示例 3：从字符串中提取子字符串。

    my_str = "12345"
new_str = my_str[:4:2]  # 从头开始，到下标4（不含）结束，步长2
print(new_str)  # 输出 "13"
（2）步长切片

  • 示例 1：步长为正数。

    my_list = [1, 2, 3, 4, 5]
new_list = my_list[::2]  # 从头开始，到尾结束，步长2
print(new_list)  # 输出 [1, 3, 5]

  • 示例 2：步长为负数（反向取）。

    my_str = "12345"
new_str = my_str[::-1]  # 从头（最后）开始，到尾结束，步长-1（倒序）
print(new_str)  # 输出 "54321"
（3）反向切片

  • 示例 1：从后向前提取子序列。

    my_list = [1, 2, 3, 4, 5]
new_list = my_list[3:1:-1]  # 从下标3开始，到下标1（不含）结束，步长-1（倒序）
print(new_list)  # 输出 [4, 3]

  • 示例 2：从后向前提取子元组。

    my_tuple = (1, 2, 3, 4, 5)
new_tuple = my_tuple[:1:-2]  # 从头（最后）开始，到下标1（不含）结束，步长-2（倒序）
print(new_tuple)  # 输出 (5, 3)

4. 综合表格总结

操作类型 语法示例 说明
基本切片 序列[起始:结束] 从起始下标到结束下标（不含），步长默认为1
省略起始 序列[:结束] 从头开始到结束下标（不含），步长默认为1
省略结束 序列[起始:] 从起始下标到结尾，步长默认为1
省略起始和结束 序列[:] 从头到尾，步长默认为1
步长切片 序列[起始:结束:步长] 按指定步长提取子序列
反向切片 序列[起始:结束:-步长] 从后向前提取子序列
倒序切片 序列[::-1] 反转整个序列

（五） 数据容器：set（集合）

定义：集合是一种无序、不重复的数据容器。

集合名 = {元素1, 元素2, ...}

1. 集合的特点

  • 无序性：集合中的元素是无序存储的，不支持下标索引访问。
  • 唯一性：集合中的元素不允许重复。
  • 可变性：集合可以修改（添加、删除元素等）。
  • 支持多种数据类型：集合可以容纳不同类型的数据（如数字、字符串、元组等）。
  • 支持遍历：可以使用 for 循环遍历集合中的元素。

2. 集合的常用操作

（1）添加元素
集合.add(元素)

my_set = {1, 2, 3}
my_set.add(4)
print(my_set)  # 输出 {1, 2, 3, 4}
（2）移除元素
集合.remove(元素)

  • 注意：如果元素不存在，会抛出 KeyError。

    my_set = {1, 2, 3}
my_set.remove(2)
print(my_set)  # 输出 {1, 3}
（3）随机取出元素
集合.pop()

  • 作用：从集合中随机取出一个元素。集合本身会被修改，元素被移除。

    my_set = {1, 2, 3}
element = my_set.pop()
print("取出的元素:", element)  # 输出随机元素
print("剩余集合:", my_set)     # 输出剩余集合
（4）清空集合
集合.clear()

my_set = {1, 2, 3}
my_set.clear()
print(my_set)  # 输出 set()
（5）取出两个集合的差集
集合1.difference(集合2)

  • 作用：返回一个新集合，包含 集合1 中有而 集合2 中没有的元素。原集合不会被修改。

    set1 = {1, 2, 3}
set2 = {2, 3, 4}
diff = set1.difference(set2)
print(diff)  # 输出 {1}
（6）消除两个集合的差集
集合1.difference_update(集合2)

  • 作用：在 集合1 中删除与 集合2 相同的元素。集合1 会被修改，集合2 不变。

    set1 = {1, 2, 3}
set2 = {2, 3, 4}
set1.difference_update(set2)
print(set1)  # 输出 {1}
（7）合并两个集合
集合1.union(集合2)

  • 作用：返回一个新集合，包含 集合1 和 集合2 的所有元素。原集合不会被修改。

    set1 = {1, 2, 3}
set2 = {3, 4, 5}
union_set = set1.union(set2)
print(union_set)  # 输出 {1, 2, 3, 4, 5}
（8）统计集合元素数量
len(集合)

my_set = {1, 2, 3}
print(len(my_set))  # 输出 3
（9）遍历集合

  • 方法：使用 for 循环遍历集合中的元素。

    my_set = {1, 2, 3}
for element in my_set:
    print(element)

3. 综合表格总结

编号 操作 说明
1 集合.add(元素) 向集合中添加一个元素
2 集合.remove(元素) 从集合中移除指定元素
3 集合.pop() 随机取出一个元素，集合被修改
4 集合.clear() 清空集合中的所有元素
5 集合1.difference(集合2) 返回一个新集合，包含 集合1 有而 集合2 没有的元素
6 集合1.difference_update(集合2) 在 集合1 中删除与 集合2 相同的元素，集合1 被修改
7 集合1.union(集合2) 返回一个新集合，包含 集合1 和 集合2 的所有元素
8 len(集合) 返回集合中元素的数量

（六） 数据容器：dict（字典、映射）

定义**：字典是一种无序的键值对集合。

字典名 = {键1: 值1, 键2: 值2, ...}

1. 字典的特点

  • 键值对结构：字典中的每个元素是一个键值对（Key: Value）。
  • Key 的唯一性：字典中的 Key 不允许重复，如果重复会覆盖原有的 Value。
  • 无序性：字典中的元素是无序存储的（Python 3.7+ 后字典保持插入顺序）。
  • 可变性：字典可以修改（添加、删除、更新元素）。
  • 支持多种数据类型：
    • Key 可以是任意不可变类型（如数字、字符串、元组等），但不能是可变类型（如列表、字典）。
    • Value 可以是任意类型（包括列表、字典等）。
  • 支持遍历：可以使用 for 循环遍历字典中的 Key 或键值对。

2. 字典的常用操作

（1）新增元素
字典[Key] = Value

my_dict = {"name": "Alice", "age": 25}
my_dict["city"] = "New York"
print(my_dict)  # 输出 {'name': 'Alice', 'age': 25, 'city': 'New York'}
（2）更新元素
字典[Key] = Value

  • 作用：如果 Key 已存在，则更新对应的 Value。

  • 示例：

    my_dict = {"name": "Alice", "age": 25}
my_dict["age"] = 26
print(my_dict)  # 输出 {'name': 'Alice', 'age': 26}
（3）删除元素
字典.pop(Key)

  • 作用：删除指定 Key 的键值对，并返回对应的 Value。

  • 注意：如果 Key 不存在，会抛出 KeyError。

    my_dict = {"name": "Alice", "age": 25}
value = my_dict.pop("age")
print("删除的Value:", value)  # 输出 25
print("删除后:", my_dict)     # 输出 {'name': 'Alice'}
（4）清空字典
字典.clear()

my_dict = {"name": "Alice", "age": 25}
my_dict.clear()
print(my_dict)  # 输出 {}
（5）获取全部 Key
字典.keys()

  • 作用：返回字典中所有 Key 的视图对象。

    my_dict = {"name": "Alice", "age": 25}
keys = my_dict.keys()
print(keys)  # 输出 dict_keys(['name', 'age'])
（6）遍历字典
  • 方法 1：遍历 Key。 
    for key in my_dict.keys():
    print(key)
  • 方法 2：遍历键值对。 
    for key, value in my_dict.items():
    print(f"{key}: {value}")
（7）统计字典元素数量
len(字典)
  • 作用：返回字典中键值对的数量。
  • 示例： 
    my_dict = {"name": "Alice", "age": 25}
print(len(my_dict))  # 输出 2
（8）嵌套字典
  • 定义：字典中的 Value 可以是另一个字典。
  • 示例： 
    students = {
    "Alice": {"age": 25, "city": "New York"},
    "Bob": {"age": 30, "city": "London"}
}
print(students["Alice"]["city"])  # 输出 New York

4. 综合代码示例

# 定义一个字典
my_dict = {"name": "Alice", "age": 25}

# 1. 新增元素
my_dict["city"] = "New York"
print("新增后:", my_dict)  # 输出 {'name': 'Alice', 'age': 25, 'city': 'New York'}

# 2. 更新元素
my_dict["age"] = 26
print("更新后:", my_dict)  # 输出 {'name': 'Alice', 'age': 26, 'city': 'New York'}

# 3. 删除元素
value = my_dict.pop("city")
print("删除的Value:", value)  # 输出 New York
print("删除后:", my_dict)     # 输出 {'name': 'Alice', 'age': 26}

# 4. 清空字典
my_dict.clear()
print("清空后:", my_dict)  # 输出 {}

# 5. 获取全部 Key
my_dict = {"name": "Alice", "age": 25}
keys = my_dict.keys()
print("全部Key:", keys)  # 输出 dict_keys(['name', 'age'])

# 6. 遍历字典
print("遍历字典:")
for key, value in my_dict.items():
    print(f"{key}: {value}")

# 7. 统计元素数量
print("字典长度:", len(my_dict))  # 输出 2

# 8. 嵌套字典
students = {
    "Alice": {"age": 25, "city": "New York"},
    "Bob": {"age": 30, "city": "London"}
}
print("Alice 的城市:", students["Alice"]["city"])  # 输出 New York

（七） 数据容器的通用操作

（1）长度

  • 使用 len() 获取容器中元素的数量。 
    print(len(fruits))  # 输出 3

（2）成员检查

  • 使用 in 检查元素是否在容器中。 
    print("apple" in fruits)  # 输出 True

（3）统计元素

  • len(容器)：统计容器中元素的数量。

    my_list = [1, 2, 3]
print(len(my_list))  # 输出 3

  • max(容器)：返回容器中的最大元素。

    my_list = [1, 2, 3]
print(max(my_list))  # 输出 3

  • min(容器)：返回容器中的最小元素。

    my_list = [1, 2, 3]
print(min(my_list))  # 输出 1

（4）排序

  • sorted(容器, [reverse=True])：对容器进行排序，返回一个新的列表。

  • reverse=True 表示降序排序。

    my_list = [3, 1, 4, 2]
result = sorted(my_list)
print(result)  # 输出 [1, 2, 3, 4]

numbers = [1, 2, 3]
print(sorted(numbers, reverse=True))  # 输出 [3, 2, 1]

（5）类型转换

  • str(容器)：将容器转换为字符串。

    my_list = [1, 2, 3]
result = str(my_list)
print(result)  # 输出 "[1, 2, 3]"

  • set(容器)：将容器转换为集合。

    my_list = [1, 2, 2, 3]
result = set(my_list)
print(result)  # 输出 {1, 2, 3}

  • list(容器)：将容器转换为列表。

    my_tuple = (1, 2, 3)
result = list(my_tuple)
print(result)  # 输出 [1, 2, 3]

  • tuple(容器)：将容器转换为元组。

    my_list = [1, 2, 3]
result = tuple(my_list)
print(result)  # 输出 (1, 2, 3)

（6）遍历容器

  • for 循环：遍历容器中的元素。
    • 对于字典，默认遍历的是 Key。
    my_list = [1, 2, 3]
for item in my_list:
    print(item)

my_dict = {"name": "Alice", "age": 25}
for key in my_dict:
    print(key)

(7) 字符串比较

  • ASCII 码：每个字符都有对应的 ASCII 码值。
  • 字符串比较：基于字符的 ASCII 码值进行比较。
    • 从第一个字符开始逐个比较，直到找到不同的字符。
    • 如果所有字符都相同，则较长的字符串更大。
print("apple" > "banana")  # 输出 False（'a' 的 ASCII 码值 < 'b'）
print("apple" < "apples")  # 输出 True（"apple" 比 "apples" 短）
print("A" < "a")          # 输出 True（大写字母的 ASCII 码值 < 小写字母）
