Urllib基本使用(urlencode\urlretrieve\urlopen\quote)

1urllib.request 发送 HTTP 请求并获取响应

1. 基本用法

1.1 发送请求并获取响应
import urllib.request

# 定义URL
url = 'http://www.baidu.com'

# 发送请求并获取响应对象
response = urllib.request.urlopen(url)
  • urlopen(url)：打开指定的 URL 并返回一个 HTTPResponse 对象。
1.2 获取响应内容
# 读取响应内容并解码为字符串
content = response.read().decode('utf-8')
print(content)
  • read()：读取整个响应内容，返回字节形式的二进制数据。
  • decode('utf-8')：将二进制数据解码为字符串，utf-8 是常见的编码格式。
1.3 读取部分内容
# 读取前10个字节
content = response.read(10)
print(content)
  • read(n)：读取响应内容的前 n 个字节。
1.4 逐行读取
# 读取一行
content1 = response.readline()
print(content1)

# 逐行读取所有内容
content2 = response.readlines()
print(content2)
  • readline()：读取一行内容。
  • readlines()：读取所有行并返回一个列表。

2. 响应对象 (HTTPResponse) 的方法和属性

2.1 获取状态码
print("状态码：", response.getcode())
  • getcode()：返回 HTTP 响应的状态码（如 200 表示成功）。
2.2 获取请求的 URL
print("URL: ", response.geturl())
  • geturl()：返回实际请求的 URL（可能会与原始 URL 不同，例如发生重定向时）。
2.3 获取响应头信息
print("头信息：", response.getheaders())
  • getheaders()：返回一个包含所有响应头信息的列表，每个元素是一个 (header, value) 元组。

3. 总结

  • 一个类型：HTTPResponse，表示 HTTP 响应对象。
  • 六个方法：
    1. read()：读取响应内容。
    2. read(n)：读取前 n 个字节。
    3. readline()：读取一行内容。
    4. readlines()：读取所有行。
    5. getcode()：获取状态码。
    6. geturl()：获取请求的 URL。
    7. getheaders()：获取响应头信息。

4. 下载文件

urllib.request 模块不仅可以用于获取网页内容，还可以用于下载文件，如图片、视频等。以下是下载文件的基本用法。

4.1 下载网页
import urllib.request

# 定义URL
url_page = 'http://www.baidu.com'

# 下载网页并保存为本地文件
urllib.request.urlretrieve(url_page, 'baidu.html')
  • urlretrieve(url, filename)：将指定 URL 的内容下载并保存为本地文件。url 是文件的 URL，filename 是保存文件的路径和名称。
4.2 下载图片和视频
import urllib.request
url_video ='http://vod.v.jstv.com/2025/02/26/JSTV_JSGJ_1740536039794_Im2008l_1563.mp4'
urllib.request.urlretrieve(url_video, 'a.mp4')

2 使用urllib库发送HTTP请求

1. URL结构解析

URL (Uniform Resource Locator) 是用于在网络中定位资源的地址。它通常由以下部分组成：

  • https://www.baidu.com/s?wd=周杰伦
  • 协议：如http或https，用于指定通信协议。
  • 主机：如www.baidu.com，表示目标服务器。
  • 端口号：通常在URL中可以省略，如果使用http协议，默认端口为80，https协议，默认端口为443。
  • 路径：如s，表示资源的路径。
  • 参数：如?wd=周杰伦，表示查询参数。
  • 锚点：如#top，用来标记页面内的位置。

例子：

协议      主机               端口号     路径    参数         锚点
http/https www.baidu.com      80/443    /s    ?wd=周杰伦   #top

2. 发送简单请求

使用urllib.request.urlopen()方法发送一个简单的HTTP GET请求：

url_page = 'https://www.baidu.com'
response = urllib.request.urlopen(url_page)  # 发送请求
content = response.read()  # 读取响应内容
print(content)  # 输出内容
  • urlopen返回一个响应对象，你可以通过调用response.read()方法来读取返回的数据。
  • 返回的数据是字节流，通常需要进一步解码。

3. 添加User-Agent头(反爬1)、添加cookie(反爬2)

有些网站会通过User-Agent来判断请求是否来自真实浏览器，如果发现不是，则会阻止访问。我们可以通过在请求中设置User-Agent头来伪装成浏览器。

headers = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/133.0.0.0 Safari/537.36 Edg/133.0.0.0'
}

4. 定制请求

urllib.request.Request()方法允许你定制HTTP请求，例如设置请求头。你需要将url和headers传递给Request对象，创建一个请求对象。

request = urllib.request.Request(url=url_page, headers=headers)

由于urlopen不能直接传递字典格式的headers，因此需要通过Request对象来封装请求头。

5. 发送带有自定义请求头的请求

使用urllib.request.urlopen()来发送自定义的请求对象。

response = urllib.request.urlopen(request)
content = response.read().decode('utf-8')  # 解码为UTF-8
print(content)
  • response.read()：读取返回的数据。
  • decode('utf-8')：将字节流解码为字符串，通常网页内容是UTF-8编码。

3 使用urllib进行编码、POST请求和JSON处理

1. URL编码与解码

在进行网络请求时，通常需要对URL中的参数进行编码，尤其是中文或特殊字符。urllib.parse.quote()方法可以将字符串编码为URL可用的格式。

  • 编码中文字符：urllib.parse.quote('周杰伦') 会将中文字符转化为Unicode编码。

示例：

name = urllib.parse.quote('周杰伦')
url = 'https://www.baidu.com/s?wd=' + name
print(url)  # 输出： https://www.baidu.com/s?wd=%E5%91%A8%E6%9D%B0%E4%BC%A6

quote编码后的字符可以直接附加到URL中，作为查询参数。

2. GET请求

使用urllib.request.Request()对象可以向指定的URL发送带有请求头的GET请求。

  • 请求头（User-Agent）：模拟浏览器请求，避免被网站识别为爬虫。
  • URL拼接查询参数：将编码后的参数附加到URL的查询部分（?后面）。

示例：

headers = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/133.0.0.0 Safari/537.36 Edg/133.0.0.0'
}
url = 'https://www.baidu.com/s?wd=' + urllib.parse.quote('周杰伦')
request = urllib.request.Request(url=url, headers=headers)
response = urllib.request.urlopen(request)
content = response.read().decode('utf-8')
print(content)

3. URL编码多个参数

urllib.parse.urlencode()方法可以将字典中的键值对转换为URL查询字符串。

示例：

data = {
    'wd': '周杰伦',
    'sex': '男',
    'location': '中国台湾'
}
new_data = urllib.parse.urlencode(data)
url = 'https://www.baidu.com/s?' + new_data
print(url)
  • 输出：https://www.baidu.com/s?wd=%E5%91%A8%E6%9D%B0%E4%BC%A6&sex=%E7%94%B7&location=%E4%B8%AD%E5%9B%BD%E5%8F%B0%E6%B9%BE

4. POST请求

POST请求常用于发送数据到服务器，用于提交表单或提交API请求。与GET请求不同，POST请求的数据放在请求体中，而不是附加在URL后。

  • 数据编码：POST请求的参数必须通过urllib.parse.urlencode()方法编码，并通过.encode('utf-8')将其转换为字节流，以便发送。

示例：

data = {'kw': 'spider'}
data = urllib.parse.urlencode(data).encode('utf-8')

url = 'https://fanyi.baidu.com/sug'
request = urllib.request.Request(url=url, data=data, headers=headers)
response = urllib.request.urlopen(request)
content = response.read().decode('utf-8')

5. JSON解析

在进行API请求时，服务器返回的响应内容往往是JSON格式。可以使用json.loads()方法将JSON字符串转换为Python的字典或列表对象。

示例：

import json
content = '{"word": "spider", "translation": "蜘蛛"}'
obj = json.loads(content)
print(obj)  # 输出： {'word': 'spider', 'translation': '蜘蛛'}

通过json.loads()方法，可以将返回的JSON数据解析成Python对象，便于后续处理。
