第六章 文件和目录管理

列出文件目录 ls

1、ls基本功能:

  • 在同一命令行中可以指定0~n个实参
  • 不给出实参时，列出当前目录下所有文件和目录
  • 实参为文件时，列出文件项
  • 实参为目录时，列出目录下的所有文件项

2、选项-F (Flag)

  • 若列出的是目录，就在名字后面缀以斜线 /
  • 若列出的是可执行文件，就在名字后面缀以星号 *
  • 若列出的是符号连接文件，就在名字后面缀以符号 @
  • 若列出的是普通文件，则名字面后无任何标记

3、ls选项-l: 长格式列表（ll） 例: drwxr-xr-x. 2 bupt2022211264 bupt2022211264 4096 Oct 10 06:11 ch04 -rw-rw-r--. 1 bupt2022211264 bupt2022211264 13892 Oct 10 06:34 index.html

第1列：文件属性 - 普通文件 b 块设备文件(Block) D 目录文件(Dir) c 字符设备文件(Char) L 符号连接文件(Link) p 命名管道文件(Pipe)

文件的访问权限(rwx读权限，写权限，可执行权限) 2-4字符: 文件所有者对文件的访问权限 5-7字符: 同组用户对文件的访问权限 8-10字符:其它用户对文件的访问权限

第2列：文件link数，涉及到此文件的目录项数

第3列，第4列：文件主的名字和组名

第5列: 普通磁盘文件：列出文件大小(字节数) 目录：列出目录表大小，不是目录下文件长度和 符号连接文件：列出符号连接文件自身的长度 字符设备和块设备文件：列出主设备号和次设备号 管道文件：列出管道内的数据长度

第6列：文件最后一次被修改的日期和时间

第7列：文件名 对于符号连接文件，附带列出符号连接文件的内容

4、ls其他选项

  • -h（human-readable），许多其他命令中也有类似选项 以便于人阅读的方式打印数值 (例如：1K 234M 2G)

  • -d (directory)当ls的参数是目录时，不象默认的情况那样列出目录下的文件，而是列出目录自身的信息 ls -l、 ls-ld

  • ls *

  • -a,列出文件名首字符为圆点的文件(默认情况下这些文件不列出，经常会用来保存用户的偏好设置信息或保存某些软件的状态信息)

  • -A (功能与-a相同，除了不列出. 和..)

  • -s (size)列出文件占用的磁盘空间

  • -i (i-node)列出文件的i节点号

文件复制和删除

cp: 拷贝文件

命令的两种格式和功能: cp file1 file2 cp file1 file2 ... filen dir file1，……，filen为文件名，dir为已有目录名

  • 第二种格式中： dir必须已经存在并且是一个目录
  • 第一种格式中： file2不存在，则创建；file2存在且是文件，则覆盖； file2存在且是目录，则按格式二处理

cp:拷贝文件举例

cp backup.d/p*.c 实际执行：cp backup.d/p1.c backup.d/p2.c 结果：backup.d目录下文件p1.c将覆盖掉p2.c

（与Windows的copy backup.d\p*.c执行结果不同,Windows的命令会把这两个备份文件拷贝回当前目录）

UNIX将这两个文件拷贝回当前目录下的正确用法： cp backup.d/p*.c .

mv: 移动文件

格式: mv file1 file2 mv file1 file2 ... filen dir mv dir1 dir2 功能: 同一文件系统内的移动：

  • 移动：如果 dir2 是一个已存在的目录，mv dir1 dir2 会将 dir1 移动到 dir2 目录中。 mv folder1 folder2

  • 重命名：如果 dir2 不存在，mv dir1 dir2 会将 dir1 重命名为 dir2 mv old_directory new_directory

不同文件系统之间的移动： 如果 dir1 和 dir2 位于不同的文件系统上，mv 的行为类似于复制并删除：

复制+删除：mv 会先将 dir1 的所有文件和子目录复制到 dir2 所在的文件系统中，然后删除原始位置的 dir1。因此，移动文件夹的过程会涉及到文件数据的传输，速度较慢，尤其当文件夹很大时。

风险：如果在复制过程中发生错误（如磁盘空间不足），那么 mv 操作可能只会部分完成，dir1 可能部分数据丢失，或者部分数据已成功复制到 dir2。因此，不同文件系统之间的移动相对来说更复杂，可能需要更多注意。

rm: 删除文件

命令格式 :rm file1 file2 ... filen

选项 : -r：递归地(Recursive)删除实参表中的目录，也就是删除一整棵目录树 -i：每删除一个文件前需要操作员确认(Inform) -f：强迫删除(Force)。只读文件也被删除并且无提示

**其它问题 :**正在运行的可执行程序文件不能被删除

1、pwd命令：打印当前工作目录 print working directory

2、cd命令：改变当前工作目录(Change Directory) cd /usr/include cd / (斜线前必须有空格 ) cd .. cd (命令无实参 )

  • 在Windows中，打印当前工作目录
  • 在UNIX中，回到用户的主目录(Home Directory)

3、注意: cd是shell的一个内部命令

创建/删除目录

1、创建目录mkdir 例：mkdir sun/work.d mkdir除创建目录外，系统自动建立文件.与..

选项-p，自动创建路径中不存在的目录,例如： mkdir database/2019/09/04/log

2、删除目录rmdir 例：rmdir sun/work.d 要求被删除的目录除.与..外无其它文件或目录(空目录) 其他命令：rm -r sun/work.d(目录下有文件)

cp: 复制目录

1、cp命令选项–r，递归地复制一个目录 cp -r dir1 dir2 根据dir2是否存在，执行结果有差异：

  • 若dir2不存在，则新建子目录dir2，把dir1下内容拷入dir2下
  • 若dir2已存在，则dir2下新建子目录dir1，把dir1下内容拷入dir2/dir1下

2、选项–v，冗长(verbose)方式 复制目录时实时列出正在复制的文件的名字

cp: 增量拷贝

选项–u，增量拷贝(update)，便于备份目录

  • 根据文件的修改时间戳，只复制源文件比目标文件更新的文件，或者目标文件不存在的情况。

  • 如果 dir1 中的文件已经存在于 dir2，且目标文件的时间戳比源文件更新或相同，那么该文件不会被拷贝。 cp -u dir1/* dir2/ 该命令将 dir1 中比 dir2 中更新的文件复制过去。 好处：避免重复拷贝，提高备份的效率

  • dir1和dir2不慎颠倒位置，不会出现灾难性后果:

    • 在 cp -u 的情况下，如果不小心把源目录 dir1 和目标目录 dir2 的位置颠倒了，不会出现灾难性后果，因为 cp -u 会根据时间戳决定是否执行拷贝。
    • 如果 dir2 的文件比 dir1 中的文件更新，颠倒位置也不会导致文件被错误覆盖，因为增量拷贝会避免把旧的文件覆盖掉新的文件

  • Windows中类似功能的命令XCOPY，选项/D可以用来实现增量拷贝(Date)

cp: 复制目录(举例)

1、复制目录 将目录work.d复制为bak.d 若bak.d不存在，执行：cp -r work.d bak.d 若bak.d已存在，执行：cp -r work.d/* bak.d

2、增量拷贝 将work.d中的内容增量拷贝到备份目录bak.d中 cp -ruv work.d/* bak.d

3、命令touch touch *.[ch]

  • touch 命令会更新文件的修改时间戳为当前时间，但不会改变文件内容。
  • 如果文件不存在，touch 命令会创建一个空的 .c 或 .h 文件

rsync：数据备份工具（增量拷贝工具）

1、rsync功能

  • 远程同步（remote sync）： rsync 可以用于本地或通过网络将文件从一台主机同步到另一台主机。它的常见用途包括备份、文件同步、镜像整个目录树等。 rsync 支持本地到远程、远程到本地、甚至远程到远程的传输方式。

  • 增量传输： rsync 使用一种精巧的增量算法来优化文件传输。 对于一个大文件，它不会将整个文件重新传输，而是将文件分块，并生成每个数据块的哈希值。

远程主机（B）将已有的 big.dat 文件的哈希值发送给源主机（A），A 根据这些哈希值比较两边的文件差异。 只有文件中有更改的块（新增、删除、修改部分）会被传输，大大减少了传输的数据量。

从主机 A 同步 big.dat 到主机 B，使用 rsync 命令可以实现： rsync -avz big.dat user@hostB:/path/to/destination/ -a：归档模式，保留文件属性（权限、时间戳等）。 -v：详细模式，显示详细输出。 -z：压缩传输，减少带宽占用。

目录遍历的命令

find:遍历目录树

1、功能 find命令从指定的查找范围开始，递归地查找子目录，凡满足条件的文件或目录，执行规定的动作

find ver1.d ver2.d -name '*.c' -print 范围：当前目录的子目录ver1.d 和ver2.d 条件：与名字*.c匹配。注:*.c应当用引号括起 动作：把查找到的文件的路径名打印出来

find命令的特点

  • 功能强，选项较多
  • 递归式查找，提供了一种遍历目录树的手段
  • find命令提供的灵活性：在“动作”中可以指定任何命令（也包括用户自己编写的处理程序），使得find成为一个任意处理命令可以借用来进行目录遍历的壳（类似awk对文本的逐行扫描，find对目录森林中的文件和目录逐个扫描）

find关于条件的选项

-name wildcard 文件名与wildcard匹配，注意：

  • 必需的引号
  • 这里的“文件名”仅指路径名的最后一部分
  • 对通配符的解释由find完成

-regex pattern

  • 整个路径名与正则表达式pattern匹配

-type f: 普通文件 d: 目录 l: 符号连接文件 c: 字符设备文件 b: 块设备文件 p: 管道文件

-size ±n[单位] 指定文件大小（大于+，等于，小于-） 单位有c(字符), b(块，512字节), k(1024),M(兆),G（吉），默认为b

-mtime ±n[days] 文件最近修改时间

-newer file 文件最近修改时间比file的还晚

其它条件选项

  • 指定i节点号-inum find /path/to/dir -inum 123456 该命令查找 /path/to/dir 目录下 i 节点号为 123456 的文件

  • 可指定文件主-user，-nouser find /path/to/dir -user username 查找 /path/to/dir 目录下由用户 username 拥有的所有文件

  • 可指定用户组-group，-nogroup find /path/to/dir -group groupname 查找 /path/to/dir 目录下属于用户组 groupname 的所有文件

  • 指定link数-links find /path/to/dir -links 2 查找 /path/to/dir 目录下链接数为 2 的所有文件。

  • 指定路径深度-depth find /path/to/dir -depth -name "*.txt" 该命令将首先查找 /path/to/dir 目录下的所有子目录中的 .txt 文件，然后再处理 /path/to/dir 目录本身 find /path/to/dir -name "*.txt" 该命令将首先查找 /path/to/dir 目录中的所有 .txt 文件，然后再进入子目录查找。

  • 指定文件的访问权限-perm find /path/to/dir -perm 644 查找 /path/to/dir 目录下权限为 644 的所有文件

复合条件 ()“与” –o“或” !“非”

find关于动作的选项

-print 打印查找的文件的路径名

-exec 对查找到的目标执行某一命令 在-exec及随后的分号之间的内容作为一条命令 在这命令的命令参数中，{}代表遍历到的目标文件的路径名

-ok 与-exec类似，只是对查找到符合条件的目标执行一个命令前需要经过操作员确认

find使用举例

1、find . -type d -print 从当前目录开始查找，寻找所有目录，打印路径名 结果：按层次列出当前的目录结构

2、find / -name 'stud*' -type d -print 指定了两个条件：名字与stud*匹配，类型为目录 两个条件逻辑“与”，必须同时符合这两个条件

3、find / -type f -mtime -10 -print 从根目录开始检索最近10天之内曾经修改过的普通磁盘文件（目录不算）

4、find . ! -type d -links +2 -print 从当前目录开始检索link数大于2的非目录文件 条件“非”用！ 注意：!号与-type之间必须保留一空格

5、find ~ -size +100k \( -name core -o -name '*.tmp' \) -print 从主目录开始寻找大于100KB的名叫core或有.tmp后缀 使用了两条件“或” (-o)及组合(圆括号) 不要遗漏了所必需的引号，反斜线和空格，尤其是圆括号前和圆括号后。圆括号是shell的特殊字符

其他写法：

find / -size +100k '(' -name core -o -name \*.tmp ')' -print
find / -size +100k \( -name core -o -name \*.tmp ')' -print

6、find /lib /usr -name 'libc*.so' -exec ls -lh {} \; -exec及随后的分号之间的内容作为一条命令执行 shell中分号有特殊含义，前面加反斜线
{} 是一个占位符，它将被 find 命令找到的每个文件的路径名替换

7、利用find的递归式遍历目录的功能在文件中搜寻字符串 find src -name \*.c -exec grep -n -- --help {} /dev/null \; 在目录src中所有.c文件中查找–help字符串

find src -name \*.c： 该命令从 src 目录开始，查找所有以 .c 结尾的文件。*.c 使用通配符 *，并且加上反斜杠来避免 shell 对 * 的提前展开。

-exec grep -n -- --help {} /dev/null \;： -exec：find 的选项，用于对找到的每个文件执行指定的命令。在这里，执行的命令是 grep。 grep -n：表示搜索文件中包含 –help 字符串的行，并输出行号。 --：这是一个特殊的标记，告诉 grep 后面的 --help 是要搜索的字符串，而不是命令选项。这样可以避免当搜索的字符串以 - 开头时与命令选项混淆。 {}：find 用来代表当前找到的文件，每找到一个 .c 文件，grep 就会在该文件中搜索 –help。 /dev/null：为了保证即使只有一个文件也能输出文件名，/dev/null 是一个空文件，将它加到命令中可以强制 grep 输出文件名。因为当 grep 只处理一个文件时，它默认不会显示文件名。 \;：结束 -exec 子命令。

补充： –（停止选项解析）： – 告诉 grep 停止解析命令选项，后面的内容都被视为纯文本参数而不是选项。

/dev/null（空文件，强制输出文件名）： grep 默认不会在只处理一个文件时输出文件名。为了确保每次搜索时都输出文件名，将 /dev/null 添加到命令中，让 grep 以为它处理了多个文件，这样它就会输出文件名。

批量处理文件

问题

find src -name \*.c -exec grep -n -- --help {} /dev/null \; 缺点：

  • 效率低：每个匹配的 .c 文件都需要启动一个新的进程来执行 grep。这会导致较大的性能开销，因为操作系统需要为每个进程分配资源和管理上下文切换。
  • 创建和销毁进程：由于每次都创建一个新的进程并在任务完成后销毁，会造成大量的进程开销，尤其是在有很多文件的情况下。

grep命令也提供了-r选项，可以递归地搜索子目录下的文件: grep –nr -- --help *.c 这样无法检索，因为那些子目录名字不能被*.c匹配 grep –nr -- --help * 这样可以检索，但是却检索了太多非C源程序的不感兴趣的文件，输出结果被无用的信息淹没。应该使用find精确筛选的功能

利用find与xargs的组合

如果能把find src -name \*.c –print生成的文件名列表追加在grep -n -- --help filelist命令后面就可以了

命令xargs可以用来完成这个工作: find src -name \*.c –print | xargs grep -n -- --help xargs命令把标准输入追加到它的参数列表后面，也就是上述grep的后面，再作为一个命令来执行。这样利用find精确筛选，利用grep批量处理文件，提高效率

xargs：将标准输入组织成命令执行

  • 将标准输入构造为命令的命令行参数
  • 如果标准输入的数据量很大，xargs指定的处理程序会启动多个进程运行，每个进程处理一批，会是几千个参数（命令行参数占满128K字节）
  • 可以使用xargs的-n选项指定每批处理多少个
  • xargs经常与find配合使用，也可以与其它命令组合使用

-0：使用 NULL 字符作为输入项的分隔符，适合处理文件名中包含空格或特殊字符的情况。 -n N：每次最多传递 N 个参数给命令。 -d delimiter：指定自定义的分隔符而不是空格或换行。 -p：在执行命令之前提示用户确认。 -I replace-str：替换字符串，将输入中的每一项替换为命令中的 replace-str 。

xargs: 构造参数列表并运行命令

1、解决shell文件名生成时，因为文件太多，缓冲区空间受限而文件名展开失败的问题 rm -f *.dat 文件名 *.dat展开失败，可以使用下面的命令: ls | grep ".dat$" | xargs rm -f ls：列出当前目录中的所有文件。 grep ".dat$"：筛选出以 .dat 结尾的文件名。 xargs rm -f：将筛选出的文件名传递给 rm -f 命令进行删除。

2、find命中目录名因删除目录导致目录遍历过程遇到麻烦 find . -name CVS –exec rm –rf {} \; 这个命令可能会在删除目录 CVS 后导致 find 继续尝试遍历已删除的目录，可能导致错误。 改为: find . -name CVS -print | xargs rm -rf find . -name CVS -print：查找当前目录及子目录中名为 CVS 的目录，并将找到的路径打印出来。 xargs rm -rf：将找到的路径传递给 rm -rf 命令以递归删除。 这样做的好处是 find 命令不再直接在 -exec 中执行删除，而是先列出所有匹配的目录，避免了因删除目录导致的遍历问题。

打包与压缩

tar：文件归档

1、功能: tar命令最早为顺序访问的磁带机设备而设计的(Tape ARchive，磁带归档)，用于保留和恢复磁带上的文件 归档：将多个文件打包成一个单一的文件（称为归档文件），以便于存储和传输。 备份：可以用于备份文件和目录。 恢复：能够从归档文件中恢复文件和目录。

2、命令语法 tar [ctxv] [f device] [file-list]

3、选项第一字母指定要执行的操作，是必需的 c: Create创建一个新的归档文件。此操作会从头开始写入数据，之前存储在归档中的内容会被覆盖。 tar cvf archive.tar /path/to/files 这条命令将 /path/to/files 中的文件打包到 archive.tar 中

t: Table列表。列出归档文件中的文件名。当不指定具体文件名时，将列出归档中的所有文件。 tar tvf archive.tar 显示 archive.tar 中包含的所有文件的详细信息。

x: eXtract抽取。从归档文件中提取指定的文件。当不指定文件名时，将提取所有文件。 tar xvf archive.tar 从 archive.tar 中提取所有文件到当前目录。

4、除功能字母外的其它选项 : v：Verbose冗长。每处理一个文件，就打印出文件的文件名，并在该名前冠以功能字母 f：File。指定设备文件名 z：采用压缩格式(gzip算法) j：采用压缩格式(bzip2算法)

tar的使用：磁带机操作

  1. 备份当前目录到磁带设备 tar cvf /dev/rct0 . c：创建一个新的归档文件。 v：冗长模式，显示正在处理的文件名。 f /dev/rct0：指定归档文件为 /dev/rct0，这是一个指向磁带设备的特殊文件。 .：圆点表示当前目录树。 命令会备份当前目录及其所有子目录和文件。

  2. 查看磁带设备上的文件目录 tar tvf /dev/rct0 t：列出归档文件中的内容。 v：冗长模式，显示文件的详细信息。 f /dev/rct0：指定要查看的归档文件为 /dev/rct0。 命令将显示在磁带设备 /dev/rct0 上备份的文件列表，包括文件名、大小、权限等信息。

  3. 从磁带设备恢复文件 tar xvf /dev/rct0 x：提取归档中的文件。 v：冗长模式，显示正在提取的文件名。 f /dev/rct0：指定要恢复的归档文件为 /dev/rct0。 这个命令将从磁带设备 /dev/rct0 中提取所有文件，并将其恢复到当前工作目录中。

tar的使用：文件打包

tar cvf my.tar *.[ch] makefile c：创建一个新的归档文件。 v：冗长模式，显示正在处理的文件名。 f my.tar：指定归档文件名为 my.tar。 *.[ch] makefile：匹配所有以 .c 或 .h 结尾的文件以及 makefile 文件。 这个命令会将当前目录下所有的 .c 和 .h 文件以及 makefile 文件打包到 my.tar 归档文件中。

危险的误操作是: tar cvf *.[ch] makefile 漏掉了功能字母f必需的“设备文件名”，按照shell对文件名的展开规则，会覆盖掉现存的排位第一的文件 *.[ch] 可能会展开为多个文件（例如 a1.c、a2.c 等） 如果第一个展开的文件是 a1.c，tar 将试图将归档写入到 a1.c 中，这可能导致 a1.c 被覆盖，从而造成数据丢失

tar的使用：目录打包

1、tar cvf work.tar work 将目录 work 及其所有子目录和文件打包到 work.tar 归档文件中

2、tar cvzf work.tar.gz work z：使用 gzip 压缩归档文件。 f work.tar.gz：指定归档文件名为 work.tar.gz。 将目录 work 及其内容打包并使用 gzip 压缩，生成的文件 work.tar.gz 的大小为原来体积的约 20%

3、tar cvjf work.tar.bz2 work j：使用 bzip2 压缩归档文件。 f work.tar.bz2：指定归档文件名为 work.tar.bz2。 将目录 work 打包并使用 bzip2 压缩，生成的文件 work.tar.bz2 的大小约为原来的 17%，但执行时间比 gzip 压缩慢三倍

4、查看归档文件中的文件目录 tar tvf work.tar.gz 这个命令将显示 work.tar.gz 中包含的所有文件和子目录的列表。

5、从归档文件中恢复目录树 tar xvf work.tar.gz 这个命令将从 work.tar.gz 中提取所有文件和目录，并恢复到当前工作目录中。

6、文件名后缀的注意事项 文件名后缀如 .tar、.tar.gz、.tar.bz2 只是约定俗成的惯例，并不是系统级的强制要求。这意味着归档文件可以使用任何名称，但遵循这些惯例可以帮助用户更容易地识别文件类型

文件压缩和解压缩

1、gzip/gunzip (执行速度快) gzip： 速度：执行速度较快，适合需要快速压缩和解压缩的场合。 压缩率：虽然速度快，但压缩比率相对较低，通常会比 bzip2 产生更大的压缩文件。 文件扩展名：压缩后的文件通常使用 .gz 扩展名。 gunzip： 功能：用于解压缩 .gz 文件。

2、bzip2/bunzip2 (占用较多的CPU时间) bzip2： 速度：压缩速度较慢，特别是相较于 gzip，但它能提供更好的压缩率。 压缩率：通常比 gzip 产生更小的文件，适合对压缩效果有较高要求的场合。 CPU 占用：由于压缩算法复杂，bzip2 通常会占用更多的 CPU 时间。 文件扩展名：压缩后的文件通常使用 .bz2 扩展名。

bunzip2： 功能：用于解压缩 .bz2 文件。

补充

归档：将多个文件合并为一个文件，不改变文件内容的大小，主要用于文件管理和传输。

压缩：通过算法减少文件的大小，主要用于节省空间和加快传输速度。

在实际应用中，归档和压缩通常结合使用，以便既能方便地管理多个文件，也能减小文件的存储大小。例如，使用 tar 命令归档多个文件后，再用 gzip 或 bzip2 对归档文件进行压缩： tar cvzf archive.tar.gz directory/ 归档过程：首先，tar 会将指定的 directory/ 目录及其内容打包到一个临时的归档文件中（未压缩）。 压缩过程：然后，在创建了这个归档文件后，tar 使用 gzip 算法对这个归档文件进行压缩，生成最终的 archive.tar.gz 文件。 c：表示创建一个新的归档文件（Create）。 v：表示冗长模式（Verbose），显示正在处理的文件名。 z：表示使用 gzip 压缩归档文件（Compress）。 f：表示接下来指定的是归档文件的名称（File）。
