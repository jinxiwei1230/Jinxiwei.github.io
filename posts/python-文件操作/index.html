Python文件操作

（一）编码

1. 编码的概念

  • 定义：编码是一种将 可识别内容（如文字、符号等）转换为 二进制数据 的规则，同时也定义了如何将二进制数据转换回可识别内容。
  • 作用：
    • 存储：将人类可读的内容转换为计算机可存储的二进制数据。
    • 传输：在网络传输中，编码确保数据能够正确传递和解析。
    • 显示：将二进制数据转换回人类可读的内容。

2. 常见编码

（1）UTF-8

  • 是一种 可变长度 的 Unicode 编码。
  • 支持全球所有语言的字符。
  • 兼容 ASCII 编码。
（2）GBK
  • 是一种针对 中文 的编码。
  • 支持简体中文和繁体中文。

（3）Big5

  • 是一种针对 繁体中文 的编码。
  • 主要用于台湾、香港等地区。

3. 编码与解码

（1）编码（Encode）

  • 作用：将字符串转换为二进制数据。

    字符串.encode(编码格式)

    text = "我喜欢你"
binary_data = text.encode("UTF-8")
print(binary_data)  # 输出 b'\xe6\x88\x91\xe5\x96\x9c\xe6\xac\xa2\xe4\xbd\xa0'
（2）解码（Decode）

  • 作用：将二进制数据转换为字符串。

    二进制数据.decode(编码格式)

    binary_data = b'\xe6\x88\x91\xe5\x96\x9c\xe6\xac\xa2\xe4\xbd\xa0'
text = binary_data.decode("UTF-8")
print(text)  # 输出 "我喜欢你"

4. 编码错误的处理

  • 常见错误：
    • UnicodeEncodeError：编码时无法将字符转换为指定编码。
    • UnicodeDecodeError：解码时无法将二进制数据转换为指定编码的字符。
  • 解决方法：
    • 使用 errors 参数指定错误处理方式。
      • ignore：忽略无法编码/解码的字符。
      • replace：用替代字符（如 ?）替换无法编码/解码的字符。

（二）文件操作

1. 打开文件

open(file, mode, encoding)

  • file：文件路径（字符串类型）。

  • mode：文件打开模式（字符串类型）。

  • encoding：文件编码格式（推荐使用 UTF-8）。

  • 常用模式：

    模式 描述
    r 以只读方式打开文件，文件指针在开头（默认模式）。
    w 以写入方式打开文件。如果文件存在，清空内容；如果文件不存在，创建新文件。
    a 以追加方式打开文件。如果文件存在，新内容写入到文件末尾；如果文件不存在，创建新文件。
    b 以二进制模式打开文件（如 rb、wb）。

  • 示例：

    f = open("python.txt", "r", encoding="UTF-8")

2. 读取文件

（1）read() 方法

  • 作用：读取文件中指定长度的内容（以字节为单位），如果不指定长度，则读取全部内容。

    文件对象.read(num)

    f = open("python.txt", "r", encoding="UTF-8")
content = f.read()  # 读取全部内容
print(content)
f.close()

（2）readline() 方法

  • 作用：一次读取一行内容。

    文件对象.readline()

    f = open("python.txt", "r", encoding="UTF-8")
line = f.readline()  # 读取一行
print(line)
f.close()

（3）readlines() 方法

  • 作用：读取文件中的所有行，并返回一个列表，每行内容为列表中的一个元素。

    文件对象.readlines()

    f = open("python.txt", "r", encoding="UTF-8")
lines = f.readlines()  # 读取所有行
print(lines)
f.close()

（4）for 循环读取文件

  • 作用：逐行读取文件内容。

    for line in 文件对象:
    print(line)

    f = open("python.txt", "r", encoding="UTF-8")
for line in f:
    print(line)
f.close()

3. 关闭文件

  • 作用：释放文件资源，避免文件被一直占用。

    文件对象.close()

    f = open("python.txt", "r", encoding="UTF-8")
content = f.read()
f.close()

4. with open 语法

  • 作用：自动管理文件的打开和关闭，避免忘记关闭文件。

    with open(file, mode, encoding) as 文件对象:
    操作文件

    with open("python.txt", "r", encoding="UTF-8") as f:
    content = f.read()
    print(content)
