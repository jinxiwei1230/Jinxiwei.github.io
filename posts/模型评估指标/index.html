1. 混淆矩阵（Confusion Matrix）

混淆矩阵是分类任务的基础，用于计算以下核心值：

预测为正例 (1) 预测为负例 (0)
实际为正例 (1) True Positive (TP) False Negative (FN)
实际为负例 (0) False Positive (FP) True Negative (TN)
  • TP（True Positive）：模型正确预测为正例的样本数（真实为机器人，预测为机器人）。
  • TN（True Negative）：模型正确预测为负例的样本数（真实为人类，预测为人类）。
  • FP（False Positive）：模型错误预测为正例的样本数（真实为人类，预测为机器人）。
  • FN（False Negative）：模型错误预测为负例的样本数（真实为机器人，预测为人类）。

2. 常用评估指标

(1) 基于混淆矩阵的指标

指标 公式 解释
准确率 (Accuracy) ( \frac{TP + TN}{TP + TN + FP + FN} ) 所有预测正确的比例，对不平衡数据不敏感。
精确率 (Precision) ( \frac{TP}{TP + FP} ) 预测为正例的样本中实际为正例的比例（避免误杀人类用户）。
召回率 (Recall) ( \frac{TP}{TP + FN} ) 实际为正例的样本中预测为正例的比例（避免漏检机器人）。
F1-Score ( 2 \times \frac{Precision \times Recall}{Precision + Recall} ) 精确率和召回率的调和平均，平衡两者关系。
特异度 (Specificity) ( \frac{TN}{TN + FP} ) 实际为负例的样本中预测为负例的比例（人类用户不被误判的能力）。

(2) 类似AUC的阈值无关指标

指标 解释
AUC-ROC ROC曲线下面积，反映模型在不同阈值下区分正负例的能力（范围0.5~1）。
AUC-PR 精确率-召回率曲线下面积，适用于高度不平衡数据（正例极少时更敏感）。
KS统计量 正负例累积分布的最大差异，值越大模型区分能力越强（范围0~1）。

(3) 其他重要指标

指标 公式/解释
G-Mean ( \sqrt{Recall \times Specificity} )，平衡正负例的检测能力。
MCC (Matthews Correlation Coefficient) ( \frac{TP \times TN - FP \times FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}} )，范围-1~1，综合衡量分类质量。
Log Loss 基于概率的损失函数，值越小模型校准越好（对概率预测敏感）。

3. 不同场景下的指标选择

(1) 平衡数据

  • 优先指标：Accuracy、F1-Score、AUC-ROC。
  • 示例：正负样本比例接近1:1时，Accuracy可直接反映模型性能。

(2) 不平衡数据（如机器人检测）

  • 优先指标：AUC-ROC、AUC-PR、Recall、F1-Score。
  • 原因：避免模型偏向多数类（人类用户），需关注少数类（机器人）的检测能力。
    • 高Recall：确保尽可能捕获更多机器人（减少FN）。
    • 高Precision：减少人类用户被误判为机器人（减少FP）。

(3) 概率预测任务

  • 优先指标：Log Loss、AUC-ROC、Brier Score。
  • 示例：预测用户是机器人的概率时，需评估概率的校准性。

4. 可视化工具辅助分析

  • ROC曲线：横轴为FPR（( \frac{FP}{FP + TN} )），纵轴为TPR（Recall），曲线越靠近左上角性能越好。
  • PR曲线：横轴为Recall，纵轴为Precision，正例极少时曲线下面积（AUC-PR）比AUC-ROC更敏感。

5. 总结

  • 核心四元组：TP、TN、FP、FN 是计算所有指标的基础。
  • AUC类似指标：AUC-ROC、AUC-PR、KS统计量等，关注模型整体排序能力。
  • 业务导向：
    • 若容忍少量误杀（FP），优先优化Recall；
    • 若需高精度（如法律场景），优先优化Precision。

通过组合这些指标，可以全面评估模型在不同方面的性能，避免单一指标的局限性。
