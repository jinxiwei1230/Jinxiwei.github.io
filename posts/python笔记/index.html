python笔记

一、python基础

  1. torch：这是 PyTorch 的主包，PyTorch 是一个由 Meta AI 等开发的开源机器学习框架。它提供了强大的工具用于张量（tensor）计算（类似于 NumPy，但支持 GPU 加速）以及构建和训练神经网络。
  2. torch.nn：这是 PyTorch 的一个子模块，专门用于构建神经网络。它包含了构建神经网络所需的组件，比如层（layers）、激活函数、损失函数等。
  3. init 是 Python 类中的构造函数，在创建类的实例时会自动调用。它用于初始化对象的属性。
    • 方法内部通过 self.d_model = d_model 和 self.vocab_size = vocab_size 将这两个参数保存为类的属性，供后续使用。
  4. super() 是 Python 用来调用父类方法的一个内置函数。

二、forward函数特点

1. 共同点：forward 方法的功能

所有继承自 nn.Module 的类的 forward 方法都有以下相似之处：

  • 定义前向传播逻辑：

    • forward 方法指定了输入数据如何通过该模块进行变换，生成输出。
    • 无论是简单的层（如 nn.Linear、nn.Embedding）还是复杂的模型（如 Transformer 或 CNN），forward 方法都描述了从输入到输出的计算流程。
    • 例如：
      • 在 nn.Embedding 中，forward 将 token 索引转换为嵌入向量。
      • 在 nn.Linear 中，forward 执行线性变换（y = xW^T + b）。
      • 在 Transformer 中，forward 可能包含多层注意力机制和前馈网络的计算。

  • 输入和输出的张量处理：

    • forward 方法通常接受 PyTorch 张量（torch.Tensor）作为输入，并返回张量作为输出。
    • 不同类的 forward 方法处理输入张量的形状和语义可能不同，但它们都遵循张量运算的规则，确保计算结果可以继续传递到后续层。

  • 与 nn.Module 的 __call__ 机制集成：

    • 在 PyTorch 中，直接调用模块实例（如 model(x)）会触发 nn.Module 的 __call__ 方法，而 __call__ 会调用 forward 方法。
    • 这意味着所有类的 forward 方法都通过相同的调用机制（__call__）被触发，确保一致性和模块化。

  • 支持自动求导：

    • forward 方法中的操作通常是可微分的，PyTorch 会自动跟踪这些操作以构建计算图，用于后续的反向传播和梯度计算。
    • 无论是简单的矩阵乘法还是复杂的注意力机制，forward 方法的计算都兼容 PyTorch 的自动求导系统（autograd）。
2. 设计上的相似之处

  • 模块化的输入-输出接口：

    • forward 方法通常被设计为一个清晰的输入-输出接口，输入是张量（或一组张量），输出是经过变换的张量。
    • 例如：
      • nn.Embedding.forward(x)：输入 token 索引张量，输出嵌入向量张量。
      • nn.Conv2d.forward(x)：输入图像张量，输出卷积特征张量。
      • 这种设计使得不同模块可以像积木一样堆叠，构建复杂的神经网络。

  • 参数化计算：

    • forward 方法通常使用模块的属性（例如权重、偏置等）进行计算。这些属性（如 self.weight）是在 __init__ 中定义并注册为 nn.Parameter 的。
    • 例如：
      • 在 nn.Linear 中，forward 使用 self.weight 和 self.bias 进行线性变换。
      • 在 nn.Embedding 中，forward 使用 self.weight 进行嵌入查找。
      • 这种参数化设计是所有 nn.Module 子类的共同点。

  • 灵活的参数签名：

    • forward 方法的输入参数可以根据模块的需求灵活定义。例如：
      • nn.Linear.forward(x) 只接受一个输入张量 x。
      • Transformer 的 forward 方法可能接受多个参数（如 input_ids, attention_mask 等）。
      • 尽管参数不同，但 forward 方法的目标始终是将输入转换为输出。
3. 代码模式的相似之处

  • 结构简单：

    • forward 方法通常专注于计算逻辑，避免复杂的控制流（如循环或条件判断），以保持计算图的简洁和高效。
    • 例如： 
      # nn.Linear 的 forward 方法（简化版）
def forward(self, x):
    return torch.matmul(x, self.weight.t()) + self.bias

      # nn.Embedding 的 forward 方法（简化版）
def forward(self, x):
    return torch.nn.functional.embedding(x, self.weight)

  • 依赖模块属性：

    • forward 方法通常通过 self 访问模块的属性（如 self.weight、self.embedding）来执行计算。
    • 例如，在你的 InputEmbeddings 类中： 
      def forward(self, x):
    return self.embedding(x) * math.sqrt(self.d_model)
      这里 self.embedding 和 self.d_model 都是在 __init__ 中定义的属性。

  • 组合子模块：

    • 在复杂模型中，forward 方法会调用其他子模块的 forward 方法。例如，Transformer 的 forward 方法可能调用嵌入层、注意力层和前馈层的 forward 方法。
    • 这种组合性是 PyTorch 模块化的核心，forward 方法通过调用子模块的 forward 方法实现层次化的计算。
4. 不同类的 forward 方法的差异

虽然 forward 方法有很多相似之处，但不同类的 forward 方法在以下方面可能不同：

  • 输入输出的语义：
    • 例如，nn.Embedding 的 forward 将索引映射为向量，而 nn.Conv2d 的 forward 执行卷积操作。
  • 计算复杂度：
    • 简单层（如 nn.Linear）的 forward 方法可能只有一行矩阵运算，而复杂模型（如 Transformer）的 forward 方法可能包含多层计算和注意力机制。
  • 参数数量：
    • 不同模块的 forward 方法接受的参数数量和类型不同。例如，nn.Linear 只需要一个输入张量，而 Transformer 可能需要 input_ids、attention_mask 等多个参数。

尽管如此，这些差异并不影响 forward 方法的核心功能：定义前向传播的计算逻辑。

三、unsqueeze

1. 什么是 .unsqueeze(dim)？
  • .unsqueeze(dim) 是 PyTorch 中的一个方法，用于在指定维度 dim 上插入一个新的维度，大小为 1。
  • 作用：改变张量的形状（shape），通常用于实现广播（broadcasting），让张量在数学运算（如加法、乘法）中与另一个张量对齐。
  • 关键点：
    • dim 是维度索引，从 0 开始，负数从末尾计数（-1 表示最后一维）。
    • 插入的维度大小为 1，不会改变张量的实际数据，只是扩展形状。
2. 简单例子：从 1D 张量开始
# 创建一个 1D 张量，形状 (3,)
x = torch.tensor([1, 2, 3])
print("原始 x:", x)
print("原始形状:", x.shape)

# 在第 0 维插入一个维度
x0 = x.unsqueeze(0)
print("unsqueeze(0) 后:", x0)
print("新形状:", x0.shape)

# 在第 1 维插入一个维度
x1 = x.unsqueeze(1)
print("unsqueeze(1) 后:", x1)
print("新形状:", x1.shape)

运行结果：

原始 x: tensor([1, 2, 3])
原始形状: torch.Size([3])
unsqueeze(0) 后: tensor([[1, 2, 3]])
新形状: torch.Size([1, 3])
unsqueeze(1) 后: tensor([[1],
                        [2],
                        [3]])
新形状: torch.Size([3, 1])
  • 解释：
    • 原始 x 是 1D 张量，形状 (3,)，表示 3 个元素。
    • .unsqueeze(0)：在第 0 维（最外层）插入一个大小为 1 的维度，相当于把 x 变成一个“行向量”，形状变为 (1, 3)。可以想象成加了一层“batch 维度”。
    • .unsqueeze(1)：在第 1 维（列方向）插入一个大小为 1 的维度，相当于把 x 变成一个“列向量”，形状变为 (3, 1)。可以想象成每个元素变成独立的一行。
    • 可视化：
      • 原始：[1, 2, 3]（一维数组）。
      • 后：[[1, 2, 3]]（一行三列）或 [[1], [2], [3]]（三行一列）。
3. 中级例子：2D 张量
# 创建一个 2D 张量，形状 (2, 3)
x = torch.tensor([[1, 2, 3],
                  [4, 5, 6]])
print("原始 x:", x)
print("原始形状:", x.shape)

# 在第 0 维插入
x0 = x.unsqueeze(0)
print("unsqueeze(0) 后:", x0)
print("新形状:", x0.shape)

# 在第 1 维插入
x1 = x.unsqueeze(1)
print("unsqueeze(1) 后:", x1)
print("新形状:", x1.shape)

# 在第 2 维插入
x2 = x.unsqueeze(2)
print("unsqueeze(2) 后:", x2)
print("新形状:", x2.shape)

运行结果：

原始 x: tensor([[1, 2, 3],
                [4, 5, 6]])
原始形状: torch.Size([2, 3])
unsqueeze(0) 后: tensor([[[1, 2, 3],
                          [4, 5, 6]]])
新形状: torch.Size([1, 2, 3])
unsqueeze(1) 后: tensor([[[1, 2, 3]],
                         [[4, 5, 6]]])
新形状: torch.Size([2, 1, 3])
unsqueeze(2) 后: tensor([[[1, 2, 3]],
                         [[4, 5, 6]]])
新形状: torch.Size([2, 3, 1])
  • 解释：
    • 原始 x 是 (2, 3)，2 行 3 列。
    • .unsqueeze(0)：在第 0 维（batch 维）插入，变成 (1, 2, 3)，就像加了一个“batch 维度”。
    • .unsqueeze(1)：在第 1 维（行方向）插入，变成 (2, 1, 3)，每个矩阵变成一个“列”。
    • .unsqueeze(2)：在第 2 维（列方向）插入，变成 (2, 3, 1)，每个元素变成一个“深度”。
    • 可视化：
      • 原始：2x3 矩阵。
      • 后：像在不同维度上“挤”出一个单元素维度。

四、view

  • view 是 PyTorch 张量的重塑函数，用于改变张量的形状，而不改变数据本身（内存连续性保持）。
  • 输入：query 的形状是 (batch_size, seq_len, d_model)。
  • 输出：query.view(query.shape[0], query.shape[1], self.h, self.d_k) 将其重塑为 (batch_size, seq_len, h, d_k)。
    • query.shape[0]：batch_size（不变）。
    • query.shape[1]：seq_len（不变）。
    • self.h：头数（h）。
    • self.d_k：每个头的维度（d_k = d_model // h）。
  • 为什么能重塑？ 因为总元素数不变：batch_size * seq_len * d_model == batch_size * seq_len * h * d_k（因为 d_model = h * d_k）。
  • 直观理解：想象 d_model 维的向量被“切割”成 h 个 d_k 维的子向量，每个子向量对应一个注意力头。view 就像将一个长向量分成 h 个短向量，并组织成新的维度。
  • 示例：假设 batch_size=1, seq_len=2, d_model=4, h=2, d_k=2。
    • 原始 query：形状 (1, 2, 4)，数据如 [[[1,2,3,4], [5,6,7,8]]]。
    • 经过 view(1, 2, 2, 2)：[[[[1,2],[3,4]], [[5,6],[7,8]]]]。现在第三个维度是 h=2，第四个是 d_k=2。

五、transpose

  • transpose(1, 2) 交换维度 1 和 2。
  • 输入：(batch_size, seq_len, h, d_k)。
  • 输出：(batch_size, h, seq_len, d_k)。
  • 为什么需要 transpose？
    • 在注意力计算中，我们需要对每个头独立计算注意力分数：分数 = (query @ key.T) / sqrt(d_k)。
    • 为了高效批量计算（利用矩阵乘法），我们希望头维度（h）在 batch 之后，便于并行处理所有头。
    • 原始顺序 (batch, seq_len, h, d_k) 不利于矩阵乘法（因为 seq_len 是序列维度，需要作为矩阵的行）。
    • 转置后 (batch, h, seq_len, d_k)：每个头是一个独立的 (seq_len, d_k) 矩阵，便于在所有头和批次上并行计算注意力（使用 torch.bmm 或 @ 操作）。

六、标准训练模式（5步循环）

# 1. 前向传播
output = model(input)  # 模型预测
loss = loss_fn(output, target)  # 计算损失

# 2. 反向传播
loss.backward()  # 计算所有参数的梯度

# 3. 更新权重
optimizer.step()  # 根据梯度更新参数

# 4. 清零梯度
optimizer.zero_grad()  # 清零梯度，准备下一轮

# 5. 记录日志（可选）
writer.add_scalar('loss', loss.item(), step)
完整训练循环
for epoch in range(num_epochs):
    for batch in dataloader:
        # 1. 前向传播
        output = model(batch['input'])
        loss = loss_fn(output, batch['target'])
        
        # 2. 反向传播
        loss.backward()
        
        # 3. 更新权重
        optimizer.step()
        
        # 4. 清零梯度
        optimizer.zero_grad()
        
        # 5. 记录日志
        writer.add_scalar('loss', loss.item(), step)

七、自回归

自回归是一种序列生成范式，核心逻辑是基于已生成的前序元素预测下一个元素，生成过程具有时序依赖性和单向性。在语言模型（含多模态大型语言模型 MLLMs）中，自回归意味着模型生成文本时，每一个新的 token（如单词、子词）都必须依赖于之前已经生成的所有 token 序列。
