numpy 多维数据、矩阵运算

1、数组操作：

  • 创建数组
    • np.array([[1, 2], [3, 4]])
    • np.zeros((3, 3)) # 3x3全0数组
    • np.ones((2, 4), dtype=np.int32) # 2x4全1整型数组
    • np.linspace(0, 10, 5) # [0., 2.5, 5., 7.5, 10.] # 生成等间隔数值的一维数组 。
    • np.arange()：类似Python的range，但返回数组（如np.arange(0, 10, 2)）。
    • np.random.rand()：生成[0,1)均匀分布的随机数组。
    • np.eye()：生成单位矩阵。

  • 数组运算：加减乘除、广播（Broadcasting）、向量化操作。

2、数学函数：

  • 线性代数np.linalg()
    • 矩阵乘法 np.dot()
    • 矩阵分解
      • 矩阵求逆np.linalg.inv()
      • 特征值和特征向量np.linalg.eig()
      • 奇异值分解np.linalg.svd()
    • 解线性方程组np.linalg.solve(A,b)(解Ax=b)
  • 统计计算
    • 基本统计量 np.sum(a), np.mean(a), np.std(a)（标准差）, np.max(a)
    • 轴方向统计 指定axis参数沿特定轴计算（如np.sum(a, axis=0)对列求和）
  • 随机数生成**（np.random）**

    • 分布类型

      • 均匀分布：np.random.rand()
      • 正态分布：np.random.randn()
      • 整数随机：np.random.randint(0, 10, size=5)

    • 随机种子 np.random.seed(42) 保证结果可复现。

3、索引与切片：

  • 基础索引、布尔索引、花式索引（Fancy Indexing）。

pandas 高性能、易用的数据结构和工具

1. 数据结构

(1) Series

  • 定义：一维带标签数组，由**数据值（values）和索引（index）**组成。

  • 特点：

    • 索引可自定义（默认从0开始）。
    • 支持异构数据类型（但推荐同类型以提升性能）。
    import pandas as pd
s = pd.Series([10, 20, 30], index=['a', 'b', 'c'])
print(s['b'])  # 输出: 20

(2) DataFrame

  • 定义：二维表格型数据结构，类似Excel或SQL表，由多个Series组成（每列是一个Series）。

  • 核心属性：

    • df.columns：列名列表。
    • df.index：行索引。
    • df.dtypes：每列数据类型。
    data = {'Name': ['Alice', 'Bob'], 'Age': [25, 30]}
df = pd.DataFrame(data)
print(df.loc[0, 'Name'])  # 输出: Alice

2. 数据操作

(1) 数据清洗

  • 处理缺失值：
    • df.dropna()：删除含缺失值的行/列。
    • df.fillna(value)：填充缺失值（如df.fillna(0)或向前填充df.fillna(method='ffill')）。
  • 去重：
    • df.drop_duplicates()：删除重复行。
    • 保留特定列的唯一组合：df.drop_duplicates(subset=['列名'])。
  • 类型转换：
    • df['列名'].astype(int)：修改列数据类型。

(2) 数据合并

  • 垂直拼接： 
    pd.concat([df1, df2], axis=0)  # 沿行方向拼接
  • 横向拼接： 
    pd.concat([df1, df2], axis=1)  # 沿列方向拼接
  • 数据库风格合并：
    • pd.merge(df1, df2, on='键列')：类似SQL的JOIN。
    • 参数控制：how='inner'（内连接）、how='left'（左连接）。

(3) 分组聚合

  • groupby()： 
    df.groupby('类别列')['数值列'].mean()  # 按类别分组求均值
  • pivot_table()： 
    pd.pivot_table(df, values='销售额', index='地区', columns='月份', aggfunc=np.sum)

3. IO工具（数据读写）

(1) 读取数据

  • CSV文件： 
    df = pd.read_csv('data.csv', encoding='utf-8', sep=',')
  • Excel文件： 
    df = pd.read_excel('data.xlsx', sheet_name='Sheet1')
  • SQL数据库： 
    import sqlite3
conn = sqlite3.connect('database.db')
df = pd.read_sql('SELECT * FROM table', conn)
  • JSON数据： 
    df = pd.read_json('data.json', orient='records')

(2) 写入数据

  • 保存为CSV：df.to_csv('output.csv', index=False)
  • 保存为Excel：df.to_excel('output.xlsx')

4. 时间序列处理

(1) 日期范围生成

  • pd.date_range()： 
    dates = pd.date_range('2023-01-01', periods=5, freq='D')  # 生成5天的日期序列
  • 频率参数freq：
    • 'D'：天，'M'：月末，'H'：小时，'5min'：5分钟。

(2) 重采样（Resampling）

  • 降采样（如日数据→月数据）： 
    df.resample('M').mean()  # 按月求均值
  • 升采样（如日数据→小时数据）： 
    df.resample('H').ffill()  # 向前填充缺失值

(3) 时区处理

  • 转换时区：df.tz_localize('UTC').tz_convert('Asia/Shanghai')

5. 其他实用功能

(1) 条件筛选

  • 布尔索引： 
    df[df['Age'] > 25]  # 筛选年龄大于25的行
  • 多条件组合： 
    df[(df['Age'] > 25) & (df['Gender'] == 'F')]

(2) 排序

  • 按列排序：df.sort_values('Age', ascending=False)

(3) 应用函数

  • apply()：

    df['Name'].apply(lambda x: x.upper())  # 将姓名转为大写

  • 数据对齐：自动按索引/列名对齐数据（避免手动循环）。

  • 高性能：底层基于NumPy，优化了大规模数据操作。

  • 易用性：提供类似SQL的语法，简化数据操作流程。

scipy 高级统计分析

1. 优化算法 (optimize)

  • minimize(): 函数最小化（支持BFGS/Nelder-Mead）
  • curve_fit(): 最小二乘曲线拟合
  • root(): 方程求根

2. 线性代数 (linalg)

  • solve(): 解线性方程组
  • eig()/svd(): 矩阵分解
  • inv()/pinv(): 矩阵求逆

3. 统计分布 (stats)

  • 概率分布：norm, t, binom等
  • 假设检验：ttest_ind, chisquare
  • 描述统计：mode, skew, kurtosis

4. 插值 (interpolate)

  • interp1d: 一维插值
  • griddata: 散点数据网格化

5. 稀疏矩阵 (sparse)

  • csr_matrix: 压缩稀疏行格式
  • spsolve: 稀疏矩阵求解

6. 信号处理 (signal)

  • firwin: 滤波器设计
  • spectrogram: 频谱分析

7. 其他实用工具

  • 积分：quad (一维积分)
  • 图像处理：gaussian_filter
  • 空间算法：KDTree (最近邻搜索)

典型应用

# 曲线拟合
from scipy.optimize import curve_fit
popt, _ = curve_fit(lambda x, a, b: a*x + b, xdata, ydata)

# 假设检验
from scipy.stats import ttest_ind
t, p = ttest_ind(group1, group2)

# 稀疏矩阵运算
from scipy.sparse import csr_matrix
A = csr_matrix((data, (row, col)))

核心优势

  • 科学计算全功能覆盖
  • 高性能数值运算
  • 完美兼容NumPy
  • 工业级算法实现

scikit-learn (sklearn) 机器学习库，提供分类、回归、聚类等算法

1. 监督学习

  • 分类
    • LogisticRegression(): 二分类/多分类
    • SVC(): 支持向量机（可选kernel）
    • RandomForestClassifier(): 随机森林（抗过拟合）
  • 回归
    • LinearRegression(): 线性回归
    • Ridge()/Lasso(): L2/L1正则化

2. 无监督学习

  • 聚类
    • KMeans(): K均值（需指定簇数）
    • DBSCAN(): 基于密度（自动找簇）
  • 降维
    • PCA(): 主成分分析（线性降维）
    • TSNE(): 非线性可视化（慢但直观）

3. 数据预处理

  • 标准化
    • StandardScaler(): 均值0方差1
    • MinMaxScaler(): 缩放到[0,1]
  • 编码
    • OneHotEncoder(): 类别→独热编码
    • LabelEncoder(): 标签→数值

4. 模型评估

  • 交叉验证
    • cross_val_score(): K折验证得分
  • 指标
    • 分类：accuracy_score(), confusion_matrix()
    • 回归：mean_squared_error(), r2_score()

5. 工具

  • 管道
    • Pipeline(): 串联预处理+模型
  • 调参
    • GridSearchCV(): 网格搜索最优参数

经典三行代码

from sklearn.ensemble import RandomForestClassifier
model = RandomForestClassifier(n_estimators=100)  # 1. 选模型
model.fit(X_train, y_train)                       # 2. 训练
score = model.score(X_test, y_test)               # 3. 评估

特点

  • 统一API：所有模型用fit()/predict()
  • 开箱即用：默认参数适合大部分场景
  • 高效：底层C++优化，支持并行

适合：结构化数据快速建模 | 不适合：深度学习/超大数据

Matplotlib 基础绘图库，支持高度定制化图表

1. 基础绘图

  • plt.plot(): 折线图
  • plt.scatter(): 散点图
  • plt.bar(): 柱状图
  • plt.hist(): 直方图
  • plt.pie(): 饼图

2. 图表定制

  • plt.title(): 添加标题
  • plt.xlabel()/plt.ylabel(): 坐标轴标签
  • plt.legend(): 添加图例
  • plt.grid(): 显示网格
  • plt.xlim()/plt.ylim(): 坐标轴范围

3. 多图布局

  • plt.subplots(): 创建多个子图
fig, ax = plt.subplots(2, 2)  # 2x2子图
ax[0,0].plot(x, y)  # 在第一个子图绘制

4. 高级功能

  • plt.style.use(): 使用预设样式
  • plt.savefig(): 保存图像（PNG/PDF等）
  • 3D绘图：
from mpl_toolkits import mplot3d
ax = plt.axes(projection='3d')
ax.plot3D(x, y, z)

5. 典型工作流

import matplotlib.pyplot as plt
plt.figure(figsize=(8,4))       # 1. 创建画布
plt.plot(x, y, label='data')    # 2. 绘制图形
plt.title('Demo')               # 3. 添加标注
plt.legend()                   
plt.savefig('plot.png')         # 4. 保存结果
plt.show()                      # 5. 显示图像

核心优势

  • 全功能2D/3D绘图
  • 高度可定制化
  • 完美兼容NumPy数组
  • 出版级图形输出

以下是 Matplotlib、Seaborn 和 Pyecharts 三个Python可视化库的详细对比分析，从多个维度说明它们的核心区别和适用场景：

1. 基础定位对比

特性 Matplotlib Seaborn Pyecharts
底层依赖 独立实现 基于Matplotlib 基于ECharts (JS)
主要优势 高度定制化 统计可视化 交互式动态图表
输出类型 静态图片 静态图片 动态HTML网页
学习曲线 陡峭 中等 中等

2. 核心功能对比

Matplotlib

  • 优点：
    • 完全自由的图表定制（每个像素可控）
    • 支持复杂的科学图表（如误差棒、矢量图）
    • 成熟的3D绘图支持
  • 缺点：
    • 默认样式不够美观
    • 多图组合代码冗长
    • 无内置交互功能

Seaborn

  • 优点：
    • 一键生成统计图表（箱线图、小提琴图等）
    • 自动计算统计量（如置信区间）
    • 美观的默认样式和调色板
  • 缺点：
    • 底层依赖Matplotlib，高级定制仍需调用Matplotlib API
    • 不适合非统计类图表（如流程图）

Pyecharts

  • 优点：
    • 丰富的交互功能（缩放、拖拽、数据筛选）
    • 开箱即用的中国地图支持（到县级）
    • 动态时间轴和图表联动
  • 缺点：
    • 依赖浏览器环境（无法直接保存为静态图片）
    • 学术论文兼容性较差（需截图使用）

3. 性能与扩展性

维度 Matplotlib Seaborn Pyecharts
大数据量支持 ★★★★☆ (优化后支持百万级数据) ★★☆☆☆ (适合中小数据集) ★★☆☆☆ (万级数据开始卡顿)
多图组合效率 ★★☆☆☆ (需手动布局) ★★★☆☆ (FacetGrid简化) ★★★★☆ (Page()自动排版)
跨平台兼容性 全平台支持 全平台支持 依赖浏览器内核

4. 典型应用场景

选择Matplotlib当：

  • 需要出版级学术图表
  • 绘制复杂组合图形（如插图+子图）
  • 开发自定义图表类型

选择Seaborn当：

  • 快速探索数据集分布
  • 生成统计报告图表
  • 需要美观的默认样式

选择Pyecharts当：

  • 制作网页交互式报表
  • 展示地理空间数据
  • 需要时间轴动画演示

5. 代码风格对比

Matplotlib (命令式)

import matplotlib.pyplot as plt
fig, ax = plt.subplots()
ax.plot(x, y, color='red', linestyle='--')
ax.set_title("Demo")

Seaborn (声明式)

import seaborn as sns
sns.lineplot(x=x, y=y, hue=group, style=group)

Pyecharts (链式调用)

from pyecharts.charts import Line
Line().add_xaxis(x).add_yaxis("系列", y).set_global_opts()

6. 总结决策指南

需求特征 推荐库
“我需要发论文图表” Matplotlib
“我要快速分析数据分布” Seaborn
“老板要看动态大屏” Pyecharts
“既要交互又要印刷质量” Matplotlib+Pyecharts组合使用

组合使用建议：

  • 用Seaborn快速探索数据 → Matplotlib精细调整 → Pyecharts制作最终演示版本
  • 避免在同一个项目中混用多种库（样式冲突风险）
