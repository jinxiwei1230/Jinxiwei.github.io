异常种类

urllib.error.URLError

常见场景：

  • 连接超时（如请求的目标服务器无法访问，网络中断）。
  • DNS 解析错误（例如，URL 域名无法解析到 IP 地址）。
  • 网络连接错误（例如，网络不可达）

urllib.error.HTTPError

HTTPError 是 urllib 模块中的一个子类异常，专门用于处理 HTTP 错误状态码（如 404、500 等）。 常见场景：

  • 请求的资源不存在，返回 404 错误。
  • 请求无法通过认证，返回 401 或 403 错误。
  • 服务器错误，返回 500 错误。

cookie、Referer

1、登录状态（Cookie）：

  • Cookie 是模拟登录状态时至关重要的一部分。爬虫通过获取登录后浏览器中的 Cookie，将其放在请求头中，以模拟已登录的状态。
  • cookie 包含一系列从微博登录后获得的身份信息，如 SCF、SINAGLOBAL、PC_TOKEN 等。 注意：使用 Cookie 时需要确保它是有效的，并且不要泄露敏感信息。

2、防止反爬虫措施：

  • Referer：一些网站通过检查 referer 来判断请求是否来自正常的浏览路径，防止直接访问资源。爬虫在请求头中加入合适的 referer 值可以绕过这种检查。
  • User-Agent：服务器根据请求头中的 User-Agent 判断请求是否来自浏览器。如果 User-Agent 显示是爬虫，服务器可能会阻止请求。为了绕过此问题，可以设置与常见浏览器相符的 User-Agent。

3、爬虫中的常见技巧：

  • 模拟浏览器请求：通过自定义请求头信息，特别是 User-Agent、Referer 和 Cookie，使爬虫看起来像一个正常用户在浏览网页。
  • 处理登录后的数据：当需要登录后获取数据时，确保爬虫能够通过获取到的 Cookie 维持登录状态。
  • 防止被封禁：通过设置适当的请求头信息和延时控制，避免被目标网站封禁 IP。

爬虫 handler

1. 什么是 Handler？

  • Handler 是 urllib 模块中的一个类，负责处理请求中的不同操作（如建立连接、发送请求、接收响应等）。Handler 可以定制请求的处理方式，以便实现不同的需求。
  • 作用：将某些操作（例如 HTTP 请求、代理设置、重定向、认证等）抽象为一个“处理程序”，可以将不同的处理逻辑组合在一起。

2. HTTPHandler 的作用：

  • HTTPHandler 是一个处理 HTTP 请求的 handler 类，它负责处理 HTTP 协议的请求和响应。
  • 它主要处理的操作包括建立 HTTP 连接、发送 HTTP 请求、获取 HTTP 响应等。
  • HTTPHandler 处理的内容相对简单，适用于普通的 HTTP 请求。

示例：

handler = urllib.request.HTTPHandler()

3. opener 对象的作用：

  • opener 是 urllib 中的一个对象，它能够结合一个或多个 handler 对象来处理请求和响应。
  • urllib.request.build_opener(handler) 方法用于创建一个 opener 对象，它将 handler 与请求处理过程结合起来。通过 opener 对象，我们可以发送请求并获取响应。
  • opener 支持多个 handler，可以通过多个 handler 来定制请求的不同处理方式，如代理设置、认证信息等。

示例：

opener = urllib.request.build_opener(handler)

4. 使用 opener.open(request) 来发送请求：

  • 使用 opener.open(request) 发送请求时，opener 会按照 handler 的定义来处理请求。通过 handler 对 HTTP 请求进行处理，最终返回响应数据。
  • 通过 open 方法，你可以发送 HTTP 请求，并获取到服务器的响应。

示例：

response = opener.open(request)

5. 使用 handler 的好处：

  • 定制化请求：使用 handler，你可以更加细粒度地控制请求过程，如设置代理、处理重定向、定制请求头等。
  • 扩展性强：urllib 提供了多种 handler（如 HTTPHandler、ProxyHandler、RedirectHandler、BasicAuthHandler 等），你可以根据需要选择不同的 handler 来处理特定的场景。
  • 更加灵活：可以通过多个 handler 配合使用，构建复杂的请求逻辑。

6. opener 的等价实现：

  • 通过 urllib.request.urlopen(request) 可以实现与使用 handler 和 opener 的相同功能。两者的区别在于：
    • urllib.request.urlopen(request) 是直接发送请求并获取响应的简化方式。
    • 使用 handler 和 opener 则提供了更多定制和扩展的功能，可以灵活添加更多处理逻辑。

7. 代码结构：

import urllib.request

# 设置请求 URL 和头信息
url = 'http://www.baidu.com'
headers = {
    'user-agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/133.0.0.0 Safari/537.36 Edg/133.0.0.0',
}

# 创建请求对象
request = urllib.request.Request(url=url, headers=headers)

# 创建 HTTPHandler 处理请求
handler = urllib.request.HTTPHandler()

# 使用 handler 创建 opener 对象
opener = urllib.request.build_opener(handler)

# 使用 opener 打开请求并获取响应
response = opener.open(request)

# 读取并输出响应内容
content = response.read().decode('utf-8')
print(content)

代理和代理池

1. 代理的基本概念：

  • 代理服务器（Proxy Server）是一个中间服务器，允许客户端通过它访问互联网。使用代理服务器可以隐藏真实的IP地址，避免被目标网站封锁或限制。
  • 在爬虫中，代理通常用于绕过IP限制、进行反爬虫防护、提高匿名性等。

2. 爬虫代理的使用：

  • 在 urllib 爬虫中，可以使用 ProxyHandler 来设置代理。ProxyHandler 负责将请求通过指定的代理服务器发送出去。
  • 通过 urllib.request.build_opener(handler) 创建一个 opener 对象，它会自动使用 ProxyHandler 进行代理设置。

3. ProxyHandler 的使用：

  • ProxyHandler 是一个处理代理设置的 handler。你需要在请求发送之前设置代理，以便将请求通过代理服务器转发。
  • 可以通过 ProxyHandler 设置多个代理（例如 HTTP、HTTPS）用于不同的请求。

代码示例：

# 设置代理池中的某个代理
proxies = {'http': '60.174.0.143:8089'}
handler = urllib.request.ProxyHandler(proxies=proxies)
opener = urllib.request.build_opener(handler)
response = opener.open(request)
content = response.read().decode('utf-8')

4. 代理池的作用：

  • 代理池（Proxy Pool）是多个代理服务器的集合，用于应对请求过程中某些代理被封禁或失效的情况。
  • 在爬虫中，使用代理池可以提高爬取效率，并且减少被封IP的风险。
  • 通过随机从代理池中选择代理，可以更好地避免频繁使用同一个代理而被目标网站封锁。

5. 随机代理选择：

  • 代理池中的代理可能会因为不同原因失效或被封禁。为了增加爬虫的稳定性，可以随机选择代理池中的代理进行请求。
  • 在代码中，使用 random.choice(proxy_pool) 来从代理池中随机选择一个代理。

代码示例：

import random

proxy_pool = [
    {'http': '60.174.0.143:8089'},
    {'http': '120.24.73.25:8118'},
    {'http': '39.98.204.54:7890'},
    {'http': '223.215.176.236:8089'},
]

# 随机选择一个代理
proxies = random.choice(proxy_pool)
print(proxies)

# 创建 ProxyHandler，配置代理
handler = urllib.request.ProxyHandler(proxies=proxies)
opener = urllib.request.build_opener(handler)
response = opener.open(request)
content = response.read().decode('utf-8')

6. 使用代理的流程：

  • 构建请求：首先构建请求对象 (Request)。
  • 设置代理：通过 ProxyHandler 设置代理，并通过 build_opener 创建一个 opener 对象。
  • 发送请求：使用 opener.open(request) 发送请求。
  • 获取响应：通过 response.read().decode('utf-8') 获取返回的 HTML 内容，并将其保存到本地。

7. 代码示例：代理池与代理的结合：

import random
import urllib.request

url = 'https://www.baidu.com/s?wd=ip'
headers = {
    'user-agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/133.0.0.0 Safari/537.36 Edg/133.0.0.0',
}
request = urllib.request.Request(url=url, headers=headers)

proxy_pool = [
    {'http': '60.174.0.143:8089'},
    {'http': '120.24.73.25:8118'},
    {'http': '39.98.204.54:7890'},
    {'http': '223.215.176.236:8089'},
]

# 随机选择代理
proxies = random.choice(proxy_pool)
print(proxies)

# 使用 ProxyHandler 设置代理
handler = urllib.request.ProxyHandler(proxies=proxies)
opener = urllib.request.build_opener(handler)

# 发送请求并获取响应
response = opener.open(request)
content = response.read().decode('utf-8')

# 保存响应内容
with open('daili_pool.html', 'w', encoding='utf-8') as f:
    f.write(content)
