1. 决策树（Decision Tree）

原理：

决策树是一种树形结构的分类或回归模型，通过递归地将数据集划分为更小的子集，最终生成一棵由节点和分支组成的树。每个内部节点表示一个特征上的判断条件，每个分支代表一个可能的判断结果，每个叶节点代表一个类别（分类树）或一个值（回归树）。

  • 核心思想：通过特征选择（如信息增益、基尼系数）找到最佳分割点，逐步构建树结构。
  • 终止条件：达到最大深度、节点样本数过少或纯度足够高时停止分裂。

优点：

  • 易于理解和解释。
  • 能处理数值型和类别型数据。
  • 不需要数据标准化。

缺点：

  • 容易过拟合，泛化能力较差。
  • 对数据扰动敏感，稳定性较低。

2. 随机森林（Random Forest）

原理：

随机森林是一种集成学习方法，通过构建多棵决策树并综合其结果来提高模型的准确性和稳定性。每棵树在训练时使用随机抽样的数据集（Bootstrap采样）和随机选择的特征子集，最终通过投票（分类）或平均（回归）得到最终结果。

  • 核心思想：通过“多样性”降低单棵树的过拟合风险，提升泛化能力。
  • 随机性来源：
    • 数据随机性：Bootstrap采样。
    • 特征随机性：随机选择特征子集。

优点：

  • 抗过拟合能力强，泛化性能好。
  • 能处理高维数据，适合大规模数据集。
  • 能评估特征重要性。

缺点：

  • 训练时间较长，计算成本较高。
  • 模型解释性较差（相对于单棵决策树）。

3. 支持向量机（Support Vector Machine, SVM）

原理：

SVM是一种二分类模型，其目标是找到一个最优超平面，将两类样本分开，并使两类样本到超平面的间隔（Margin）最大化。对于非线性可分的数据，SVM通过核函数将数据映射到高维空间，使其在高维空间中线性可分。

  • 核心思想：最大化间隔，提升模型的泛化能力。
  • 核函数：用于处理非线性问题，常见核函数包括线性核、多项式核、RBF核等。

优点：

  • 在高维空间中表现优异。
  • 对小样本数据集效果好。
  • 通过核函数能处理非线性问题。

缺点：

  • 对大规模数据集训练时间较长。
  • 对参数（如核函数、正则化参数）敏感，调参复杂。
  • 模型解释性较差。

联系与区别

联系：

  1. 目标一致：三者都用于分类或回归任务。
  2. 非线性能力：都能处理非线性问题（决策树通过分裂规则，随机森林通过集成，SVM通过核函数）。
  3. 特征重要性：决策树和随机森林能直接评估特征重要性，SVM可通过权重间接分析。

区别：

维度 决策树 随机森林 支持向量机（SVM）
模型类型 单一模型 集成模型（多棵决策树） 单一模型
核心思想 递归划分数据集 通过多样性降低过拟合 最大化间隔
随机性 无 数据和特征的随机性 无
过拟合风险 高 低 中等
计算复杂度 低 高 高（尤其在大规模数据集上）
解释性 高 中等 低
适用场景 小数据集、需要解释性的场景 大规模数据集、高维数据 小样本、高维数据、非线性问题

总结

  • 决策树：简单直观，适合小数据集和需要解释性的场景，但容易过拟合。
  • 随机森林：通过集成提升泛化能力，适合大规模数据集和高维数据，但计算成本较高。
  • 支持向量机：适合小样本和高维数据，尤其擅长处理非线性问题，但对参数敏感且计算复杂度高。

根据具体任务需求和数据特点，可以选择合适的算法或结合多种方法（如随机森林+SVM）以提升模型性能。

3、Training: 1. Function with Unknown Parameters ( y = b + w x_1 )

2. Define Loss from Training Data ( L = \frac{1}{N} \sum_{n} e_n ) ( e_n = (y_n - \hat{y}_n)^2 )

3. Optimization

  • 初始化参数：随机选择 ( w^0 ) 和 ( b^0 ) 作为初始值，分别表示权重 ( w ) 和偏置 ( b ) 的起始点。

  • 定义目标：寻找 ( w^, b^ = \arg \min_{w, b} L )，其中 ( w^* ) 和 ( b^* ) 是使损失函数 ( L ) 达到最小的参数值。

  • 计算梯度：

    • 在当前 ( w = w^0 ) 和 ( b = b^0 ) 下，计算损失函数对 ( w ) 和 ( b ) 的偏导数： [ \frac{\partial L}{\partial w} \Big|{w = w^0, b = b^0} \quad \text{和} \quad \frac{\partial L}{\partial b} \Big|{w = w^0, b = b^0}。 ]

  1. 更新参数：

    • 使用学习率 ( \eta ) 调整 ( w ) 和 ( b ) 的值： [ w^1 \leftarrow w^0 - \eta \frac{\partial L}{\partial w} \Big|{w = w^0, b = b^0} ] [ b^1 \leftarrow b^0 - \eta \frac{\partial L}{\partial b} \Big|{w = w^0, b = b^0} ]
    • 这里 ( w^1 ) 和 ( b^1 ) 是更新后的 ( w ) 和 ( b ) 值。

  2. 迭代：用新的 ( w^1 ) 和 ( b^1 ) 代替原来的 ( w^0 ) 和 ( b^0 )，重复以上步骤，直到达到收敛（即损失函数变化足够小）或达到最大迭代次数。

通过这个过程，参数 ( w ) 和 ( b ) 会逐步趋向使损失函数 ( L ) 最小的值，从而提高模型的预测能力。
