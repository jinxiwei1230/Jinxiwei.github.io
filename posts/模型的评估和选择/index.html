测试集和训练集

经验误差与泛化误差

1、就分类问题而言，通常把分类错误的样本数占样本总数的比例称为错误率.

2、对于回归问题，把学习器的实际预测输出与样本的真实标值之间的差异称为误差.

3、如果以训练集样本数据为测量参考，模型在训练集上的误差称为“训练误差”（training error）或者“经验误差”（empirical error）.

4、在测试集上的误差称为“测试误差”（testing error），在新样本上的误差称为“泛化误差”（generalization error）

过拟合和欠拟合

1、在机器学习中太多反映训练样本个性化属性而导致普遍规律受重视不够 引起的，使模型泛化误差大于测试误差的现象称为“过拟合”（overfitting）。 （1）有噪声的数据导致过拟合 （2）训练数据量过少（有限的训练数据）导致过拟合 （3）过于复杂的模型导致过拟合

常用的处理过拟合的一些方法

  • early stopping：当训练精度不再增加的时候停止迭代。
  • 数据集扩增：通过扩充数据集，让训练集中的噪音数据占比越来越小。
  • 正则化：限制模型的复杂度
  • Dropout：
    • 每个训练的batch,随机（依概率p）让一些隐层的节点不工作， 来进行训练（进行参数调整）
    • 测试的时候使用全部网络， 但是权值上乘以概率p（否则预测值会有所扩张）
  • 挑选合适的模型

2、欠拟合是由于模型不能全面反映样本“普遍规律”造成的。训练误差和测试误差、泛化误差都很大。 欠拟合的主要原因是模型不能很好的捕捉数据特征 常用的处理欠拟合的一些方法

  • 添加其他特征项，特征组合、多项式特征等
  • 减少正则化参数
  • 增加模型复杂性

测试样本数据获取方法

方法1：留出法 (Hold-out)

  1. 数据划分：

    • 将数据集 ( D ) 划分为两个互斥的集合：训练集 ( S ) 和测试集 ( T )，即 ( D = S \cup T ) 且 ( S \cap T = \emptyset )。
    • ( S ) 用于训练模型，( T ) 用于评估模型的测试误差。

  2. 保持数据分布一致性：

    • 在划分数据时，保持数据的分布尽可能一致。在分类任务中，尤其要确保每个类别的样本在训练集和测试集中的比例相似。这种方法被称为 分层采样 (Stratified Sampling)。
    • 例如，在 MNIST 数据集上，如果每个数字类别的样本数占总数的 10%，那么训练集和测试集中的每个数字的比例也应该尽量保持 10%。

  3. 多次划分：

    • 通常进行多次随机划分，取评估结果的平均值，以减少偶然性影响。

  4. 选择比例：

    • 常用 2/3 到 4/5 数据作为训练集，剩余作为测试集。测试集过小可能导致不稳定，过大则影响评估的保真性。

方法2：m折交叉验证 (m-fold Cross Validation)

  1. 数据划分：

    • 将数据集 ( D ) 划分为 ( m ) 个大小相似的互斥子集：( D = D^{(1)} \cup D^{(2)} \cup \cdots \cup D^{(m)} )，其中 ( D^{(i)} \cap D^{(j)} = \emptyset ) 且 ( i \neq j )。
    • 每个子集 ( D^{(i)} ) 应尽可能保持数据的分布一致性，通常通过分层采样进行划分。

  2. 训练和测试：

    • 交叉验证的基本步骤是，每次将 ( m-1 ) 个子集的并集作为训练集，剩下的那个子集作为测试集。
    • 这样可以进行 ( m ) 次训练和测试，每一次的训练集和测试集都不同。

  3. 评估：

    • 最终，将 ( m ) 次测试结果的平均值作为模型的评估值。通过这种方式，可以更可靠地估计模型在新数据上的表现，避免了由于划分数据集不同导致的偶然性偏差。

方法3：自助法 (Bootstrap)

自助法 (Bootstrap) 是一种通过 有放回采样 从原始数据集生成多个训练集的方法。具体步骤如下：

  1. 数据采样：从数据集 (D) 中随机选取样本，重复此过程直到得到一个新的数据集 (D’)，每个样本可以多次出现在 (D’) 中，也可以不出现。
  2. 测试集：未被选中的样本（大约 36.8%）构成测试集。
  3. 优点：
    • 适用于小数据集。
    • 能生成多个训练集，支持集成学习。
  4. 缺点：
    • 可能引入偏差，因为生成的数据集分布与原数据不同。
    • 测试集可能缺乏代表性。

模型性能度量

回归模型的性能度量：均方误差 (MSE)

均方误差衡量的是模型预测值与真实值之间的平均平方差，公式为： [ MSE = \frac{1}{n} \sum_{i=1}^{n} \left( H(\mathbf{x}_i) - \mathbf{y}_i \right)^2 ]

  • ( H(\mathbf{x}_i) ) 是模型对输入 ( \mathbf{x}_i ) 的预测值。
  • ( \mathbf{y}_i ) 是真实值。
  • ( n ) 是样本数量。

分类模型的性能度量：错误率、精度

  1. 错误率 ( E(\mathbf{x}, \mathbf{y}) )：表示模型预测错误的概率。给定样例集 ( \mathcal{D} = { (\mathbf{x}_1, y_1), (\mathbf{x}_2, y_2), \dots, (\mathbf{x}_M, y_M) } )，其中 ( H(\mathbf{x}_i) ) 是模型对输入 ( \mathbf{x}_i ) 的预测结果。错误率的定义是：

    [ E(\mathbf{x}, \mathbf{y}) = \frac{1}{M} \sum_{i=1}^{M} I(H(\mathbf{x}_i) \neq y_i) ]

    其中，指示函数 ( I(x) ) 在 ( x ) 为真时取值为 1，假时取值为 0。

    如果每个样本的权重不相同，设权重为 ( p(\mathbf{x}_i) )，则错误率的定义变为加权形式：

    [ E(\mathbf{x}, \mathbf{y}) = \sum_{i=1}^{M} p(\mathbf{x}_i) I(H(\mathbf{x}_i) \neq y_i) ]

  2. 精度 ( A(\mathbf{x}, \mathbf{y}) )：表示模型预测正确的概率，等于 1 减去错误率。因此，精度的定义为：

    [ A(\mathbf{x}, \mathbf{y}) = \frac{1}{M} \sum_{i=1}^{M} I(H(\mathbf{x}_i) = y_i) = 1 - E(\mathbf{x}, \mathbf{y}) ] 精度和错误率是互补关系

在二分类问题中，我们可以将模型的性能度量通过以下几个指标来描述：

  1. 精度（Accuracy, ( A )）：表示模型在所有预测中预测正确的比例。定义为：

    [ A = \frac{TP + TN}{TP + TN + FP + FN} ]

    其中：

    • ( TP )（True Positive）：将正类正确预测为正类的数量。
    • ( TN )（True Negative）：将负类正确预测为负类的数量。
    • ( FP )（False Positive）：将负类错误预测为正类的数量。
    • ( FN )（False Negative）：将正类错误预测为负类的数量。

  2. 查准率（Precision, ( P )）：表示模型预测为正类的样本中实际为正类的比例。定义为：

    [ P = \frac{TP}{TP + FP} ]

    查准率衡量的是在所有被预测为正类的样本中，真正属于正类的比例。例如，在判断肿瘤是否为恶性时，查准率可以理解为预测为恶性肿瘤的样本中，确诊为恶性的比例。

  3. 查全率（Recall, ( R )）：表示实际为正类的样本中被模型正确预测为正类的比例。定义为：

    [ R = \frac{TP}{TP + FN} ]

    查全率衡量的是在所有真实正类的样本中，被正确识别出来的比例。若判断标准“宽松”一些，查全率会增大，意味着漏检的样本减少，但这也可能会增加 ( FP ) 的数量。

  4. ( F_\beta ) 度量（( F_\beta )-Score）：是查准率和查全率的加权调和均值。定义为：

    [ F_\beta = (1 + \beta^2) \cdot \frac{P \cdot R}{\beta^2 \cdot P + R} ]

    其中 ( \beta ) 是查全率与查准率的权重平衡因子：

    • 当 ( \beta = 1 ) 时，称为 ( F_1 )-Score，表示查准率和查全率的调和均值，即：

      [ F_1 = \frac{2 \cdot P \cdot R}{P + R} ]

    • 当 ( \beta > 1 ) 时，查全率的影响更大（即更注重减少漏检）。

    • 当 ( \beta < 1 ) 时，查准率的影响更大（即更注重减少误检）。

ROC（Receiver Operating Characteristic）曲线和AUC（Area Under the ROC Curve）

  1. 真正例比率（TPR, True Positive Rate）： TPR，也称为灵敏度（Sensitivity），是指在所有实际为正的样本中，模型正确预测为正的比例。公式为： [ TPR = \frac{TP}{TP + FN} ] 其中，TP（True Positive）是正确预测为正类的样本数，FN（False Negative）是实际为正类但被预测为负类的样本数。

  2. 假正例比率（FPR, False Positive Rate）： FPR是指在所有实际为负的样本中，模型错误地预测为正的比例。公式为： [ FPR = \frac{FP}{FP + TN} ] 其中，FP（False Positive）是错误预测为正类的样本数，TN（True Negative）是正确预测为负类的样本数。

  3. ROC曲线：ROC曲线是以FPR为横坐标、TPR为纵坐标绘制的图形

  4. AUC（Area Under the Curve）： AUC是ROC曲线下的面积，表示模型在所有可能的分类阈值下的综合性能。AUC值越接近1，表示模型的分类性能越好。AUC值为0.5时，表示模型的表现与随机猜测相当。

阈值的敏感性： 就如你所说，不同的模型对阈值的敏感度不同。在概率模型中，阈值的调整可能会影响到TPR和FPR，进而影响到ROC曲线的形状。当阈值较高时，TPR会降低，FPR也会减少；而当阈值较低时，TPR和FPR都会增加。ROC曲线的作用就是通过展示不同阈值下的模型表现，帮助我们更全面地评价模型。

总结来说，ROC和AUC提供了一个较为全面的指标，能够在不同的分类阈值下衡量模型的表现，并帮助我们选择最佳的阈值和模型。

回归模型的泛化误差分解

泛化误差的分解：

  1. 偏差（Bias）：偏差是模型预测的期望值与真实值之间的差异。

  2. 方差（Variance）：方差衡量的是模型在不同的训练集上表现的波动程度。高方差意味着模型对训练数据的细微变化非常敏感，可能导致在不同的数据集上表现不一致。

  3. 噪声（Noise）：噪声是数据本身的随机性，是无法通过任何模型学习到的部分。噪声的存在限制了模型的预测准确度，导致无法完全消除预测误差。

泛化误差的分解公式：

对于回归模型，期望误差（MSE）可以分解为： [ \text{MSE}(x, y) = \mathbb{E}[(H_D(x) - y_D)^2] = \mathbb{E}[(H_D(x) - H^{}(x))^2] + \mathbb{E}[(H^{}(x) - y)^2] + \mathbb{E}[(y - y_D)^2] ] 其中：

  • 方差：(\mathbb{E}[(H_D(x) - H^{*}(x))^2]) 表示模型在不同训练集上的表现变化。
  • 偏差：(\mathbb{E}[(H^{*}(x) - y)^2]) 衡量的是模型的预测与真实值之间的差异。
  • 噪声：(\mathbb{E}[(y - y_D)^2]) 是样本本身的随机误差。 最终的泛化误差是这三个部分的加和，表示了模型在实际应用中的误差来源。

训练程度与模型复杂度对泛化误差的影响：

  1. 训练不足（欠拟合）：偏差较大，且方差较小。

  2. 过度训练（过拟合）：，偏差较小，但方差较大。

    • 解决方案：通过正则化、减少模型复杂度、使用集成学习方法（如随机森林或梯度提升机）来减少过拟合。

噪声的影响：

  • 噪声是不可避免的
  • 噪声的影响限制了模型的最优性能。
