1. IoC（Inversion of Control，控制反转）

定义： IoC是一种设计原则，将对象的创建和依赖管理交给框架或容器，而不是由开发者手动控制。

传统方式： 开发者通常在代码中直接创建和管理对象，控制权在开发者手中。

IoC方式： 框架或容器负责对象的创建和生命周期管理，开发者只需定义对象及其依赖关系，控制权转移到框架。

优点：

  • 降低耦合：对象不直接依赖具体实现，而是依赖抽象。
  • 提高灵活性：依赖关系可通过配置更改，无需修改代码。
  • 便于测试：依赖可替换为模拟对象，简化单元测试。

2. DI（Dependency Injection，依赖注入）

定义： DI是IoC的一种实现方式，通过构造函数、setter方法或接口注入依赖对象。

实现方式：

  • 构造函数注入：通过构造函数传递依赖。
  • Setter注入：通过setter方法设置依赖。
  • 接口注入：通过接口方法注入依赖。

示例：

public class MyService {
    private MyRepository repository;

    // 构造函数注入
    public MyService(MyRepository repository) {
        this.repository = repository;
    }

    // Setter注入
    public void setRepository(MyRepository repository) {
        this.repository = repository;
    }
}

优点：

  • 解耦：对象不直接创建依赖，依赖由外部注入。
  • 可测试性：依赖可替换为模拟对象，便于测试。
  • 可配置性：依赖关系可通过配置文件管理。

3. AOP（Aspect-Oriented Programming，面向切面编程）

定义： AOP通过切面将横切关注点（如日志、事务、安全等）与核心业务逻辑分离，提升代码的模块化。

核心概念：

  • 切面（Aspect）：封装横切关注点的模块。
  • 连接点（Join Point）：程序执行中的特定点（如方法调用）。
  • 通知（Advice）：在连接点执行的动作（如前置、后置、环绕通知）。
  • 切入点（Pointcut）：定义哪些连接点会触发通知。
  • 引入（Introduction）：为类添加新方法或属性。
  • 织入（Weaving）：将切面应用到目标对象的过程。

示例：

@Aspect
public class LoggingAspect {

    @Before("execution(* com.example.service.*.*(..))")
    public void logBefore(JoinPoint joinPoint) {
        System.out.println("Before method: " + joinPoint.getSignature().getName());
    }

    @After("execution(* com.example.service.*.*(..))")
    public void logAfter(JoinPoint joinPoint) {
        System.out.println("After method: " + joinPoint.getSignature().getName());
    }
}

优点：

  • 分离关注点：横切逻辑与业务逻辑分离，提升代码可读性。
  • 代码复用：通用逻辑封装在切面中，减少重复代码。
  • 灵活性：通过配置动态添加或移除切面。

4、Bean 的核心概念

  1. 由 Spring 容器管理：

    • Bean 是 Spring IoC（控制反转）容器管理的对象。
    • Spring 容器负责 Bean 的创建、初始化、依赖注入以及销毁。

  2. 通过配置或注解定义：

    • Bean 可以通过 XML 配置文件、Java 配置类或注解（如 @Component、@Service 等）来定义。

  3. 单例模式（默认）：

    • 默认情况下，Spring 容器中的 Bean 是单例的，即容器中只有一个实例，所有请求都共享这个实例。
    • 也可以通过配置将 Bean 设置为原型（Prototype）模式，每次请求时都创建一个新的实例。

  4. 生命周期管理：

    • Spring 容器管理 Bean 的整个生命周期，包括初始化、使用和销毁。
    • 开发者可以通过实现特定的接口（如 InitializingBean、DisposableBean）或使用注解（如 @PostConstruct、@PreDestroy）来定义 Bean 的生命周期回调方法。

5、Bean 的定义方式

  1. XML 配置： 在 XML 文件中定义 Bean，例如：

    <bean id="myBean" class="com.example.MyBeanClass" />

  2. Java 配置类： 使用 @Configuration 和 @Bean 注解定义 Bean，例如：

    @Configuration
public class AppConfig {
    @Bean
    public MyBeanClass myBean() {
        return new MyBeanClass();
    }
}

  3. 注解扫描： 使用注解（如 @Component、@Service、@Repository、@Controller）标记类，Spring 会自动扫描并注册为 Bean，例如：

    @Component
public class MyBeanClass {
    // 类内容
}

6、Bean 的作用域

Spring 支持多种 Bean 的作用域，常用的有以下几种：

  1. Singleton（单例，默认）：

    • 容器中只有一个 Bean 实例，所有请求共享该实例。
    • 示例： 
      @Scope("singleton")
@Component
public class MyBeanClass { ... }

  2. Prototype（原型）：

    • 每次请求时都会创建一个新的 Bean 实例。
    • 示例： 
      @Scope("prototype")
@Component
public class MyBeanClass { ... }

  3. Request（请求）：

    • 每个 HTTP 请求都会创建一个新的 Bean 实例，适用于 Web 应用。

  4. Session（会话）：

    • 每个 HTTP Session 都会创建一个新的 Bean 实例，适用于 Web 应用。

  5. Application（应用）：

    • 每个 ServletContext 中只有一个 Bean 实例。

  6. WebSocket（WebSocket 会话）：

    • 每个 WebSocket 会话中只有一个 Bean 实例。

7、Bean 的生命周期

Spring 容器管理 Bean 的整个生命周期，包括以下阶段：

  1. 实例化：

    • 容器根据配置或注解创建 Bean 的实例。

  2. 属性赋值（依赖注入）：

    • 容器将 Bean 的依赖注入到对象中。

  3. 初始化：

    • 调用初始化方法（如 @PostConstruct 注解的方法或 InitializingBean 接口的 afterPropertiesSet 方法）。

  4. 使用：

    • Bean 可以被应用程序使用。

  5. 销毁：

    • 当容器关闭时，调用销毁方法（如 @PreDestroy 注解的方法或 DisposableBean 接口的 destroy 方法）。

8、Bean 的依赖注入

Spring 通过依赖注入（DI）来管理 Bean 之间的依赖关系，常见的注入方式有：

  1. 构造函数注入：

    • 通过构造函数注入依赖。
    • 示例： 
      @Component
public class MyService {
    private final MyRepository repository;

    @Autowired
    public MyService(MyRepository repository) {
        this.repository = repository;
    }
}

  2. Setter 注入：

    • 通过 Setter 方法注入依赖。
    • 示例： 
      @Component
public class MyService {
    private MyRepository repository;

    @Autowired
    public void setRepository(MyRepository repository) {
        this.repository = repository;
    }
}

  3. 字段注入：

    • 直接在字段上使用 @Autowired 注解注入依赖。
    • 示例： 
      @Component
public class MyService {
    @Autowired
    private MyRepository repository;
}

  • Bean 是 Spring 容器管理的对象，由容器负责创建、配置和管理。
  • 可以通过 XML、Java 配置类或注解定义 Bean。
  • Spring 支持多种 Bean 的作用域（如 Singleton、Prototype 等）。
  • Spring 管理 Bean 的整个生命周期，包括初始化、使用和销毁。
  • 依赖注入（DI）是 Spring 实现 IoC 的核心机制，用于管理 Bean 之间的依赖关系。
