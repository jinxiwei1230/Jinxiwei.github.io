SQL时间相关总结

1. 常见时间类型

数据库通常支持以下几种时间类型：

  • DATE：仅存储日期，格式为 YYYY-MM-DD。
  • TIME：仅存储时间，格式为 HH:MM:SS。
  • DATETIME / TIMESTAMP：存储日期和时间，格式为 YYYY-MM-DD HH:MM:SS。
  • YEAR：仅存储年份。
  • INTERVAL：表示时间间隔（如 30 days、1 month 等）。

2. 获取当前时间

数据库提供了多种函数来获取当前时间：

  • CURRENT_DATE：返回当前日期（不包括时间）。 
    SELECT CURRENT_DATE;  -- 2023-10-05
  • CURRENT_TIME：返回当前时间（不包括日期）。 
    SELECT CURRENT_TIME;  -- 14:30:45
  • CURRENT_TIMESTAMP / NOW()：返回当前日期和时间。 
    SELECT CURRENT_TIMESTAMP;  -- 2023-10-05 14:30:45

3. 时间计算

数据库支持对时间进行加减运算，常用的方式是使用 INTERVAL。

示例 1：加减天数

SELECT CURRENT_DATE + INTERVAL '10 days';  -- 10 天后的日期
SELECT CURRENT_DATE - INTERVAL '30 days'; -- 30 天前的日期

示例 2：加减月份

SELECT CURRENT_DATE + INTERVAL '1 month';  -- 1 个月后的日期
SELECT CURRENT_DATE - INTERVAL '3 months'; -- 3 个月前的日期

示例 3：加减时间

SELECT CURRENT_TIME + INTERVAL '2 hours';  -- 2 小时后的时间
SELECT CURRENT_TIME - INTERVAL '30 minutes'; -- 30 分钟前的时间

4. 时间过滤

在查询中，经常需要根据时间范围过滤数据。例如：

  • 查询过去 30 天的记录： 
    SELECT *
FROM orders
WHERE order_date >= CURRENT_DATE - INTERVAL '30 days';
  • 查询本月的记录： 
    SELECT *
FROM orders
WHERE order_date >= DATE_TRUNC('month', CURRENT_DATE);

5. 时间格式化

数据库提供了函数来格式化时间输出：

  • DATE_FORMAT（MySQL）： 
    SELECT DATE_FORMAT(NOW(), '%Y-%m-%d %H:%i:%s');  -- 2023-10-05 14:30:45
  • TO_CHAR（PostgreSQL）： 
    SELECT TO_CHAR(NOW(), 'YYYY-MM-DD HH24:MI:SS');  -- 2023-10-05 14:30:45

6. 时间提取

可以从时间字段中提取部分值：

  • YEAR()：提取年份。 
    SELECT YEAR('2023-10-05');  -- 2023
  • MONTH()：提取月份。 
    SELECT MONTH('2023-10-05');  -- 10
  • DAY()：提取日期。 
    SELECT DAY('2023-10-05');  -- 5
  • HOUR()、MINUTE()、SECOND()：提取时间部分。 
    SELECT HOUR('14:30:45');  -- 14

7. 时间差计算

计算两个时间之间的差值：

  • DATEDIFF（MySQL）： 
    SELECT DATEDIFF('2023-10-05', '2023-09-01');  -- 34 天
  • AGE（PostgreSQL）： 
    SELECT AGE('2023-10-05', '2023-09-01');  -- 34 days

8. 时间函数

数据库提供了丰富的时间函数：

  • DATE_TRUNC：截断时间到指定精度（如天、月、年）。

    SELECT DATE_TRUNC('month', '2023-10-05 14:30:45');  -- 2023-10-01 00:00:00

  • EXTRACT：提取时间的部分值。

    SELECT EXTRACT(YEAR FROM '2023-10-05');  -- 2023

9. 时区处理

如果需要处理时区，可以使用以下方法：

  • AT TIME ZONE（PostgreSQL）： 
    SELECT NOW() AT TIME ZONE 'UTC';  -- 转换为 UTC 时间
  • CONVERT_TZ（MySQL）： 
    SELECT CONVERT_TZ(NOW(), '+00:00', '+08:00');  -- 转换为东八区时间

10. 时间索引

为了提高时间字段的查询性能，通常会对时间字段创建索引：

CREATE INDEX idx_order_date ON orders(order_date);
