Python可视化-折线图

（一） JSON 数据处理

（1）JSON 简介

  • 定义：JSON（JavaScript Object Notation）是一种轻量级的数据交互格式，采用文本格式存储和表示数据。

（2）JSON 转换

  • 将 Python 数据转换为 JSON：

    • 使用 json.dumps() 方法。
    • 如果有中文，可以设置 ensure_ascii=False 确保中文正常转换。
    • 语法： 
      json_data = json.dumps(python_data, ensure_ascii=False)
    • 示例： 
      import json

data = {"name": "张三", "age": 25}
json_data = json.dumps(data, ensure_ascii=False)
print(json_data)  # 输出 {"name": "张三", "age": 25}

  • 将 JSON 转换为 Python 数据：

    • 使用 json.loads() 方法。
    • 语法： 
      python_data = json.loads(json_data)
    • 示例： 
      json_data = '{"name": "张三", "age": 25}'
data = json.loads(json_data)
print(data)  # 输出 {'name': '张三', 'age': 25}

（二） pyecharts 数据可视化

1、pyecharts 简介

  • 定义：pyecharts 是一个基于 ECharts 的 Python 数据可视化库。

  • 特点：

    • 支持丰富的图表类型（如折线图、柱状图、饼图等）。

    • 提供全局配置和系列配置选项，灵活定制图表。

    • 交互性强，适合数据分析和展示。

2、基本使用

① 创建折线图

  • 步骤：
    1. 导入 Line 类。
    2. 创建 Line 对象。
    3. 添加 X 轴和 Y 轴数据。
    4. 设置全局配置项。
    5. 渲染图表。
  • 示例： 
    from pyecharts.charts import Line
from pyecharts import options as opts

# 创建折线图对象
line = Line()

# 添加 X 轴数据
line.add_xaxis(["周一", "周二", "周三", "周四", "周五", "周六", "周日"])

# 添加 Y 轴数据
line.add_yaxis("销量", [120, 200, 150, 80, 70, 110, 130])

# 设置全局配置项
line.set_global_opts(
    title_opts=opts.TitleOpts(title="每周销量统计"),
    yaxis_opts=opts.AxisOpts(name="销量"),
    xaxis_opts=opts.AxisOpts(name="星期")
)

# 渲染图表
line.render("line_chart.html")

② 全局配置项

  • 常用配置项：
    • title_opts：设置图表标题。
    • yaxis_opts：配置 Y 轴。
    • xaxis_opts：配置 X 轴。
    • legend_opts：配置图例。
  • 示例： 
    line.set_global_opts(
    title_opts=opts.TitleOpts(title="每周销量统计", pos_left="center"),
    yaxis_opts=opts.AxisOpts(name="销量"),
    xaxis_opts=opts.AxisOpts(name="星期"),
    legend_opts=opts.LegendOpts(pos_left="70%")
)

③ 系列配置项

  • 常用配置项：
    • series_name：设置图例名称。
    • symbol_size：设置点的大小。
    • label_opts：设置标签显示。
    • linestyle_opts：设置线条样式。
  • 示例： 
    line.add_yaxis(
    series_name="销量",
    y_axis=[120, 200, 150, 80, 70, 110, 130],
    symbol_size=10,
    label_opts=opts.LabelOpts(is_show=False),
    linestyle_opts=opts.LineStyleOpts(width=2)
)

3. 综合代码示例

（1）JSON 转换

import json

# Python 数据转 JSON
data = {"name": "张三", "age": 25}
json_data = json.dumps(data, ensure_ascii=False)
print("JSON 数据:", json_data)

# JSON 转 Python 数据
python_data = json.loads(json_data)
print("Python 数据:", python_data)

（2）pyecharts 折线图

from pyecharts.charts import Line
from pyecharts import options as opts

# 创建折线图对象
line = Line()

# 添加 X 轴数据
line.add_xaxis(["周一", "周二", "周三", "周四", "周五", "周六", "周日"])

# 添加 Y 轴数据
line.add_yaxis(
    series_name="销量",
    y_axis=[120, 200, 150, 80, 70, 110, 130],
    symbol_size=10,
    label_opts=opts.LabelOpts(is_show=False),
    linestyle_opts=opts.LineStyleOpts(width=2)
)

# 设置全局配置项
line.set_global_opts(
    title_opts=opts.TitleOpts(title="每周销量统计", pos_left="center"),
    yaxis_opts=opts.AxisOpts(name="销量"),
    xaxis_opts=opts.AxisOpts(name="星期"),
    legend_opts=opts.LegendOpts(pos_left="70%")
)

# 渲染图表
line.render("line_chart.html")
