Python基础语法

(一) 6中常用数据（值）类型：

类型 描述 说明
数字（Number） 支持多种数字类型
- 整数（int） 如：10、-10 表示整数值
- 浮点数（float） 如：13.14、-13.14 表示带小数点的数值
- 复数（complex） 如：4+3j 以 j 结尾表示复数
- 布尔（bool） True、False 表达逻辑值，True 记作 1，False 记作 0
字符串（String） 描述文本的数据类型 由任意数量的字符组成，如："Hello"
列表（List） 有序的可变序列 可有序记录一堆数据，如：[1, 2, 3]
元组（Tuple） 有序的不可变序列 可有序记录一堆不可变的数据，如：(1, 2, 3)
集合（Set） 无序不重复集合 可无序记录一堆不重复的数据，如：{1, 2, 3}
字典（Dictionary） 无序 Key-Value 集合 可无序记录键值对数据，如：{"name": "Alice", "age": 25}

  • 数据类型： type()

  • 类型转换

    • 转换为字符串：str()

    • 转换为整数：int()

    • 转换为浮点数：float()

  • 任何类型，都可以通过str()，转换成字符串

  • 字符串内必须真的是数字，才可以将字符串转换为数字

(二)运算符

运算符 描述 实例
+ 加 两个对象相加：a + b，如 10 + 20 输出结果 30
- 减 得到负数或一个数减去另一个数：a - b，如 10 - 20 输出结果 -10
* 乘 两个数相乘或返回一个被重复若干次的字符串：a * b，如 10 * 20 输出结果 200
/ 除 返回除法结果：b / a，如 20 / 10 输出结果 2.0
// 取整除 返回商的整数部分：9 // 2 输出结果 4，9.0 // 2.0 输出结果 4.0
% 取余 返回除法的余数：b % a，如 20 % 10 输出结果 0
** 指数 返回一个数的幂：a ** b，如 10 ** 20 输出结果 100000000000000000000
运算符 描述 说明
= 赋值运算符 将 = 右边的结果赋给左边的变量
+= 加法赋值运算符 c += a 等效于 c = c + a
-= 减法赋值运算符 c -= a 等效于 c = c - a
*= 乘法赋值运算符 c *= a 等效于 c = c * a
/= 除法赋值运算符 c /= a 等效于 c = c / a
%= 取模赋值运算符 c %= a 等效于 c = c % a
**= 幂赋值运算符 c **= a 等效于 c = c ** a
//= 取整除赋值运算符 c //= a 等效于 c = c // a

(三)字符串

1、字符串定义形式

定义方式 语法 特点
单引号定义法 '字符串内容' 适合定义单行字符串
双引号定义法 "字符串内容" 适合定义单行字符串，内容中可包含单引号
三引号定义法 '''字符串内容''' 或 """字符串内容""" 支持多行字符串，也可作为多行注释使用

2、字符串格式化

格式符号 转化 说明
%s 将内容转换成字符串，放入占位位置 适用于字符串、数字等类型，自动转换为字符串
%d 将内容转换成整数，放入占位位置 适用于整数类型，浮点数会被截断为整数
%f 将内容转换成浮点型，放入占位位置 适用于浮点数类型，默认保留 6 位小数，可通过 %.nf 指定小数位数（n 为数字）

  1. %s 示例：

    • 将内容转换为字符串。
    • 代码： 
      name = "Alice"
age = 25
print("姓名：%s，年龄：%s" % (name, age))
    • 输出： 
      姓名：Alice，年龄：25

  2. %f 示例：

    • 指定保留 2 位小数：

      pi = 3.1415926535
print("圆周率：%.2f" % pi)

      输出：

      圆周率：3.14
  • 如果需要格式化多个值，可以使用元组传递，例如 "字符串 %s %d" % (值1, 值2)。
  • 在 Python 3.6 及以上版本中，推荐使用 f-string（格式化字符串字面值），例如 f"姓名：{name}，年龄：{age}"。

3、辅助符号 m.n 的作用

  • m：控制数据的宽度（总长度）。
    • 要求是数字。
    • 如果设置的宽度小于数据本身的长度，则不生效。
  • .n：控制小数点精度（小数位数）。
    • 要求是数字。
    • 会对小数部分进行四舍五入。
格式化符号 说明
%md 控制整数的宽度为 m 位，不足时左侧补空格
%m.nf 控制浮点数的宽度为 m 位，小数点精度为 n 位，不足时左侧补空格
%.nf 不限制宽度，只设置小数点精度为 n 位 
# 整数宽度控制
num1 = 11
print("整数宽度控制：%5d" % num1)  # 输出：   11

# 浮点数宽度和精度控制
num2 = 11.345
print("浮点数宽度和精度控制：%7.2f" % num2)  # 输出：  11.35

# 仅精度控制
num3 = 11.345
print("仅精度控制：%.2f" % num3)  # 输出：11.35

(四) 数据输入、输出

  • 输入：name = input()
  • 输出：print()

无论键盘输入的是什么格式的数据，接收到都是字符串类型

(五) 判断语句

1、基本语法：

if 条件1:
    执行语句1
elif 条件2:
    执行语句2
else:
    执行语句3

  • 三元运算符：

    值1 if 条件 else 值2

  • 功能：如果条件为 True，返回 值1；否则返回 值2。适用于简单的条件赋值。

  • 常用运算符：

    • and：所有条件都为 True 时返回 True。

    • or：至少一个条件为 True 时返回 True。

    • not：反转条件的布尔值。

2、in 和 not in

  • 功能：用于检查元素是否在序列（如列表、字符串等）中。

  • 示例：

    if x in [1, 2, 3]:
    print("x 在列表中")

3、is 和 is not

  • 功能：用于比较两个对象的身份**（内存地址）**，而不仅仅是值。
  • 示例： 
    if x is y:
    print("x 和 y 是同一个对象")

4、pass 语句

  • 功能：用于占位，表示不执行任何操作。常用于未完成的代码块中。

  • 示例：

    if x > 10:
    pass  # 待实现

5、assert 语句

  • 功能：用于调试，检查条件是否为 True，如果为 False 则抛出 AssertionError。
  • 示例： 
    assert x > 0, "x 必须大于 0"

6、布尔上下文中的真值

  • 在布尔上下文中，非零数字、非空字符串、非空列表等被视为 True；
  • 0、None、空字符串、空列表等被视为 False。

(六) 循环语句

1、while 循环

基本语法：

while 条件:
    循环体

2、for 循环

基本语法：

for 变量 in 可迭代对象:
    循环体
  • 功能：遍历可迭代对象（如列表、字符串、字典、范围等），每次迭代将当前元素赋值给变量，并执行循环体。
  • 特点：
    • 适合已知循环次数的场景。
    • 可迭代对象可以是 range()、列表、字符串等。
  • 示例： 
    for i in range(5):  # range(5)取得的数据是：[0, 1, 2, 3, 4]
    print(i)

#字符串
for char in "Python":
    print(char)

# 列表
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

#元组
colors = ("red", "green", "blue")
for color in colors:
    print(color)

# 字典
person = {"name": "Alice", "age": 25, "city": "New York"}
for key, value in person.items():
    print(f"{key}: {value}")

# 集合
numbers = {1, 2, 3, 4, 5}
for num in numbers:
    print(num)

3、break 语句

  • 功能：立即终止当前循环，跳出循环体。当满足某个条件时，提前结束循环。

  • 示例：

    for i in range(10):
    if i == 5:
        break
    print(i)  # 输出 0 1 2 3 4

4、continue 语句

  • 功能：跳过当前迭代，直接进入下一次循环。

  • 示例：

    for i in range(5):
    if i == 2:
        continue
    print(i)  # 输出 0 1 3 4

5、else 子句

  • 功能：在循环正常结束后执行（即没有被 break 中断）。用于检查循环是否完整执行。

  • 示例：

    for i in range(3):
    print(i)
else:
    print("循环结束")  # 输出 0 1 2 循环结束

for i in range(3):
    if i == 1:
        break
    print(i)
else:
    print("循环结束")  # 不会执行 else 部分

6、 range() 函数

  • 功能：生成一个整数序列，常用于 for 循环。
  • 语法： 
    range(start, stop, step)
    • start：起始值（默认为 0）。
    • stop：结束值（不包含）。
    • step：步长（默认为 1）。
  • 示例： 
    for i in range(2, 10, 2):
    print(i)  # 输出 2 4 6 8

7、循环控制技巧

  • 避免无限循环：在 while 循环中确保条件最终会变为 False。

  • 使用 enumerate()：在 for 循环中同时获取索引和值。

    for index, value in enumerate(["a", "b", "c"]):
    print(index, value)  # 输出 0 a, 1 b, 2 c

  • 使用 zip()：同时遍历多个可迭代对象。

    for a, b in zip([1, 2, 3], ["a", "b", "c"]):
    print(a, b)  # 输出 1 a, 2 b, 3 c

(七) 函数

1. 函数的定义

  • 语法：

    def 函数名(参数1, 参数2, ...):
    函数体
    return 返回值

  • 说明：

    • def 是定义函数的关键字。
    • 函数名是函数的标识符，遵循变量命名规则。
    • 参数是函数的输入（可选）。
    • return 用于返回函数的输出（可选）。

2. 函数的参数

（1）位置参数

  • 参数按顺序传递，位置必须匹配。

  • 示例：

    def add(a, b):
    return a + b
print(add(2, 3))  # 输出 5
（2）关键字参数
  • 通过参数名指定值，顺序可以任意。
  • 示例： 
    print(add(b=3, a=2))  # 输出 5
（3）默认参数（缺省参数）：
  • 为参数提供默认值，调用时可省略。
  • 函数调用时，如果为缺省参数传值则修改默认参数值, 否则使用这个默认值
  • 示例： 
    def greet(name="Guest"):
    return f"Hello, {name}!"
print(greet())  # 输出 Hello, Guest!
（4）可变参数
  • *args：接收任意数量的位置参数，存储为元组。
  • **kwargs：接收任意数量的关键字参数，存储为字典。
  • 示例： 
    def show_args(*args, **kwargs):
    print("位置参数:", args)
    print("关键字参数:", kwargs)
show_args(1, 2, a=3, b=4)

3. 函数的返回值

  • 使用 return 语句返回结果，可以返回单个值、多个值（以元组形式）或无返回值（默认返回 None）。

    def add_and_multiply(a, b):
    return a + b, a * b
result = add_and_multiply(2, 3)
print(result)  # 输出 (5, 6)

4. 函数说明文档

  • 使用文档字符串（docstring）描述函数的功能、参数和返回值。
  • 文档字符串位于函数体的开头，用三引号（"""）包裹。
  • 示例： 
    def add(a, b):
    """
    计算两个数的和

    参数:
    a (int): 第一个数
    b (int): 第二个数

    返回:
    int: 两个数的和
    """
    return a + b
print(add.__doc__)  # 查看文档字符串

5. 函数的嵌套调用

  • 在一个函数内部调用另一个函数。
  • 示例： 
    def square(x):
    return x * x

def sum_of_squares(a, b):
    return square(a) + square(b)

print(sum_of_squares(2, 3))  # 输出 13

6. 变量的作用域

  • 局部变量：在函数内部定义的变量，只能在函数内部访问。

  • 全局变量：在函数外部定义的变量，可以在整个程序访问。

  • 使用 global 关键字在函数内部修改全局变量。

  • 示例：

    x = 10  # 全局变量

def change_x():
    global x
    x = 20  # 修改全局变量

change_x()
print(x)  # 输出 20

7. 匿名函数（Lambda）：

  • 函数没有名称，只能临时使用一次。

  • 函数体只能写一行代码,用于定义简单的单行函数。

    lambda 参数1, 参数2, ...: 表达式

    square = lambda x: x * x
print(square(5))  # 输出 25

add = lambda x, y: x + y
print(add(2, 3))  # 输出 5

8.函数作为参数传递

（1）函数作为参数

  • 作用：将函数作为参数传递给另一个函数，传递的是 计算逻辑 而非数据。

    def compute(x, y, func):
    return func(x, y)

def add(a, b):
    return a + b

result = compute(2, 3, add)
print(result)  # 输出 5
（2）使用 lambda 作为参数

  • 作用：临时定义一个匿名函数作为参数传递。

    def compute(x, y, func):
    return func(x, y)

result = compute(2, 3, lambda a, b: a * b)
print(result)  # 输出 6

9.递归函数：函数调用自身。

def factorial(n):
    if n == 1:
        return 1
    return n * factorial(n - 1)
print(factorial(5))  # 输出 120
