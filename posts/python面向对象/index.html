Python面向对象

1. 类的组成

类由两部分组成：

  • 成员变量（属性）：描述类的特征或状态。
  • 成员方法（行为）：描述类的行为或功能。

注意：函数写在类外，而定义在类内部的函数称为方法。

2. 类和成员方法的定义语法

类的定义语法：

class 类名:
    成员变量
    成员方法

成员方法的定义语法：

def 方法名(self, 参数1, 参数2, ...):
    方法体

3. self 的作用

  • self 表示类对象本身。
  • 只有通过 self，成员方法才能访问类的成员变量。
  • self 出现在形参列表中，但不占用参数位置，调用时无需传递。

4. 构造方法

构造方法的名称：

__init__，注意 init 前后有两个下划线。

构造方法的作用：

  • 在创建类对象时自动运行。
  • 构造方法的参数会传递给类对象，借此可以初始化成员变量。

注意事项：

  • 构造方法中不要忘记 self 关键字。
  • 在方法内使用成员变量时需要使用 self。

8. 常用特殊方法

方法 功能
__init__ 构造方法，用于创建类对象时设置初始化行为。
__str__ 用于实现类对象转字符串的行为，通常用于打印对象信息。
__lt__ 用于两个类对象进行小于或大于比较。
__le__ 用于两个类对象进行小于等于或大于等于比较。
__eq__ 用于两个类对象进行相等比较。

示例代码

class Person:
    # 构造方法
    def __init__(self, name, age):
        self.name = name  # 成员变量
        self.age = age

    # 成员方法
    def say_hello(self):
        print(f"Hello, my name is {self.name} and I am {self.age} years old.")

    # __str__ 方法
    def __str__(self):
        return f"Person(name={self.name}, age={self.age})"

    # __eq__ 方法
    def __eq__(self, other):
        return self.name == other.name and self.age == other.age

# 创建对象
person1 = Person("Alice", 25)
person2 = Person("Bob", 30)

# 调用方法
person1.say_hello()

# 打印对象信息
print(person1)

# 比较对象
print(person1 == person2)  # False

面向对象编程的三大特性：封装、继承、多态

1. 封装

将现实世界事物的 属性 和 行为 封装到类中，描述为 成员变量 和 成员方法，从而完成程序对现实世界事物的描述。

私有成员：

  • 私有成员变量：变量名以 __ 开头（2 个下划线）。
  • 私有成员方法：方法名以 __ 开头（2 个下划线）。

私有成员的特点：

  • 私有成员无法被类对象直接访问。
  • 私有成员可以被类内部的其他成员访问。

2. 继承

一个类继承另一个类的成员变量和成员方法。继承分为 单继承 和 多继承。

单继承：一个类继承一个父类。

多继承：一个类继承多个父类。如果多个父类中有同名成员，按照继承顺序（从左到右）优先级，先继承的优先级高于后继承的。

class 父类:
    pass

class 子类(父类):
    pass

pass 关键字的作用：

pass 是占位语句，用于保证函数（方法）或类定义的完整性，表示无内容。

3. 复写

子类继承父类的成员属性和成员方法后，如果对其“不满意”，可以在子类中重新定义同名的属性或方法。

复写的语法：在子类中重新实现同名成员方法或成员属性即可。
调用父类成员的方式：
  1. 方式 1：使用父类名调用父类成员。
    • 使用成员变量：父类名.成员变量
    • 使用成员方法：父类名.成员方法(self)
  2. 方式 2：使用 super() 调用父类成员。
    • 使用成员变量：super().成员变量
    • 使用成员方法：super().成员方法()

注意：只能在子类内部调用父类的同名成员，子类的实体类对象默认调用的是子类复写的成员。

示例代码

封装与私有成员
class Person:
    def __init__(self, name, age):
        self.name = name  # 公有成员变量
        self.__age = age  # 私有成员变量

    def __say_hello(self):  # 私有成员方法
        print(f"Hello, my name is {self.name}.")

    def introduce(self):  # 公有成员方法
        self.__say_hello()
        print(f"I am {self.__age} years old.")

# 创建对象
person = Person("Alice", 25)
person.introduce()  # 正常调用
# person.__say_hello()  # 报错，无法直接调用私有方法
# print(person.__age)  # 报错，无法直接访问私有变量
继承与复写
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name} makes a sound.")

class Dog(Animal):
    def speak(self):  # 复写父类方法
        print(f"{self.name} barks.")

    def call_parent_speak(self):
        super().speak()  # 调用父类方法

# 创建对象
dog = Dog("Buddy")
dog.speak()  # 调用子类复写的方法
dog.call_parent_speak()  # 调用父类方法
多继承
class A:
    def greet(self):
        print("Hello from A.")

class B:
    def greet(self):
        print("Hello from B.")

class C(A, B):  # 多继承
    pass

# 创建对象
c = C()
c.greet()  # 输出：Hello from A.（A 的优先级高于 B）

4、多态与抽象类（接口）

多态是指 同一个行为，使用 不同的对象 获得 不同的状态。

多态的特点：

  • 同一个方法，在不同类中有不同的实现。
  • 通过父类引用调用方法，实际执行的是子类的实现。

抽象类（接口）

  • 抽象类：包含 抽象方法 的类，称之为抽象类。
  • 抽象方法：没有具体实现的方法（方法体为空，用 pass 表示），称之为抽象方法。
抽象类的特点：
  • 抽象类不能被实例化（不能创建对象）。
  • 抽象类通常用于定义标准或规范，要求子类必须实现抽象方法。
抽象类的作用
  1. 顶层设计：定义标准或规范，明确子类需要实现哪些方法。
  2. 软性约束：要求子类必须复写（实现）父类的抽象方法。
  3. 配合多态：通过多态实现不同的行为状态。
示例代码：
from abc import ABC, abstractmethod  # Python 中定义抽象类和抽象方法的核心工具

# 定义抽象类
class Shape(ABC):
    @abstractmethod
    def area(self):
        pass  # 抽象方法

    @abstractmethod
    def perimeter(self):
        pass  # 抽象方法

# 子类实现抽象方法
class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14 * self.radius ** 2

    def perimeter(self):
        return 2 * 3.14 * self.radius

class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

    def perimeter(self):
        return 2 * (self.width + self.height)

# 创建对象
circle = Circle(5)
rectangle = Rectangle(4, 6)

# 调用方法
print("圆的面积:", circle.area())  # 输出：圆的面积: 78.5
print("矩形的周长:", rectangle.perimeter())  # 输出：矩形的周长: 20

类型注解与 Union 类型

1. 什么是类型注解？

类型注解是指在代码中对变量、函数参数、返回值等的数据类型进行显式说明。它的作用包括：

  • 开发工具支持：帮助 PyCharm 等开发工具进行类型推断，提供代码提示。
  • 代码可读性：为开发者提供类型备注，增强代码的可读性和可维护性。

2. 类型注解的支持范围

类型注解支持以下场景：

  • 变量的类型注解
  • 函数（方法）的形参和返回值的类型注解

3. 变量的类型注解语法

语法 1：直接注解
变量: 类型

示例：

name: str = "Alice"
age: int = 25
语法 2：注释中注解
# type: 类型

示例：

name = "Alice"  # type: str
age = 25  # type: int
注意事项：
  • 类型注解只是提示性的，并非强制性的。即使数据类型和注解类型不匹配，也不会导致错误。

4. 函数（方法）的类型注解

可以为以下部分添加注解：
  • 形参的类型注解
  • 返回值的类型注解
函数（方法）的类型注解语法：
def 函数名(参数1: 类型, 参数2: 类型, ...) -> 返回值类型:
    函数体

示例：

def add(a: int, b: int) -> int:
    return a + b

注意：

  • 返回值类型注解使用 -> 符号。

5. 什么是 Union 类型？

Union 类型用于定义 联合类型注解，表示一个变量可以是多种类型中的一种。

使用方式：
  1. 导包： 
    from typing import Union
  2. 使用： 
    Union[类型1, 类型2, ...]
示例：
from typing import Union

def process_data(data: Union[int, str]) -> None:
    if isinstance(data, int):
        print(f"Processing integer: {data}")
    elif isinstance(data, str):
        print(f"Processing string: {data}")

# 调用函数
process_data(10)       # 输出：Processing integer: 10
process_data("Hello")  # 输出：Processing string: Hello

6. 注意事项

  • 类型注解不会影响程序的运行，即使类型不匹配也不会报错。
  • 类型注解主要用于提高代码的可读性和开发工具的支持。
  • 在 Python 3.10 及以上版本中，可以使用 | 代替 Union，例如 int | float。
