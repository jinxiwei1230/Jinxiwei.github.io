Python异常、模块与包

（一）异常

1. 异常的概念

  • 异常：程序运行过程中出现的错误。
  • Bug：指程序中的异常或错误，源于历史上因小虫子导致计算机失灵的案例。
  • 异常的影响：
    • 程序可能因异常停止运行（崩溃）。
    • 通过捕获异常，可以让程序在出现异常时继续运行。

2. 捕获异常

（1）基本语法

  • 作用：提前假设某处会出现异常，并做好处理准备。

  • 语法：

    try:
    可能发生错误的代码
except:
    如果出现异常执行的代码

（2）捕获指定异常

  • 作用：捕获特定类型的异常。

  • 语法：

    try:
    可能发生错误的代码
except 异常类型 as e:
    处理异常的代码

（3）捕获多个异常

  • 作用：捕获多种类型的异常。
  • 语法： 
    try:
    可能发生错误的代码
except (异常类型1, 异常类型2) as e:
    处理异常的代码
  • 示例： 
    try:
    print(num)  # 可能抛出 NameError
    print(1 / 0)  # 可能抛出 ZeroDivisionError
except (NameError, ZeroDivisionError) as e:
    print("捕获到异常:", e)

（4）捕获所有异常

  • 作用：捕获所有类型的异常。

  • 语法：

    try:
    可能发生错误的代码
except Exception as e:
    处理异常的代码

（5）else 和 finally

  • else：当没有异常时执行的代码。
  • finally：无论是否发生异常，都会执行的代码（如关闭文件）。
  • 语法： 
    try:
    可能发生错误的代码
except Exception as e:
    处理异常的代码
else:
    没有异常时执行的代码
finally:
    无论是否异常都会执行的代码
  • 示例： 
    try:
    f = open("test.txt", "r")
except Exception as e:
    print("捕获到异常:", e)
else:
    print("没有异常，真开心")
finally:
    f.close()

3. 异常的传递性

  • 定义：当函数中发生异常且未被捕获时，异常会传递给调用该函数的代码，直到被捕获或程序崩溃。
  • 特点：
    • 异常会从内层函数向外层函数传递。
    • 如果所有函数都未捕获异常，程序会崩溃。
  • 示例： 
    def func01():
    print(1 / 0)  # 抛出 ZeroDivisionError

def func02():
    func01()  # 异常传递到 func02

def main():
    try:
        func02()  # 异常传递到 main
    except Exception as e:
        print("捕获到异常:", e)

main()  # 输出 "捕获到异常: division by zero"

（二）模块

1. 模块的概念

  • 定义：模块是一个 Python 文件（以 .py 结尾），包含类、函数、变量等，可以被其他 Python 程序导入和使用。
  • 作用：
    • 将代码组织成可重用的单元。
    • 提供工具包，帮助快速实现功能（如 time 模块用于时间操作）。

2. 导入模块

（1）基本语法

  • import 语句：

    import 模块名

  • 使用模块中的功能：

    模块名.功能名()

    import math
print(math.sqrt(16))  # 输出 4.0

（2）from ... import 语句

  • 语法：

    from 模块名 import 功能名

  • 使用功能：

    功能名()

    from math import sqrt
print(sqrt(16))  # 输出 4.0

（3）导入所有功能

  • 语法： 
    from 模块名 import *
  • 注意：不推荐使用，可能导致命名冲突。
  • 示例： 
    from math import *
print(sqrt(16))  # 输出 4.0

（4）别名

  • 模块别名：

    import 模块名 as 别名

  • 功能别名：

    from 模块名 import 功能名 as 别名

    import math as m
print(m.sqrt(16))  # 输出 4.0

from math import sqrt as square_root
print(square_root(16))  # 输出 4.0

（5）导入多个模块

  • 语法：

    import 模块1, 模块2

    import math, random
print(math.sqrt(16))  # 输出 4.0
print(random.randint(1, 10))  # 输出随机数

3. 自定义模块

（1）创建模块

  • 步骤：

    1. 新建一个 Python 文件（如 my_module.py）。
    2. 在文件中定义函数、类或变量。
    # my_module.py
def test(a, b):
    return a + b

（2）导入自定义模块

  • 语法：

    import 模块名

    import my_module
print(my_module.test(1, 2))  # 输出 3

（3）__main__ 变量

  • 作用：区分模块是直接运行还是被导入。

  • 语法：

    if __name__ == "__main__":
    直接运行时执行的代码

    # my_module.py
def test(a, b):
    return a + b

if __name__ == "__main__":
    print(test(1, 1))  # 直接运行时输出 2

（4）__all__ 变量

  • 作用：控制 from 模块名 import * 时导入的功能。
  • 语法： 
    __all__ = ["功能1", "功能2"]
  • 示例： 
    # my_module.py
__all__ = ["test"]

def test(a, b):
    return a + b

def another_function():
    return "Hello"

（三）包

1. Python 包的概念

  • 定义：包是一个包含多个模块的文件夹，文件夹内必须有一个 __init__.py 文件。
  • 作用：
    • 将功能相关的模块组织在一起，方便管理。
    • 提供命名空间，避免模块名冲突。
  • 特点：
    • 从物理上看，包是一个文件夹。
    • 从逻辑上看，包的本质依然是模块。

2. 创建包

（1）步骤

  1. 在 PyCharm 中，右键点击项目目录。
  2. 选择 New → Python Package。
  3. 输入包名，点击 OK。
  4. 包内会自动生成 __init__.py 文件。

（2）示例

  • 创建包 my_package。
  • 在包内创建模块 my_module1.py 和 my_module2.py。

3. 导入包

（1）导入包中的模块

  • 语法：

    import 包名.模块名

  • 使用模块中的功能：

    包名.模块名.功能名()

    import my_package.my_module1
print(my_package.my_module1.test(1, 2))  # 输出 3

（2）从包中导入模块

  • 语法：

    from 包名 import 模块名

  • 使用模块中的功能：

    模块名.功能名()

    from my_package import my_module1
print(my_module1.test(1, 2))  # 输出 3

（3）导入包中的所有模块

  • 语法：

    from 包名 import *

  • 注意：需要在 __init__.py 文件中定义 __all__ 变量，控制导入的模块。

    # my_package/__init__.py
__all__ = ["my_module1"]

# main.py
from my_package import *
print(my_module1.test(1, 2))  # 输出 3

4. __init__.py 文件

  • 标识一个文件夹是 Python 包。
  • 控制包的导入行为（如 __all__ 变量）。
# my_package/__init__.py
__all__ = ["my_module1"]

5. 安装第三方包

（1）使用 pip 安装

  • 语法：

    pip install 包名

    pip install numpy

（2）使用国内镜像加速

pip install -i 镜像地址 包名
