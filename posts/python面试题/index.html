1、Python 中的三元表达式

[on_true] if [expression] else [on_false]
  • [expression] 是一个布尔表达式，结果为 True 或 False。
  • 如果 [expression] 为 True，则整个表达式的结果是 [on_true]。
  • 如果 [expression] 为 False，则整个表达式的结果是 [on_false]。

例子：

x = 10
y = 20

# 使用三元表达式选择较大的值
max_value = x if x > y else y

print(max_value)  # 输出: 20

在这个例子中，x > y 是 False，所以 max_value 被赋值为 y，即 20。

2、Python 中如何实现多线程？

Python 中的多线程可以通过 threading 模块来实现。线程是轻量级的进程，多线程允许程序同时执行多个任务。然而，由于 Python 的全局解释器锁（GIL），多线程在 CPU 密集型任务中并不能真正实现并行执行，但在 I/O 密集型任务中仍然有用。

使用 threading 模块实现多线程

import threading

def print_numbers():
    for i in range(5):
        print(i)

def print_letters():
    for letter in ['a', 'b', 'c', 'd', 'e']:
        print(letter)

# 创建线程
thread1 = threading.Thread(target=print_numbers)
thread2 = threading.Thread(target=print_letters)

# 启动线程
thread1.start()
thread2.start()

# 等待线程完成
thread1.join()
thread2.join()

print("多线程执行完毕")

  1. GIL（全局解释器锁）：Python 的 GIL 确保同一时间只有一个线程执行 Python 字节码。这意味着即使在多核 CPU 上，Python 的多线程也不能真正并行执行 CPU 密集型任务。GIL 的存在是为了保护 Python 解释器的内部数据结构不被多个线程同时修改。

  2. 线程的创建与启动：通过 threading.Thread 创建线程对象，并指定目标函数（target）。调用 start() 方法启动线程。

  3. 线程的同步：join() 方法用于等待线程执行完毕。主线程会阻塞，直到调用 join() 的线程完成。

  4. 适用场景：多线程适用于 I/O 密集型任务（如文件读写、网络请求等），因为这些任务通常会等待外部资源，线程可以在等待时释放 GIL，从而让其他线程执行。对于 CPU 密集型任务，建议使用多进程（multiprocessing 模块）来绕过 GIL 的限制。

3、python内存管理

自动的，由python解释器负责，使用一个私有堆来管理所有对象和数据结构的内存分配和释放。

不需要手动管理，但是可以借助工具和机制来优化和监控内存使用。

Python 内存管理的关键点：

  1. 引用计数：
    • Python 使用引用计数来跟踪对象的使用情况。每个对象都有一个引用计数，当引用计数为 0 时，对象会被自动回收。
    • 引用计数增加的场景：
      • 对象被赋值给变量。
      • 对象被添加到容器（如列表、字典等）。
      • 对象作为参数传递给函数。
    • 引用计数减少的场景：
      • 变量被重新赋值。
      • 对象从容器中移除。
      • 变量超出作用域。

2.垃圾回收（Garbage Collection）：

  • Python 的垃圾回收器负责处理循环引用（即两个或多个对象相互引用，导致引用计数无法归零）。
  • 垃圾回收器使用分代回收算法，将对象分为不同的“代”，并根据对象的存活时间进行回收。

3.内存管理工具：

  • gc 模块：提供了与垃圾回收器交互的接口，如手动触发垃圾回收（gc.collect()）或禁用/启用垃圾回收。
  • sys 模块：提供了查看内存使用情况的工具，如 sys.getsizeof() 可以查看对象占用的内存大小。
  • tracemalloc 模块：用于跟踪内存分配，帮助定位内存泄漏问题。

4、 Python 中的 help() 函数和 dir() 函数

help() 函数：

  • help() 函数用于获取对象的帮助文档。它可以显示模块、类、函数、方法等的文档字符串（__doc__）和参数说明。

5、当退出 Python 时是否释放所有内存分配？答案是否定的

  1. 循环引用：
    • 如果对象之间存在循环引用（例如，两个对象相互引用），即使 Python 退出，这些对象也可能不会被释放，因为它们的引用计数不会归零。
    • 虽然 Python 的垃圾回收器可以处理循环引用，但在某些情况下，垃圾回收器可能无法及时回收这些对象。
  2. 全局命名空间引用：
    • 全局变量和模块级别的对象在 Python 退出时可能不会被释放，因为它们一直被引用。
  3. C 库保留的内存：
    • Python 的一些底层实现依赖于 C 库（如 NumPy、Pandas 等）。这些库分配的内存可能不会被 Python 的垃圾回收器管理，因此在 Python 退出时可能不会被释放。
  4. 操作系统回收内存：
    • 当 Python 进程退出时，操作系统会回收该进程占用的所有内存。因此，即使 Python 没有显式释放内存，操作系统最终也会回收这些资源。

6、 什么是猴子补丁？

猴子补丁（Monkey Patching） 是指在运行时动态修改类、模块或对象的行为。这种技术允许开发者在程序运行时替换或扩展已有的方法、属性或功能，而无需修改源代码。

猴子补丁的特点：

  1. 动态性：猴子补丁是在运行时进行的，而不是在代码编写时。
  2. 灵活性：可以在不修改原始代码的情况下，为现有类或模块添加新功能或修复问题。
  3. 风险性：过度使用猴子补丁可能导致代码难以维护和调试，因为它会改变预期的行为。

猴子补丁的常见用途：

  1. 修复第三方库的 Bug：当无法直接修改第三方库的源代码时，可以通过猴子补丁临时修复问题。
  2. 添加新功能：为现有类或模块添加新的方法或属性。
  3. 测试和模拟：在单元测试中，可以使用猴子补丁模拟某些行为或替换依赖。

例子：

1. 修改类的方法
class MyClass:
    def greet(self):
        return "Hello!"

# 猴子补丁：动态修改 greet 方法
def new_greet(self):
    return "Hi there!"

# 替换原有方法
MyClass.greet = new_greet

obj = MyClass()
print(obj.greet())  # 输出: Hi there!
2. 修改模块的函数
import math

# 猴子补丁：动态修改 math 模块的 sqrt 函数
def new_sqrt(x):
    return x ** 0.5

math.sqrt = new_sqrt

print(math.sqrt(16))  # 输出: 4.0
3. 修复第三方库的问题

假设有一个第三方库的类 ThirdPartyClass 有一个 Bug，我们可以通过猴子补丁修复它：

from some_library import ThirdPartyClass

# 原始方法有 Bug
def fixed_method(self):
    return "Bug fixed!"

# 应用猴子补丁
ThirdPartyClass.buggy_method = fixed_method

obj = ThirdPartyClass()
print(obj.buggy_method())  # 输出: Bug fixed!

猴子补丁的注意事项：

  1. 谨慎使用：猴子补丁会改变代码的预期行为，可能导致难以调试的问题。
  2. 文档化：如果使用了猴子补丁，务必在代码中明确记录，以便其他开发者理解。
  3. 测试覆盖：确保对猴子补丁的修改进行充分的测试，避免引入新的问题。

7、 解释 *args 和 **kwargs

在 Python 中，*args 和 **kwargs 是用于函数定义的特殊语法，允许函数接受任意数量的参数。它们通常用于处理不确定数量的输入参数。

1. *args

  • *args 用于将不定数量的非关键字参数传递给函数。
  • args 是一个元组（tuple），包含所有传递给函数的非关键字参数。
  • * 是解包操作符，表示将传入的参数打包成一个元组。
例子：
def my_function(*args):
    for arg in args:
        print(arg)

my_function(3, 2, 1, 4, 7)

输出：

3
2
1
4
7
解释：
  • my_function(3, 2, 1, 4, 7) 传递了 5 个参数。
  • 这些参数被 *args 打包成一个元组 (3, 2, 1, 4, 7)。
  • 函数内部通过遍历 args 来访问每个参数。

2. **kwargs

  • **kwargs 用于将不定数量的关键字参数传递给函数。
  • kwargs 是一个字典（dictionary），包含所有传递给函数的关键字参数。
  • ** 是解包操作符，表示将传入的关键字参数打包成一个字典。
例子：
def my_function(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

my_function(a=1, b=2, c=7)

输出：

a: 1
b: 2
c: 7
解释：
  • my_function(a=1, b=2, c=7) 传递了 3 个关键字参数。
  • 这些参数被 **kwargs 打包成一个字典 {'a': 1, 'b': 2, 'c': 7}。
  • 函数内部通过遍历 kwargs.items() 来访问每个键值对。

3. 结合使用 *args 和 **kwargs

  • 可以在同一个函数中同时使用 *args 和 **kwargs，以接受任意数量的非关键字参数和关键字参数。
  • 注意：*args 必须在 **kwargs 之前。
例子：
def my_function(*args, **kwargs):
    print("Positional arguments (args):", args)
    print("Keyword arguments (kwargs):", kwargs)

my_function(1, 2, 3, a=4, b=5)

输出：

Positional arguments (args): (1, 2, 3)
Keyword arguments (kwargs): {'a': 4, 'b': 5}
解释：
  • 1, 2, 3 被 *args 打包成元组 (1, 2, 3)。
  • a=4, b=5 被 **kwargs 打包成字典 {'a': 4, 'b': 5}。

4. 参数名的灵活性

  • *args 和 **kwargs 只是约定俗成的命名方式，实际可以使用任意名称，例如 *numbers 或 **options。
  • 但为了代码的可读性，建议使用 *args 和 **kwargs。
例子：
def my_function(*numbers, **options):
    print("Numbers:", numbers)
    print("Options:", options)

my_function(1, 2, 3, a=4, b=5)

输出：

Numbers: (1, 2, 3)
Options: {'a': 4, 'b': 5}

5. 实际应用场景

  • *args 的常见用途：

    • 接受任意数量的非关键字参数，例如实现一个通用的加法函数。
    • 将列表或元组解包后传递给函数。

  • **kwargs 的常见用途：

    • 接受任意数量的关键字参数，例如配置选项或参数传递。
    • 将字典解包后传递给函数。
例子：解包列表和字典
def my_function(a, b, c):
    print(a, b, c)

# 解包列表
args_list = [1, 2, 3]
my_function(*args_list)  # 输出: 1 2 3

# 解包字典
kwargs_dict = {'a': 1, 'b': 2, 'c': 3}
my_function(**kwargs_dict)  # 输出: 1 2 3

9、删除空格

  • lstrip()：删除字符串开头的空格或指定字符。

  • rstrip()：删除字符串末尾的空格或指定字符。

  • strip()：同时删除字符串开头和末尾的空格或指定字符。

  • 删除特定字符

    • lstrip()、rstrip() 和 strip() 还可以指定要删除的字符。
    • 语法：str.lstrip(characters)，str.rstrip(characters)，str.strip(characters)
