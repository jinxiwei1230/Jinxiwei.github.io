# Linux开发环境及应用
## 第四章 正则表达式

### 元字符和集合
1、**正则表达式的概念**
应用范围：字符串匹配操作和替换操作

正则表达式的功能：描述一个字符串模式

**注意:**
正则表达式规则与文件名通配符规则不同
正则表达式规则用于文本处理的场合
文件名匹配规则用于文件处理的场合

不同软件对正则表达式的定义会有差异

2、**正则表达式中的特殊字符**
6个元字符 :**`. * [ \ ^ $`**

转义:用反斜线可以取消特殊字符的特殊含义
如：正则表达end\.只与字符串end.匹配

3、**单字符正则表达式**
转义字符后除以上六种之外的不该出现其他字符，例如:不该出现\u，这样的组合被视为undefined（未定义的），后出的软件有可能会有特殊的解释

*圆点（`·`）：匹配任意单字符*

4、**单字符正则表达式:定义集合**
**在[]之间的字符为集合的内容**
如：单字符正则表达式`[abcd]`与a或b,c,d匹配

**圆点,星号，反斜线在方括号内时，代表它们自己**
如:`[\*.]`可匹配3个单字符

**用减号-定义一个区间**
- `[a-d]`、 `[A-Z]`、 `[a-zA-Z0-9]`
- `[][]` 集合含左右中括号两个字符
- 减号在最后，则失去表示区间的意义，`[ad-]`只与3个字符匹配

**用^表示补集**
^在开头,则表示与集合内字符之外的任意字符匹配.
`[^a-z]`匹配任一非小写字母.
-`[^][]`匹配任一非中括号字符.

^不在开头,则失去其表示补集的意义
`[a-z^]`能匹配27个单字符


### 组合与锚点
**1、单字符正则表达式的组合**
**串结**
如abc， `[A-Z].[0-9]`

**星号（*）**：单字符正则表达式后跟*，匹配此单字符正则表达式的0次或任意多次出现
- 正则表达式`12*4 `
与字符串1234不匹配，与1224，12224，14匹配
- 正则表达式`[A-Z][0-9]* `与`A`,`A1`,`C45`,`D768`匹配，与`b64512`,`T56t`不匹配
- `[Cc]hapter *[1-4] `在*号前有一个空格，允许数字1-4之前有多个或者0个空格,可匹配Chapter2, chapter 3等等

**2、锚点:$和^**
**`$` 在尾部时有特殊意义，否则与其自身匹配**
- `123$` 匹配文件中行尾的123，不在行尾的123字符不匹配
- `$123`与字符串`$123`匹配
- `.$`匹配行尾的任意字符

**`^` 在首部时有特殊意义，否则与其自身匹配**
- `^printf`匹配行首的printf字符串，不在行首的printf串不匹配
- `Hel^lo`与字符串`Hel^lo`匹配
- 在vi中使用:`10,50s/^ //g`,删除10-50行的每行行首的4个空格,`s/匹配内容/替换内容/`、`g`： global（全局替换）

**3、正则表达式扩展**
**基本正则表达式（BRE）**

**扩展正则表达式（ERE）**：增加了分组、逻辑运算符 |、+、? 等更丰富的操作符。ERE 在表达方式上更加直观和易读，通常使用 grep -E 或 egrep 进行支持。

**分组**：使用圆括号 () 将一个子表达式包裹起来，使其作为一个整体来匹配，且可以用于捕获匹配到的内容。

**逻辑运算符`|`**：表示**或**操作，匹配括号内的任意一个子模式。
- `(cat|dog)`,匹配字符串 "`cat`" 或 "`dog`"
- `*`：表示匹配其左侧单个字符或表达式的 0 次或多次,`a*`匹配 0 个或多个 a
- `+`：表示匹配其左侧单个字符或表达式的 1 次或多次,`a+` 匹配 1 个或多个 a
- `?`：表示匹配其左侧单个字符或表达式的 0 次或 1 次
- `\{m,n\}`（重复次数限制）：表示匹配其左侧单个字符或表达式的 m 到 n 次，a\{2,4\} 表示匹配 2 到 4 个a

*在BRE中，像 {} 这样的重复限定符默认是特殊字符，所以需要用反斜杠来转义。
在ERE中，你可以直接使用 {m,n} 而不需要反斜杠。*

`echo "aab" | grep -E "a?b"`  
- `echo` 是一个 shell 命令，用于将其后面的字符串输出到标准输出（通常是终端）
- `-E` 选项表示使用扩展正则表达式（ERE）,使得某些特殊字符（如 ? 和 +）可以直接使用，而不需要转义


**命名的预定义集合**
- `[[:xdigit:]]`:匹配十六进制数字字符
- `\d`:匹配任何数字字符，等价于 `[0-9]`
- `\D`:匹配任何非数字字符，等价于 `[^0-9]`

**比^和$更灵活的锚点定义**

### 三个与正则表达式相关的处理命令
`grep`/`egrep`/`fgrep`：在文件中查找字符串（筛选）
`sed`：流编辑（加工）
`awk`：逐行扫描进行文本处理的一门语言（筛选与加工） 是一门小语言

**1、grep(Global regular expression print)在文件中查找字符串**
语法: `grep 模式 文件名列表`

`egrep` 使用扩展正则表达式ERE描述模式,在指定模式方面比grep更灵活

`fgrep` 快速搜索指定字符串,按字符串搜索而不是按模式搜索,可以使用数据结构中的kmp，以及AC算法来加速

`grep`选项 :
`-F`, --fixed-strings：固定字符串(而不是正则表达式)
`-G`, --basic-regexp：基本正则表达式(BRE)
`-E`, --extended-regexp：扩展正则表达式(ERE)
`-P`, --perl-regexp： perl兼容正则表达式(PCRE)
查PCRE语法: `man pcresyntax`

`grep/fgrep/egrep`选项: 
`-n`：显示时每行前面显示行号
`-v`：显示所有不包含模式的行
`-i`：字母比较时忽略字母的大小写
- `grep -n main *.c` ：查找所有.c文件中含有正则表达式main的行，并打印行号，当文件数超过一个时，除了输出行号，还输出文件名

- `grep -v '[Dd]isable' dev.stat>dev.active`:从 dev.stat中读取内容，并查找所有不包含 disable 或 Disable 的行，将这些行写入到 dev.active中

- `grep -i richard telnos`:在telnos文件中检索字符串richard，不顾字母的大小写

**2、sed：流编辑**
用法:
`sed '命令' 文件名列表`
`sed –e '命令1' –e '命令2' –e '命令3' 文件名列表`
`sed -f 命令文件 文件名列表`

`tail -f pppd.log | sed 's/145\.37\.23\.26/桥西/g'`:持续监视 `pppd.log` 文件中的新内容，并将所有出现的 IP 地址` 145.37.23.26 `替换为 `桥西`

`cat pm.txt | sed 's/\[[^][]*]//g'`
 `\[ 和 ]`：表示匹配方括号 `[ 和 ]`，由于方括号是特殊字符，需要用反斜杠转义。
 `[^][]*`：表示匹配**任意数量**的**不是[或]**的字符（即匹配方括号内的内容）

在正则表达式中，使用 \( 和 \) 来匹配字面上的圆括号，而不是用于分组:
`echo "(test)" | grep -E "\(test\)"  # 匹配 "(test)"`

`[a-zA-Z_][a-zA-Z0-9_]*` 匹配一个合法的**标识符**，开始字符可以是字母或下划线，后续字符可以是字母、数字或下划线。

**后向引用**:在替换字符串中，使用 `\0` 表示整个匹配的字符串，`\1`, `\2`, 等表示第1、第2个子表达式的匹配结果:`s/\([a-zA-Z_][a-zA-Z0-9_]*\)->number/\1->num/g`
将形如 `标识符->number` 的字符串替换为 `标识符->num`，保留标识符。

`s/\([0-9][0-9]\)-\([0-9][0-9]\)-\([0-9][0-9]*\)/\3.\1.\2/g`:将日期格式从“月-日-年”转换为“年.月.日”
```
echo "04-26-1997" | sed 's/\([0-9][0-9]\)-\([0-9][0-9]\)-\([0-9][0-9]*\)/\3.\1.\2/g'
# 输出: 1997.04.26
```

**3、awk：逐行扫描进行文本处理的一门语言**
**用法:**
`awk '程序' 文件名列表`
`awk -f 程序文件名 文件名列表`
程序结构： `条件 { 动作 }`
awk自动对每行文本执行条件判断，满足条件执行动作 （内置循环）
允许多段程序：多段程序间用空格或分号隔开

**处理方式: 符合条件的行，执行相应的动作**
输入文件的每行作为一个**记录**，变量**NR**就是行号
每行用空格分隔开的部分，叫做记录的**域**
内置变量`$1`是第1域内容，`$2`是第2域内容，……
特别的，`$0`指的是整个这一行的内容

**awk描述条件的方法:**
- 使用与C语言类似的关系算符
- 使用与C语言类似的逻辑算符
- 正则表达式的模式匹配 /regexpr/,包含该模式的行，执行动作

特殊的条件:
不指定任何条件，对所有文本行执行动作
BEGIN 开始处理所有文本行之前执行动作
END 处理完所有文本行之后执行动作

**awk描述动作的方法:**
- **自定义变量**:在 awk 中可以使用变量存储数据并进行操作。变量可以在 BEGIN 块中初始化，也可以在处理数据时进行赋值
定义了一个变量 sum，在每行中累加第一列的值，最后输出总和:
```
echo -e "10\n20\n30" | awk '{ sum += $1 } END { print sum }'
# 输出: 60
```

*  **加减乘除等算术逻辑运算**:awk 支持基本的算术运算，如加 (+)、减 (-)、乘 (*)、除 (/) 和取模 (%),逻辑运算符包括与 (&&)、或 (||)、非 (!) 等
对每行的第一列和第二列进行乘法运算:
```
echo -e "5 3\n10 2" | awk '{ print $1 * $2 }'
# 输出: 15
```

- **正则表达式匹配运算符**:使用 ~ 表示匹配，使用 !~ 表示不匹配,只有符合正则表达式（只包含小写字母的单词）的行才会被打印
```
echo -e "apple\nbanana\ncherry\n45" | awk '$1 ~ /^[a-z]+$/ { print $1 }'
# 输出: apple
# 输出: banana
# 输出: cherry
```

* **流程控制**:awk 提供 if 语句用于条件判断，for 循环用于遍历范围、数组或其他集合(语法类似于 C 语言)
输出第一列大于 15 的值:
```
echo -e "10\n20\n30" | awk '{ if ($1 > 15) print $1 }'
# 输出: 20
# 输出: 30
```

对每行的每个字段（单词）进行遍历并打印:
```
echo "1 2 3 4 5" | awk '{ for (i = 1; i <= NF; i++) print $i }'
# 输出:
# 1
# 2
# 3
# 4
# 5
```

- **输出**:
print 用于输出文本或变量，可以输出多个变量，使用逗号分隔
printf 用于格式化输出，类似于 C 语言的 printf 函数,可以控制输出格式，例如小数点位数、填充字符等

打印每行的第一列和第二列:
```
echo -e "name age\nAlice 30\nBob 25" | awk '{ print $1, $2 }'
# 输出:
# name age
# Alice 30
# Bob 25
```

使用格式化字符串输出姓名和年龄:
```
echo -e "name age\nAlice 30\nBob 25" | awk '{ printf "%s is %d years old\n", $1, $2 }'
# 输出:
# Alice is 30 years old
# Bob is 25 years old
```

**补充：**
`NR` (记录数)：表示输入的记录数，从 1 开始计数;当读取多个文件时，计数是全局的，即不会在新文件开始时重置
```
echo -e "line 1\nline 2\nline 3" | awk '{ print "Record number:", NR }'
#输出: 
Record number: 1
Record number: 2
Record number: 3
```

`NF` (字段个数)：表示当前记录（行）中的字段数量,每个字段是由输入字段分隔符（默认为空格）分隔的
```
echo -e "apple orange banana\ncat dog" | awk '{ print "Number of fields in line:", NF }'
#输出: 
Number of fields in line: 3
Number of fields in line: 2
```

`FNR` (读取文件的记录数)：表示当前文件中读取的记录数，从 1 开始计数;当读取多个文件时，每个文件的计数会重置为 1
```
echo -e "file1 line 1\nfile1 line 2" > file1.txt
echo -e "file2 line 1\nfile2 line 2\nfile2 line 3" > file2.txt
awk '{ print "FNR:", FNR, "NR:", NR }' file1.txt file2.txt
#输出: 
FNR: 1 NR: 1
FNR: 2 NR: 2
FNR: 1 NR: 3
FNR: 2 NR: 4
FNR: 3 NR: 5
```

`FS` (输入字段分隔符)：定义如何分隔输入行中的字段，默认是空格
```
echo -e "name,age,gender\nAlice,30,F\nBob,25,M" | awk 'BEGIN { FS="," } { print $1 " is " $2 " years old." }'
#输出: 
name is age years old.
Alice is 30 years old.
Bob is 25 years old.
```

`OFS` (输出字段分隔符):定义在输出时字段之间的分隔符，默认为空格
```
echo -e "1 2 3" | awk 'BEGIN { OFS=":" } { print $1, $2, $3 }'
#输出: 1:2:3
```

`RS` (输入行分隔符)：定义输入记录的分隔符，默认为换行符
```
echo -e "line1\nline2\nline3" | awk 'BEGIN { RS="\n" } { print "Record:", $0 }'
#输出: 
Record: line1
Record: line2
Record: line3
```

`ORS` (输出行分隔符)：定义输出记录的分隔符，默认为换行符
```
echo -e "1 2 3\n4 5 6" | awk 'BEGIN { ORS=" | " } { print $0 }'
#输出: 1 2 3 | 4 5 6 | 
```
