# Linux开发环境及应用

## 第一章 Linux入门
### Linux的历史
1、 **操作系统的演变**
- 手工操作
- 单道批处理操作系统
- 多道批处理系统
- 分时系统

2、 **Unix发展史**
- UNiplexed Information and Computing System
- Unix早期的两大流派：贝尔实验室、加州大学伯克利分校

### Linux字符终端
1、 **Unix/Linux是多用户系统：**
- 主机连接多台字符终端
- 字符终端作为交互式输入输出设备

2、 **终端和主机**
- 终端: 主机的输入和输出设备
终端通过电缆把用户的按键信息送到主机，把主机发来的信息在屏幕上显示

- 主机: 程序和数据的存储及处理
数据及程序存放在主机的硬盘上，程序的运行也都由主机内的CPU占用主机内存来完成

3、 **行律与驱动程序**
- 驱动程序：
不同的硬件需要不同的驱动程序
与行律模块的接口：上行和下行字符流

- 行律的作用
一行内字符的缓冲、回显与编辑，直到按下回车键
数据加工，如：将\n转化为\r\n
将Ctrl-C字符转化为中止进程运行的信号(signal)

4、 **主机与终端间的通信过程**

5、 **终端转义序列**
- 转义字符
Esc：ASCII码1B（十进制27，八进制033）

- 主机发往终端方向数据中的转义序列的功能
控制光标位置、字符颜色、字符大小等等
选择终端的字符集
控制终端上的打印机、刷卡机、磁条器、密码键盘

*Esc[2J 由主机发送到终端的四字节序列：1B 5B 32 4A 功能：清除屏幕
Esc[8A 四字节序列，光标上移8行
Esc[16;8H 七字节序列，光标移到16行8列
Esc[1;31m 七字节序列，红色字符*

6、 **终端类型**
- 定义:定义一组转移序列以及相对应的操作

- 主机和终端之间的类型匹配
主机根据终端类型，实现相应功能时发送对应的控制码
当终端类型不对时，可能全屏幕操作失败

7、 **主机和终端之间的流量控制**
- 必要性
终端的显示速度跟不上主机的发送速度
主机送来数据终端需要打印出来，但打印速度慢
主机送来的显示内容，需暂停显示，仔细分析
需要一种机制控制主机方向来的数据流量

- 两种流控方法
硬件方式：RS232接口的CTS信号线（Clear To Send）
软件方式：利用流控字符Xon和Xoff

8、 **Ctrl-S 和Ctrl-Q**
软件流量控制的方式（利用流控字符Xon 和Xoff）
- 终端希望主机暂停发送数据时，发Xoff字符
- 终端希望主机继续发送数据时，发Xon字符

9、 **仿真终端和虚拟终端**
- 仿真终端
PC机串口，运行终端仿真软件来仿真终端
例如: DOS操作系统下的CrossTalk，Windows中的“超级终端”
仿真的内容包括实现终端的转义码序列功能

- 虚拟终端
UNIX主机与PC机通过网络相连，客户端运行telnet，服务器端telnetd，成为UNIX的一个基于TCP通信的虚拟终端
安全终端：仅仅通过网络，telnet，是不保密的，可以被截获，看到。

### 登录和注销
1、 **超级用户和普通用户**
- Root 用户（超级用户）
root不受权限的制约，可随意修改和删除文件
root用户误删重要文件可能带来严重后果

- 普通用户
由root用户创建（useradd命令）
用户信息存放在/etc/passwd文件中，包括用户名和用户ID，以及Home目录，登录shell
登录shell一般为bash，也可以选其他shell，其他系统程序，甚至自设计的程序
用户可以从普通终端或者网络虚拟终端登录进入系统



## 第二章 命令和工具
### 基本命令
1、 **man 查阅联机手册**(manual)
- 联机手册内容：各种命令的说明书、系统调用的使用手册、C语言和其它语言的库函数手册、系统配置文件格式

- 分页器：q-退出，空格-下一页， 上下箭头-上移下移

- man 命令的用法
`man name`
`man section name`
章节编号：1命令 2系统调用 3库函数 5配置文件
`man -k regexp`
列出关键字(keyword)与正则表达式regexp匹配的手册项目录

2、 **Date 读取系统日期和时间**
`date`
Wed Nov 7 21:09:16 CST 2018

`date "+%Y-%m-%d %H:%M:%S Day %j"`
2018-11-07 21:09:54 Day 311

`date "+%s"`
1541596457

- 格式控制字符串：第一个字符必须为+号，%Y代表年号，%m代表月份，%M代表分钟,"Day 311"指的是今天是今年的第311天

- %s 秒坐标（从UTC1970开始），常用于计算时间间隔


通过NTP协议校对系统时间：命令 ntpdate
`ntpdate 0.pool.ntp.org` (设置时间，必须root用户)
`ntpdate –q 0.pool.ntp.org` (查询时间，普通用户也可以)

3、**cal 打印日历**
`cal`:打印当前月份的日历.
`cal 2020`: 打印2020年的日历.
`cal 10 2019`: 打印2019年10月份的日历.
`cal 12`: 打印公元12年的日历.

4、**bc 计算器**
- 缺省精度
`bc` 缺省精度为小数点后0位.
`bc -l` 缺省精度为小数点后20位.
- 可以通过设置scale自行决定精度（小数点位数）.
例如: scale=10000
例如: s(1.0) (设置精度为小数点后1位)

5、**passwd 更换口令**
- 普通用户：使用passwd命令更改自己的口令，更改前系统先验证原来的口令

- 超级用户root
修改口令之前不验证旧的口令
可修改自己的口令，还可强迫设置其它用户口令
passwd liu：将用户liu的口令强迫设置为某一已知口令
超级用户无法读取其它用户的口令
当普通用户忘记口令时，可请求超级用户强设口令
改超级用户root的口令时要特别注意


### 了解系统状态的命令
1、**who：确定有谁在系统中**
`who` ：列出当前已登录入系统的用户
`tty` ：可以打印出当前终端的设备文件名
`who am i` ：可以列出当前终端上的登录用户
`whoami` ：仅列出当前终端上的登录用户

2、 **uptime: 已开机时间(年龄)**
系统自启动后到现在的运行时间 
当前登录入系统的用户数
近期1分钟，5分钟，15分钟内系统CPU的负载
平均调度队列长度
`uptime`
21:32:56 up 412 days, 4:15, 5 users, load average: 0.55, 0.73, 0.43

3、**top：列出资源占用排名靠前的进程**
VIRT：进程逻辑地址空间大小(virtual)
RES： 驻留内存数(Resident),也就是占用物理内存数.
SHR： 与其他进程共享的内存数(share)
%CPU：占用CPU百分比
%MEM：占用内存百分比
TIME+：占用的CPU时间

4、**ps**
查阅进程状态(process status)(实际上就是将内核中进程状态信息有选择地打印出来)

- UID：用户ID(注册名) 
- PID：进程ID 
- PPID：父进程的PID 
- C：CPU占用指数：最近一段时间(秒级别)进程占用CPU情况
- STIME：启动时间
- SZ：进程逻辑内存大小(Size) 
- TTY：终端的名字
- COMMAND：命令名
- WCHAN：进程在内核的何处睡眠(Wait Channel) 
- TIME：累计执行时间(占用CPU的时间) 
- PRI：优先级
- S：状态，S(Sleep)，R(Run)， Z(Zombie)

- 无选项：只列出在当前终端上启动的进程
`-e` 选项：列出系统中所有的进程(进程范围)
`-f` 选项：以full格式列出每一个进程(控制列的数目)
`-l` 选项：以long格式列出每一个进程(控制列的数目)

5、**free：了解内存使用情况**

6、**vmstat：了解系统负载**
- Procs 
r：等待运行的进程数
b：处在非中断睡眠状态的进程数
- Memory free：空闲的内存; buff/cache：用作缓存的内存数
- Swap：磁盘/内存的交换页数量，单位：KB/秒
- IO：块设备I/O块数，单位：块/秒
- System
in：每秒的硬件中断数(interrupt)，包括时钟中断
cs：每秒的环境切换次数(context switch) 
- CPU 的总使用率： us=user, sy=system, id=idle，wa=wait for disk I/O

### 基础命令
1、**more/less：逐屏显示文件**
`more shudu.c`：指定一个文件
`more *.[ch]`：指定多个文件
`ls -l | more`：指定0个文件
`less shudu.c`
- more:
| Syntax | Description |
| --- | ----------- |
| 空格 | 显示下一屏 |
| 回车 | 上滚一行，当所感兴趣的段落内容正好处于当前屏的尾部，另有一部分在下一页中时，可以连续按回车，将感兴趣的部分滚动上来 |
| q | (quit)退出程序，后面的内容不再显示 |
| /pattern | 搜索指定模式的字符串，模式描述用正则表达式 |
| / | 继续查找指定模式的字符串 |
| h | (Help)帮助信息。打印more命令的所有功能列表 |
| ctrl-L | 屏幕刷新 |

- less:
可直接使键盘的上下箭头键，或者j、k，类似vi的光标定位键，以及PgUp，PgDn，Home，End键

2、**cat 和 od：列出文件内容**
- cat： concatenate:串结，文本格式打印 （选项-n：行号）
- od： octal dump逐字节打印（-c, -t c, -t x1，-t d1, -t u1选项）

`cat -n shudu.c`
`cat try1.c try2.c try.h`
`cat >try` (命令行参数=0个，从stdin获取数据，直到ctrl-d )
`cat try1.c try2.c try.h > trysrc`
`cat makefile *.[ch] > src`

`od -t x1 x.dat` (以十六进制打印文件x.dat各字节 )
`od -t x1 x.dat | more` (以十六进制打印文件x.dat各字节)
`od -c /bin/bash` (逐字符方式打印文件，遇到不可打印字符打印编码)
`echo abcdABCD | od -t x1` (十六进制显示字符的ASCII码)

3、**head 和 tail：显示文件的头部或者尾部**
`head -n 15 ab.c`
显示文件ab.c中前15行 .
`head -n 23 a.c b.c c.c | more `
显示三个文件各自的前23行共显示69行 .
`tail -n 40 liu.mail`
`head -n -20 msg.c` 除去文件尾部20行其余均算“头”
`tail -n +20 msg.c` 除去文件头部20行其余均算作“尾”
`tail -f debug.txt` 实时打印文件尾部被追加的内容（选项-f:forever）

- `netstat -s -p tcp | head`
`netstat`: 网络状态监视命令，用来显示网络连接、路由表、接口统计信息、伪装连接（masquerade connections）以及多播成员（multicast memberships）。
`-s`: 显示每个协议的统计信息（如TCP、UDP、ICMP等）。
`-p tcp`: 只显示 TCP 协议的统计信息。
`| head`: 通过管道（|）将 netstat 的输出传递给 head 命令。head 命令只显示前 10 行内容（默认设置）。
示例输出：
```
Tcp:
    36789 active connections openings
    23412 passive connection openings
    119 connection resets received
    ...
```

- `ls -s | sort | head -n 20`
`ls -s`: 列出当前目录下的文件和目录名，同时显示每个文件/目录所占用的磁盘块大小（以块为单位）。`-s` 选项会在文件名之前显示大小。
`| sort`: 通过管道将 ls 的输出传递给 sort 命令。sort 对输入数据进行排序，默认按照字典序（可以使用其他参数来调整排序方式）。
`| head -n 20`: 通过管道将 sort 的输出传递给head 命令，只显示前 20 行内容。
示例输出：
```
4 a.txt  //占用了 4 个磁盘块
4 b.txt
8 c.log
...
```

4、**tee：将从标准输入stdin得到的数据抄送到标准输出stdout显示，同时存入磁盘文件中**
`./myap | tee myap.log`
`./myap`运行当前目录（./）下的可执行文件 myap
管道符号 `|` 将前一个命令（./myap）的输出作为输入传递给下一个命令（tee）处理
`tee myap.log`：tee 命令将接收到的输入内容同时输出到终端（标准输出）和指定的文件myap.log中。
`tee` 的作用是分流输出（类似于 T 型管道），让 `./myap` 的输出既能在终端上显示，又能保存到文件 myap.log 中。

5、**wc：字计数**
- 列出文件中一共有多少行，有多少个单词，多少字符
- 当指定的文件数大于1时，最后还列出一个合计
- 常用选项-l：只列出行计数

- `wc sum.c` 
- `wc x.c makefile stat.sh` 
- `ps -ef | wc -l` 于统计系统中所有正在运行的进程数量
- `ps -ef | grep liang | wc -l` 该命令用于统计当前系统中与 liang 相关的进程数量
- `who | wc -l` 统计当前系统中登录用户的数量
- `wc -l *.c makefile start.sh`
`*.c`：通配符（wildcard），用于匹配当前目录下所有以 .c 结尾的文件（C 源代码文件），*.c 会匹配这些文件并将其传递给 wc -l 命令。
`makefile`、`start.sh`：具体的文件名

6、**sort：对文件内容排序**
- `-n`选项(Numberic):对于数字按照算术值大小排序，而不是按照字符串比较规则，例如123与67.
- 可以选择行中某一部分作为排序关键字
- 选择升序或降序 .
- 字符串比较时对字母是否区分大小写 .
- 内排序外排序等算法参数选择（当数据量较大时，性能调优） .

- `sort telno > telno1`
对 telno 文件的内容进行排序，并将排序后的内容写入新的文件 telno1 中,如果 telno1 已经存在，则该文件的内容会被覆盖
- `ls -s | sort | tail -10`
按字母顺序显示当前目录中最后 10 个文件（或目录），并显示其大小。
- `ls -s | sort -n | tail -10`
按文件大小排序，并显示当前目录中文件大小最大的 10 个文件。

7、**tr：翻译字符**
- `cat telnos | tr UVX uvx`
该命令读取 telnos 文件的内容，并将所有出现的 U、V、X 转换为 u、v、x。
**注意：tr 只转换单个字符，不会对字符串、单词或多字符模式进行转换。**

- `cat report | tr '[a-z]' '[A-Z]'`
将 report 文件中的所有小写字母转换为对应的大写字母，而非字母字符（例如数字、标点符号）保持不变

- `cat file1 | tr % '\012'`
`\012` 是八进制表示的 ASCII 换行符（换行符的 ASCII 十进制值是 10，转换为八进制是 012）
将 file1 文件中每个 % 符号替换为换行符

8、**uniq：筛选文件中的重复行**
只会识别**连续**的重复行，因此通常与 sort 命令一起使用，先对文件内容排序，然后再使用 uniq 进行去重或其他操作。
`-u`:只显示在整个文件中仅出现一次(不重复)的行
`-d`:只显示文件中出现多次的行，但只显示一次
`-c`:在每行前面加上一个数字，表示该行在文件中出现的次数
